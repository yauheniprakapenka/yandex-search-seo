В Яндекс Вебмастере есть несколько способов, как сообщить Яндексу об обновлениях на сайте. Используйте эти инструменты, чтобы информация с вашего сайта в результатах поиска была актуальной. Это повышает качество поиска, так как посетители получают на сайте соответствующую их запросу информацию.

Какой способ индексирования выбрать — зависит от особенностей сайта и конкретной ситуации. Рекомендуем совмещать подходящие вам способы. Например, можно добавить в Яндекс Вебмастер карту сайта, включить обход по счетчику Метрики и установить плагин IndexNow. Также ссылки на страницы можно добавлять на переобход вручную, на странице **Переобход страниц**.

## Переобход страниц

Чтобы сообщить Яндексу о новых и измененных страницах сайта, перейдите на страницу **Индексирование** → **Переобход страниц** и отправьте ссылки на переобход. Робот Яндекса посетит указанные вами адреса в приоритетном порядке при следующем обращении к сайту. Индексирование страницы может занять от 3 до 7 дней.

На этой же странице можно узнать статусы отправленных страниц и добавить нужную страницу для отслеживания в **Мониторинг важных страниц**.

> **Примечание**
>
> Если вы удалили страницу на сайте и хотите убрать ее из поиска, используйте для этого специальный инструмент Яндекс Вебмастера: **Инструменты** → **Удаление страниц из поиска**.

Подробно:

- [Как переиндексировать сайт](https://yandex.ru/support/webmaster/ru/robot-workings/site-reindex)
- [Как удалить страницы из поиска](https://yandex.ru/support/webmaster/ru/yandex-indexing/removing-from-index)

## Файлы Sitemap

На странице **Индексирование** → **Файлы Sitemap** можно добавить новую или отправить на переобход старую карту сайта. Этот способ особенно подходит для случаев, когда на сайте появилось много новых страниц и карта сайта сильно изменилась.

Подробно: [Использование файла Sitemap](https://yandex.ru/support/webmaster/ru/controlling-robot/sitemap).

## Обход счетчиком

Обход страниц по данным из счетчика Метрики можно включить на странице Яндекс Вебмастера **Индексирование** → **Обход счетчиком**. Для этого на страницах должен быть установлен привязанный к Яндекс Вебмастеру счетчик.

Подробно: [Индексирование сайта с помощью счетчика Метрики](https://yandex.ru/support/webmaster/ru/indexing-options/link-metrica).

## Протокол IndexNow

Протокол IndexNow позволяет напрямую сообщать поисковым системам об изменениях на сайте. Для передачи изменений можно использовать API или специальные плагины для CMS. Результаты индексирования через IndexNow можно узнать в Яндекс Вебмастере.

Подробно: [Поддержка протокола IndexNow](https://yandex.ru/support/webmaster/ru/indexing-options/index-now).

Как узнать результаты индексирования: [Как отслеживать индексирование и управлять им](https://yandex.ru/support/webmaster/ru/robot-workings/control).
