# Yandex Search SEO — офлайн-архив

Полный офлайн-архив справочной документации Яндекс Вебмастера (https://yandex.ru/support/webmaster/ru/).
Все 10 разделов навигации сохранены — более 250 страниц.

Каждая страница сохранена в markdown с сохранением таблиц, списков, примеров кода и описаний полей.
В начале файла указаны заголовок H1 и ссылка на оригинал (`> Source: <URL>`).
Внутренние относительные ссылки преобразованы в абсолютные.

## Разделы

| № | Раздел | Содержание |
|---|--------|------------|
| 1 | Работа с Яндекс Вебмастером | Быстрый старт, права доступа, диагностика, безопасность, качество, эффективность, индексирование, инструменты |
| 2 | Индексирование сайта | Как работает поиск, robots.txt, Sitemap, IndexNow, метатеги, дубли, переезд сайта, канонические адреса |
| 3 | Оформление результатов поиска (сниппет) | Title, description, фавиконка, дата в сниппете |
| 4 | Поиск с Алисой | Ответы Алисы AI, ЭПОС (экспертность, полезность, оригинальность, содержательность) |
| 5 | Дополнительные возможности | Авиабилеты, банковские услуги, видео, врачи, недвижимость, отели, товары, услуги, фильмы и др. |
| 6 | Как измеряется и улучшается качество Поиска | Метрики Проксима и Профицит, асессоры |
| 7 | Рекомендации по созданию сайтов | Советы вебмастеру, мобильные сайты, автозаполнение форм |
| 8 | Партнерские программы | Какие данные передать, Schema.org, Open Graph, JSON-LD, микроформаты (hCard, hRecipe) |
| 9 | Информеры | ИКС, Метрика, время |
| 10 | Справочники | Ошибки индексирования, HTTP-коды, ошибки robots.txt, ошибки Sitemap |
