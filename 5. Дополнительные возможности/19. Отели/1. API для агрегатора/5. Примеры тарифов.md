# Примеры тарифов

> Source: https://yandex.ru/support/webmaster/ru/search-appearance/hotels/example

Тариф для одного или двух взрослых гостей, доступный в любые даты с 1 мая по 1 октября:

```
{
    "conditions": {
        "dates": [
            {
                "min": "2022-05-01",
                "max": "2022-10-01"
            }
        ],
        "occupancy": {
            "adults": {
                "max": 2
            }
        }
    },
    "rate": {
        "amount": "1000",
        "currency": "RUB"
    }
}
```

При поиске с 1 июня по 1 июля цена будет равна 30 \* 1000 = 30000 RUB.

Тариф для двух взрослых гостей с заездом только 1 мая и выездом только 2 мая:

```
{
  "conditions": {
    "dates": [
      {
        "min": "2022-05-01",
        "max": "2022-05-01"
      }
    ],
    "occupancy": {
      "adults": {
        "min": 2,
        "max": 2
      }
    },
    "days": {
      "min": 1,
      "max": 1
    }
  },
  "rate": {
    "amount": "1000",
    "currency": "RUB"
  }
}
```

Тариф для двух взрослых гостей с заездом 1 мая и выездом 3 мая:

```
{
    "conditions": {
        "dates": [
            {
                "min": "2022-05-01",
                "max": "2022-05-02"
            }
        ],
        "occupancy": {
            "adults": {
                "min": 2,
                "max": 2
            }
        }
    },
    "rate": {
        "amount": "1000",
        "currency": "RUB"
    }
}
```

Цена будет равна 2 \* 1000 = 2000 RUB. Для выезда 3 мая нужно указать `"max": "2022-05-02"`, так как сутки выезда не считаются.

Тариф для двух взрослых и двух детей 3 и 4 лет до трех суток в рабочие дни:

```
{
    "conditions": {
        "dates": [
            {
                "min": "2022-05-01",
                "max": "2022-10-01"
            }
        ],
        "occupancy": {
            "adults": {
                "min": 2,
                "max": 2
            },
            "childrenAges": [
                {"max": 3},
                {"max": 7}
            ]
        },
        "days": {
            "max": 3
        },
        "weekdays": [
            "mon",
            "tue",
            "wed",
            "thu",
            "fri"
        ]
    },
    "rate": {
        "amount": "1000",
        "currency": "RUB"
    }
}
```

При поиске с 1 июня по 4 июня цена будет равна 3 \* 1000 = 3000 RUB. После бронирования этого номера с 1 июня по 4 июня, эти даты надо будет исключить из списка доступных:

```
{
    "conditions": {
        "dates": [
            {
                "min": "2022-05-01",
                "max": "2022-05-31"
            },
            {
                "min": "2022-06-04",
                "max": "2022-10-01"
            }
        ],
        "occupancy": {
            "adults": {
                "min": 2,
                "max": 2
            },
            "childrenAges": [
                {"max": 3},
                {"max": 7}
            ]
        },
        "days": {
            "max": 3
        },
        "weekdays": [
            "mon",
            "tue",
            "wed",
            "thu",
            "fri"
        ]
    },
    "rate": {
        "amount": "1000",
        "currency": "RUB"
    }
}
```

Пример параметров ссылки на бронирование:

```
?token=123e4567e89b12d3a456426614174000&checkIn=2022-08-29&checkOut=2022-09-03&adults=2&tariffs.id=season_tariff&tariffs.id=off_season_tariff&tariffs.switchDate=2022-09-01
```
