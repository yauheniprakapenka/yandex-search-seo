# О работе с API для агрегаторов отелей

> Source: https://yandex.ru/support/webmaster/ru/search-appearance/hotels/about

Используйте возможности API для передачи Яндексу данных об отелях, доступности и стоимости номеров, а также о бронированиях, совершенных после перехода с универсальных ответов в результатах поиска Яндекса на ваш сайт.

Для работы с API нужен авторизационный токен — узнайте его у вашего менеджера. Отправляйте токен с каждым запросом к API.

## Лимитирование запросов

- Ограничение *RPS* — 100.
- Ограничение объема данных в одном запросе — 0,08 Мб.
- При превышении ограничения будет приходить ответ с кодом HTTP-статуса 429 (Too Many Requests):
  - `api/v1/hotels` (получить данные о всех отелях): RPS — 1;
  - `api/v1/hotels/{hotelId}/offers` (получить все предложения отеля): RPS — 5;
  - `api/v1/statistics-url` (получить ссылку на статистики): RPS — 1.

## Схема взаимодействия через API

Схема взаимодействия доступна в [оригинале страницы](https://yandex.ru/support/webmaster/ru/search-appearance/hotels/about#scheme).

## Отображение кешбэка

| Параметр | Обязательно | Описание | Примечание |
| --- | --- | --- | --- |
| `promoId` | Да | Идентификатор программы. Определяет: к каким предложениям в фиде относится кешбэк; какой группе пользователей доступен кешбэк. | Один пользователь может участвовать в 5 программах. |
| `cashback` | Да | Сумма кешбэка. Например, 10. | Фиксируется в процентах или в размере кешбэка. |
| `dateFrom` | Нет | Дата начала действия программы кешбэка. | Например, 28.06.2023. |
| `dateTo` | Нет | Дата окончания действия программы кешбэка. | Например, 29.06.2023. |
| `phoneHash` | Да | Номер телефона пользователя. | Перед отправкой используйте хеширование. Информация нужна для определения пользователей, для которых [доступен кешбэк](https://yandex.ru/support/webmaster/ru/search-appearance/hotel-list#hash). |
| `emailHash` | Да | Адрес электронной почты пользователя. | Перед отправкой используйте хеширование. Информация нужна для определения пользователей, для которых [доступен кешбэк](https://yandex.ru/support/webmaster/ru/search-appearance/hotel-list#hash). |

> RPS — количество отправляемых запросов в секунду.
