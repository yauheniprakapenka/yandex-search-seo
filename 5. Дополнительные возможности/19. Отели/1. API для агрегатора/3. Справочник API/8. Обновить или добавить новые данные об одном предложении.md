# Обновить или добавить новые данные об одном предложении

> Source: https://yandex.ru/support/webmaster/ru/search-appearance/hotels/post-offer-id

Перезаписывает сохраненное предложение. Может быть использовано для изменения доступности номеров. Отели представлены моделью [Hotel](https://yandex.ru/support/webmaster/ru/search-appearance/hotels/models/hotel).

Предложение (`offer`) — это номер с ценами, заданными для разных условий размещения. Представлено моделью [Offer](https://yandex.ru/support/webmaster/ru/search-appearance/hotels/models/offer).

## Формат запроса

```
POST https://unisearch-hotels-pacific-partner-api.yandex.ru/api/v1/hotels/{hotelId}/offers/{offerId}
```

### Формат тела запроса

```
<Offer>
```

> `{hotelId}` — идентификатор отеля.
> `{offerId}` — идентификатор предложения (номера).
