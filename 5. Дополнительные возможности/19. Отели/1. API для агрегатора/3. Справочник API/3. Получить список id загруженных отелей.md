# Получить список id загруженных отелей

> Source: https://yandex.ru/support/webmaster/ru/search-appearance/hotels/get-hotels

Получает информацию об id всех загруженных отелей для отображения в результатах поиска Яндекса.

## Формат запроса

```
GET https://unisearch-hotels-pacific-partner-api.yandex.ru/api/v1/hotels
```

## Формат ответа

```
{
    "count": <Number>,
    "ids": [
        "hotel_id_1",
        "hotel_id_2",
        ...,
        "hotel_id_N"
    ]
}
```
