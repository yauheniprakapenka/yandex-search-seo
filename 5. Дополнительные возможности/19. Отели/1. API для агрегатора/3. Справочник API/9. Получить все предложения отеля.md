# Получить все предложения отеля

> Source: https://yandex.ru/support/webmaster/ru/search-appearance/hotels/get-offers

Получает сохраненный список предложений для указанного отеля. Отели представлены моделью [Hotel](https://yandex.ru/support/webmaster/ru/search-appearance/hotels/models/hotel).

Предложение (`offer`) — это номер с ценами, заданными для разных условий размещения. Представлено моделью [Offer](https://yandex.ru/support/webmaster/ru/search-appearance/hotels/models/offer).

## Формат запроса

```
GET https://unisearch-hotels-pacific-partner-api.yandex.ru/api/v1/hotels/{hotelId}/offers
```

## Формат ответа

```
{
    "count": <Number>,
    "offers": [
        <Offer 1>,
        <Offer 2>,
        ...,
        <Offer N>
    ]
}
```

> `{hotelId}` — идентификатор отеля.
