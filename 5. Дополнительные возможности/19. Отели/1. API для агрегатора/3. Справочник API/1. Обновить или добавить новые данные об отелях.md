# Обновить или добавить новые данные об отелях

> Source: https://yandex.ru/support/webmaster/ru/search-appearance/hotels/post-hotels

Обновляет информацию о всех отелях для [отображения в результатах поиска Яндекса](https://yandex.ru/support/webmaster/ru/search-appearance/hotel-list). Отели представлены моделью [Hotel](https://yandex.ru/support/webmaster/ru/search-appearance/hotels/models/hotel).

## Формат запроса

```
POST https://unisearch-hotels-pacific-partner-api.yandex.ru/api/v1/hotels
```

### Формат тела запроса

```
{
    "hotels": [
        <Hotel 1>,
        <Hotel 2>,
        ...,
        <Hotel N>
    ]
}
```

## Особенности отправки данных

При отправке данных сверяются их идентификаторы. Если найдено совпадение, данные обновляются. Например:

1. Вы отправили данные об отелях.

```
{
    "hotels": [
        {
            "id": "hotel_1",
            "names": ["Отель 1"],
            ...
        },
        {
            "id": "hotel_2",
            "names": ["Отель 2"],
            ...
        }
    ]
}
```

2. При последующей отправке будут сохранены данные `"hotel_1"` с названием `"Отель 1"` и `"hotel_2"` с `"Отель номер 2"`:

```
{
    "hotels": [
        {
            "id": "hotel_2",
            "names": ["Отель номер 2"],
            ...
        }
    ]
}
```
