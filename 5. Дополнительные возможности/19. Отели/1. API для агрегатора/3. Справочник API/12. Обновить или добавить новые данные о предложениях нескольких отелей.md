# Обновить или добавить новые данные о предложениях нескольких отелей

> Source: https://yandex.ru/support/webmaster/ru/search-appearance/hotels/post-offers-few

Добавляет или обновляет предложения для указанных отелей. Отели представлены моделью [Hotel](https://yandex.ru/support/webmaster/ru/search-appearance/hotels/models/hotel).

Предложение (`offer`) — это номер с ценами, заданными для разных условий размещения. Представлено моделью [Offer](https://yandex.ru/support/webmaster/ru/search-appearance/hotels/models/offer).

## Формат запроса

```
POST https://unisearch-hotels-pacific-partner-api.yandex.ru/api/v1/offers
```

### Формат тела запроса

```
{
    "offersPerHotel": [
        {
            "hotelId": "hotel_id_1",
            "offers": [
                <Offer 1>,
                <Offer 2>,
                ...,
                <Offer M>
            ]
        },
        {
            "hotelId": "hotel_id_2",
            "offers": [
                <Offer 1>,
                <Offer 2>,
                  ...,
                <Offer K>
            ]
        },
        ...,
        {
            "hotelId": "hotel_id_N",
            "offers": [
                <Offer 1>,
                <Offer 2>,
                ...,
                <Offer L>
            ]
        }
    ]
}
```
