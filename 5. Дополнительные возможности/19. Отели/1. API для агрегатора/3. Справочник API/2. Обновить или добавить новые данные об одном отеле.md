# Обновить или добавить новые данные об одном отеле

> Source: https://yandex.ru/support/webmaster/ru/search-appearance/hotels/post-hotel-id

Обновляет информацию об отеле для [отображения в результатах поиска Яндекса](https://yandex.ru/support/webmaster/ru/search-appearance/hotel-list). Отели представлены моделью [Hotel](https://yandex.ru/support/webmaster/ru/search-appearance/hotels/models/hotel).

## Формат запроса

```
POST https://unisearch-hotels-pacific-partner-api.yandex.ru/api/v1/hotels/{hotelId}
```

### Формат тела запроса

```
<Hotel>
```

> `{hotelId}` — идентификатор отеля.
