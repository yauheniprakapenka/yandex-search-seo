# Удалить данные о предложениях нескольких отелей

> Source: https://yandex.ru/support/webmaster/ru/search-appearance/hotels/delete-offers-few

Удаляет информацию о предложениях нескольких отелей. Отели представлены моделью [Hotel](https://yandex.ru/support/webmaster/ru/search-appearance/hotels/models/hotel).

Предложение (`offer`) — это номер с ценами, заданными для разных условий размещения. Представлено моделью [Offer](https://yandex.ru/support/webmaster/ru/search-appearance/hotels/models/offer).

## Формат запроса

```
DELETE https://unisearch-hotels-pacific-partner-api.yandex.ru/api/v1/offers
```

### Формат тела запроса

```
{
    "offersIdsPerHotel": [
        {
            "hotelId": "hotel_id_1",
            "offersIds": [
                "offer_id_1",
                "offer_id_2",
                ...,
                "offer_id_M"
            ]
        },
        {
            "hotelId": "hotel_id_2",
            "offersIds": [
                "offer_id_1",
                "offer_id_2",
                ...,
                "offer_id_K"
            ]
        },
        ...,
        {
            "hotelId": "hotel_id_N",
            "offersIds": [
                "offer_id_1",
                "offer_id_2",
                ...
                "offer_id_L"
            ]
        }
    ]
}
```
