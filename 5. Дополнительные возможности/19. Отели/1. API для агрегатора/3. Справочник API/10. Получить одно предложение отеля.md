# Получить одно предложение отеля

> Source: https://yandex.ru/support/webmaster/ru/search-appearance/hotels/get-offer-id

Получает сохраненное предложение для указанного отеля. Отели представлены моделью [Hotel](https://yandex.ru/support/webmaster/ru/search-appearance/hotels/models/hotel).

Предложение (`offer`) — это номер с ценами, заданными для разных условий размещения. Представлено моделью [Offer](https://yandex.ru/support/webmaster/ru/search-appearance/hotels/models/offer).

## Формат запроса

```
GET https://unisearch-hotels-pacific-partner-api.yandex.ru/api/v1/hotels/{hotelId}/offers/{offerId}
```

## Формат ответа

```
<Offer>
```

> `{hotelId}` — идентификатор отеля.
> `{offerId}` — идентификатор предложения (номера).
