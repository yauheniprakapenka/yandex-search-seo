# Удалить данные о нескольких предложениях отеля по Id

> Source: https://yandex.ru/support/webmaster/ru/search-appearance/hotels/delete-offers

Удаляет информацию о нескольких предложениях отеля по Id. Отели представлены моделью [Hotel](https://yandex.ru/support/webmaster/ru/search-appearance/hotels/models/hotel).

Предложение (`offer`) — это номер с ценами, заданными для разных условий размещения. Представлено моделью [Offer](https://yandex.ru/support/webmaster/ru/search-appearance/hotels/models/offer).

## Формат запроса

```
DELETE https://unisearch-hotels-pacific-partner-api.yandex.ru/api/v1/hotels/{hotelId}/offers
```

### Формат тела запроса

```
{
  "offersIds": [
      "offer_id_1",
      ...,
      "offer_id_N"
  ]
}
```

> `{hotelId}` — идентификатор отеля.
