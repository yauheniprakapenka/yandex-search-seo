# Отправить данные о заказах

> Source: https://yandex.ru/support/webmaster/ru/search-appearance/hotels/post-orders

Сохраняет данные о заказах, которые представлены моделью [Order](https://yandex.ru/support/webmaster/ru/search-appearance/hotels/models/order).

## Формат запроса

```
POST https://unisearch-hotels-pacific-partner-api.yandex.ru/api/v1/orders
```

### Формат тела запроса

```
{
    "orders": [
        <Order 1>,
        <Order 2>,
        ...
        <Order N>
    ]
}
```

## Особенности отправки данных

При отправке данных сверяются их идентификаторы. Если найдено совпадение, данные обновляются. Например:

1. Вы отправили данные о заказах.

```
{
    "orders": [
        {
            "id": "order_1",
            "token": "123e4567e89b12d3a456426614174000",
            ...
        },
        {
            "id": "order_2",
            "token": "sbdhQmWcG5R1oAy1Ga85O9LokVFHEf7HNDNh6xA",
            ...
        }
    ]
}
```

2. При последующей отправке будут сохранены данные `"order_1"` с токеном `"123e4567e89b12d3a456426614174000"` и `"order__2"` с токеном `"sbdhQmWcG5R1oAy1Ga85O9LokVFHEf7HNDNh6xA"`:

```
{
    "orders": [
        {
            "id": "order_2",
            "token": "sfPSfJDiwAmwKsy3AEooufbaQhKH4ARZ9KVfYKg",
            ...
        }
    ]
}
```
