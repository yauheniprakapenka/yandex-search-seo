# Проверка сформированных предложений для отображения на выдаче из загруженных данных

> Source: https://yandex.ru/support/webmaster/ru/search-appearance/hotels/post-service-offers

Получает сформированный список предложений для отображения на выдаче по указанному отелю и параметрам поиска.

## Формат запроса

```
POST https://unisearch-hotels-pacific-partner-api.yandex.ru/api/v1/hotels/{hotelId}/service-offers
```

### Формат тела запроса

```
{
    "checkIn": "2023-10-02",
    "checkOut": "2023-10-04",
    "ages": {
        "adultsCount": 2,
        "childrenAges": "3,7"
        },
    "currency": "RUB"
}
```

| Поле | Обязательно | Тип | Описание |
| --- | --- | --- | --- |
| `adultsCount` | Да | `Integer` | Количество взрослых. |
| `childrenAges` | Да | `String` | Возраст детей. |
| `checkIn` | Да | `String` | Дата заезда в формате [ISO 8601](https://en.wikipedia.org/wiki/ISO_8601). |
| `checkOut` | Да | `String` | Дата отъезда в формате [ISO 8601](https://en.wikipedia.org/wiki/ISO_8601). Должна быть больше или равна дате в `checkIn`. |

## Формат ответа

```
{
    "hotelOfferInfo": [
        {
            "hotelId": {
                "partnerId": "partner_1",
                "originalId": "hotel_1"
            },
            "offerRecords": {
                "offers": [
                    {
                        "name": "string",
                        "price": {
                            "currency": "RUB",
                            "amount": "2468"
                            },
                            "features": {
                              "boardBasis": "AI",
                              "wifi": "true"
                            },
                            "url": "<https:\\hotel_1.com\room4?adults=2&checkIn=2023-10-02&checkOut=2023-10-04&childAge=3%2C7&price.amount=2468&price.currency=RUB&tariffs.id=hotel_1_offer_4_tariff_1>",
                            "sourceId": "hotel_1_offer_4",
                            "refundRules": [
                                {
                                   "type": "fullyRefundable"
                                }
                            ]
                        }
                    ]
                }
            }
        ]
    }
```

| Поле | Обязательно | Тип | Описание |
| --- | --- | --- | --- |
| `offerRecords` | Да | `Object` | Предложения для этого отеля, которые подходят под задаваемые параметры. |
| `hotelId` | Да | `Object` | `id` отеля. |
| `url` | Да | `String` | Внутренний `url` предложения. |

> `{hotelId}` — идентификатор отеля.
