# Обновить или добавить новые данные о предложениях отеля

> Source: https://yandex.ru/support/webmaster/ru/search-appearance/hotels/post-offers

Добавляет или обновляет предложения для указанного отеля. Отели представлены моделью [Hotel](https://yandex.ru/support/webmaster/ru/search-appearance/hotels/models/hotel).

Предложение (`offer`) — это номер с ценами, заданными для разных условий размещения. Представлено моделью [Offer](https://yandex.ru/support/webmaster/ru/search-appearance/hotels/models/offer).

## Формат запроса

```
POST https://unisearch-hotels-pacific-partner-api.yandex.ru/api/v1/hotels/{hotelId}/offers
```

### Формат тела запроса

```
{
    "offers": [
        <Offer 1>,
        <Offer 2>,
        ...,
        <Offer N>
    ]
}
```

## Особенности отправки данных

Например:

1. Вы отправили данные о предложениях.

```
{
    "offers": [
        {
            "id": "offer_1",
            "name": "Комната 1",
            ...
        },
        {
            "id": "offer_2",
            "name": "Комната 2",
            ...
        }
    ]
}
```

2. При последующей отправке будут сохранены данные `"offer_1"` с названием `"Комната 1"` и `"offer_2"` с названием `"Комната 2"`.

```
{
    "offers": [
        {
            "id": "offer_2",
            "name": "Комната номер 2",
            ...
        }
    ]
}
```

> `{hotelId}` — идентификатор отеля.
