# DateRange

> Source: https://yandex.ru/support/webmaster/ru/search-appearance/hotels/models/date-range

Диапазон дат.

Пример диапазона с 1 мая по 10 мая:

```
{
    "min": "2022-05-01",
    "max": "2022-05-10"
}
```

| Поле | Обязательно | Тип | Описание |
| --- | --- | --- | --- |
| `min` | Да | String | Минимальная дата в формате [ISO 8601](https://en.wikipedia.org/wiki/ISO_8601). |
| `max` | Да | String | Максимальная дата в формате [ISO 8601](https://en.wikipedia.org/wiki/ISO_8601). Должна быть больше или равна дате в `min`. |
