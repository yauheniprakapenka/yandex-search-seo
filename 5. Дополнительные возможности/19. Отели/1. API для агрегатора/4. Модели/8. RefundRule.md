# RefundRule

> Source: https://yandex.ru/support/webmaster/ru/search-appearance/hotels/models/refund-rule

Условия возврата.

Пример:

```
{
    "type": "refundableWithPenalty",
    "startsAt": "P3D",
    "endsAt": "P1DT12H",
    "penalty": {
        "amount": "500",
        "currency": "RUB"
    }
}
```

| Поле | Обязательно | Тип | Описание |
| --- | --- | --- | --- |
| `type` | Да | String | Тип условия. Возможные значения: `fullyRefundable`, `refundableWithPenalty`, `nonRefundable`. |
| `startsAt` | Нет | String | Максимальное значение. |
| `endsAt` | Нет | String | Длительность от окончания действия условия до начала суток заезда. Задается в формате [ISO 8601 Durations](https://en.wikipedia.org/wiki/ISO_8601#Durations). При отсутствии считается что ограничения нет. |
| `penalty` | Нет | Object | Штраф при отмене. Модель [Money](https://yandex.ru/support/webmaster/ru/search-appearance/hotels/models/money). Обязательное при значении `refundableWithPenalty`. |
