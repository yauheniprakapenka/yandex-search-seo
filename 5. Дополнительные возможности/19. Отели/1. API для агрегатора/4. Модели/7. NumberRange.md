# NumberRange

> Source: https://yandex.ru/support/webmaster/ru/search-appearance/hotels/models/number-range

Диапазон целых чисел.

Пример:

```
{
    "min": 2,
    "max": 10
}
```

| Поле | Обязательно | Тип | Описание |
| --- | --- | --- | --- |
| `min` | Нет | String | Минимальное значение. При отсутствии считается равным минимально допустимому значению: 1 для `adults` и `days`, 0 для `childrenAges`. Подробно в разделе [DateRange](https://yandex.ru/support/webmaster/ru/search-appearance/hotels/models/date-range). |
| `max` | Да | String | Максимальное значение. |
