# Tariff

> Source: https://yandex.ru/support/webmaster/ru/search-appearance/hotels/models/tariff

Тариф содержит в себе правила применения, стоимость одного дня проживания и условия возврата. Правила задают условия для параметров поиска: даты проживания и гостей.

Пример:

```
{
    "id": "basic_tariff",
    "conditions": {
        "dates": [
            {
                "min": "2022-05-01",
                "max": "2022-05-03"
            }
        ],
        "occupancy": {
            "adults": {
                "min": 2,
                "max": 2
            },
            "childrenAges": [
                {"max": 3},
                {"max": 7}
            ]
        }
    },
    "rate": {
        "amount": "5000",
        "currency": "RUB"
    },
    "refundRules": [
        {
            "type": "fullyRefundable",
            "endsAt": "P3D"
        },
        {
            "type": "refundableWithPenalty",
            "startsAt": "P3D",
            "endsAt": "P1D",
            "penalty": {
                "amount": "500",
                "currency": "RUB"
            }
        },
        {
            "type": "nonRefundable",
            "startsAt": "P1D"
        }
    ],
    "expiredDate": "2022-05-02T12:00:00Z"
}
```

| Поле | Обязательно | Тип | Ограничения | Описание |
| --- | --- | --- | --- | --- |
| `id` | Да | String | \[a-zA-Z0-9-\_\]{1,255} | Идентификатор тарифа. Передается в параметрах перехода на лендинг. |
| `conditions` | Да | Object | | Правила применения тарифа. Модель [Conditions](https://yandex.ru/support/webmaster/ru/search-appearance/hotels/models/conditions). |
| `rate` | Да | Object | | Стоимость одних суток проживания по данному тарифу. Модель [Money](https://yandex.ru/support/webmaster/ru/search-appearance/hotels/models/money). |
| `refundRules` | Нет | Object\[\] | | Условия возврата. При отсутствии этого значения тариф считается невозвратным. Модель [RefundRule](https://yandex.ru/support/webmaster/ru/search-appearance/hotels/models/refund-rule). |
| `expiredDate` | Нет | Date | | Дата в формате [ISO 8601](https://en.wikipedia.org/wiki/ISO_8601), после которой тариф будет удален без запроса партнера. При отсутствии параметра по умолчанию используется дата на 1 день больше, чем самая поздняя из доступных в поле `conditions.dates` дат для тарифа. |
