# Occupancy

> Source: https://yandex.ru/support/webmaster/ru/search-appearance/hotels/models/occupancy

Условия для гостей.

Пример:

```
{
    "adults": {
        "min": 2,
        "max": 2
    },
    "childrenAges": [
        {"max": 3},
        {"max": 7}
    ]
}
```

| Поле | Обязательно | Тип | Описание |
| --- | --- | --- | --- |
| `adults` | Да | Object | Количество мест для взрослых. Допустимое значение [NumberRange](https://yandex.ru/support/webmaster/ru/search-appearance/hotels/models/number-range). |
| `childrenAges` | Нет | Object\[\] | Места с ограничением возраста задаются списком диапазонов возрастов [NumberRange](https://yandex.ru/support/webmaster/ru/search-appearance/hotels/models/number-range). Массив должен содержать не более 4 элементов. |
