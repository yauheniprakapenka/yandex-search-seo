# Conditions

> Source: https://yandex.ru/support/webmaster/ru/search-appearance/hotels/models/conditions

Правила для применения тарифа.

Пример:

```
{
    ...
    "conditions": {
        "dates": [
            {
                "min": "2022-05-01",
                "max": "2022-05-03"
            }
        ],
        "occupancy": {
            "adults": {
                "min": 2,
                "max": 2
            },
            "childrenAges": [
                {"max": 3},
                {"max": 7}
            ]
        }
    },
    ...
}
```

| Поле | Обязательно | Тип | Ограничения | Описание |
| --- | --- | --- | --- | --- |
| `dates` | Да | Object\[\] | — | Даты проживания. Список [DateRange](https://yandex.ru/support/webmaster/ru/search-appearance/hotels/models/date-range). |
| `occupancy` | Да | Object | — | Гости. Модель [Occupancy](https://yandex.ru/support/webmaster/ru/search-appearance/hotels/models/occupancy). |
| `days` | Нет | Object | — | Количество дней проживания. Допустимое значение [NumberRange](https://yandex.ru/support/webmaster/ru/search-appearance/hotels/models/number-range). |
| `weekdays` | Нет | Object\[\] | — | Дни недели. Возможные значения: `mon`, `tue`, `wed`, `thu`, `fri`, `sat`, `sun`. |

> **Примечание**
> Не учитывайте в условиях сутки выезда.
>
> Например, в условиях бронирования проживания на одни сутки (`days`: 1), с заездом 2022-10-01 и выездом 2022-10-02 поле `dates` будет иметь значение:
>
> ```
> "dates": [
>     {
>         "min": "2022-10-01",
>         "max": "2022-10-01"
>     }
> ]
> ```
>
> Поле `weekdays` при этом не ограничивает сутки выезда.
