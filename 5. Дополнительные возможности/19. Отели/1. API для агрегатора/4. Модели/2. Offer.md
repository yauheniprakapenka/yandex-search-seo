# Offer

> Source: https://yandex.ru/support/webmaster/ru/search-appearance/hotels/models/offer

```
{
    "id": "offer_id",
    "url": "https://example.org/offer/12345",
    "name": "Двухместный номер",
    "features": {
        "boardBasis": "HB",
        "wifi": true
    },
    "tariffs": [
        <Tariff 1>,
        <Tariff 2>,
        ...
        <Tariff N>
    ]
}
```

| Поле | Обязательно | Тип | Ограничения | Описание |
| --- | --- | --- | --- | --- |
| `url` | Да | String\[\] | max\[i\]=1000 | Адрес лендинга. При переходе в запрос будут добавлены [параметры лендинга](#land). |
| `id` | Да | String | \[a-zA-Z0-9-\_\]{1,255} | Идентификатор предложения. Используется для изменения данных об этом предложении. |
| `name` | Да | String\[\] | max\[i\]=255 | Название предложения. |
| `features` | Нет | Object | | Удобства в номере. |
| `features.boardBasis` | Нет | String\[\] | | Питание. [Возможные значения](#board). |
| `features.wifi` | Нет | Boolean | | Наличие Wi-Fi. |
| `tariffs` | Да | Object\[\] | | Тарифы предложения. Модель [Tariff](https://yandex.ru/support/webmaster/ru/search-appearance/hotels/models/tariff). |

### Параметры лендинга

| Параметр | Количество | Описание |
| --- | --- | --- |
| `token` | 1 | Токен перехода на лендинг. |
| `checkIn` | 1 | Дата заезда в формате [ISO 8601](https://en.wikipedia.org/wiki/ISO_8601). |
| `checkOut` | 1 | Дата выезда в формате [ISO 8601](https://en.wikipedia.org/wiki/ISO_8601). |
| `adults` | 1 | Количество мест для взрослых. |
| `childAge` | от 0 | Возраст ребенка. При поиске размещения для нескольких детей передается несколько параметров. |
| `price.amount` | 1 | Цена предложения, показанная пользователю. |
| `price.currency` | 1 | Валюта предложения, показанная пользователю. |
| `tariffs.id` | от 0 | Идентификаторы выбранных тарифов. |

### Виды питания

| Код | Описание |
| --- | --- |
| AI | All inclusive |
| BB | Bed and breakfast (Завтрак) |
| FB | Full board (Завтрак, обед, ужин; пансион) |
| HB | Half board (Завтрак и ужин; полупансион) |
| RO | Без питания |
| UAI | Ultra All Inclusive |
| LAI | Light All Inclusive |
| BD | Только ужин |
