# Money

> Source: https://yandex.ru/support/webmaster/ru/search-appearance/hotels/models/money

Денежная сумма.

Пример:

```
{
    "amount": "500",
    "currency": "RUB"
}
```

| Поле | Обязательно | Тип | Описание |
| --- | --- | --- | --- |
| `amount` | Да | String | Сумма. |
| `currency` | Да | String | Код валюты по ISO. Допустимое значение — RUB (рубли). |
