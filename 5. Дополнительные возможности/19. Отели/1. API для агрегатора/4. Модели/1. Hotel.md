| Поле | Обязательно | Тип | Ограничения | Описание |
| --- | --- | --- | --- | --- |
| `id` | Да | String | \[a-zA-Z0-9-\_\]{1,255} | Идентификатор отеля. Используется для изменения данных об этом отеле и его предложениях. |
| `names` | Да | String\[\] | max\[i\]=255 | Название отеля. |
| `urls` | Нет | String\[\] | max\[i\]=1000 | Адреса сайтов отеля. |
| `phones` | Нет | String\[\] | max\[i\]=255 | Телефоны отеля. |
| `emails` | Нет | String\[\] | max\[i\]=255 | Адреса email отеля. |
| `address` | Да | Object | | Адрес отеля. |
| `address.country` | Да | String | max\[i\]=255 | Страна. |
| `address.region` | Нет | String | max\[i\]=255 | Область. |
| `address.district` | Нет | String | max\[i\]=255 | Район. |
| `address.settlement` | Да | String | max\[i\]=255 | Населенный пункт. |

| `address.streetAddress` | Да | String | max\[i\]=255 | Улица и дом. |
