# Отели

> Source: https://yandex.ru/support/webmaster/ru/search-appearance/hotel-list

## Для каких сайтов

Агрегаторы, сайты объектов.

> Под объектами здесь и далее по тексту понимается гостиница, кемпинг, глэмпинг или гостевой дом.

## Что добавляет в результаты поиска

Содержит фото, названия, адреса, рейтинги, цены и условия размещения в объектах, а также отметки на карте. Когда пользователь ищет информацию о вариантах проживания, Поиск может показать ему карусель из карточек объектов, которые лучше всего соответствуют запросу. Кнопки над таким ответом позволяют пользователю уточнить запрос (например, изменить даты и количество проживающих), не покидая страницу поисковой выдачи. Также можно раскрыть карту и выбрать объект по расположению на местности.

Пример отображения (дизайн может меняться).

## Как настроить

### Подключение для объектов

Подключитесь к одному из агрегаторов:

- [101Hotels.com](http://101hotels.com)
- [Hotelofficial](https://hotelofficial.ru/)
- [Ostrovok.ru](http://ostrovok.ru)
- [Tutu.ru](http://tutu.ru)
- [Tvil.ru](http://tvil.ru)
- [ЖилиБыли](https://zhilibyli.ru/)
- [Отелло](http://otello.2gis.ru)
- [Свой Отель](https://svoy-hotel.ru/)
- [Яндекс Путешествия](http://travel.yandex.ru)

Подключение к агрегатору позволит лицам, оказывающим гостиничные услуги, выводить информацию не только об объекте, но и о доступности номеров на определенные даты, включая стоимость.

Карточки также могут отображаться для объектов, которые не подключены к агрегатору, но они будут содержать только общие сведения об организации без информации о ценах и доступных номерах.

В этом случае для отображения карточки с информацией об объекте:

1. Перейдите на страницу [Организации](https://yandex.ru/sprav/companies).
2. Нажмите кнопку **Добавить** и заполните поля.

   Также вы можете привязать компанию, у которой уже есть профиль на Яндексе, к своему сайту. Для этого перейдите в профиль и в форме редактирования организации в поле **Сайт** укажите адрес сайта, к которому привязывается информация.

### Подключение для агрегаторов

1. Отправьте заявку на подключение через форму.
2. Дождитесь, когда менеджер свяжется с вами по оставленным в форме контактам. Заключите договор с Яндексом — его предоставит менеджер. Обратите внимание, что подключение производится на платной основе.
3. Подготовьте техническую интеграцию и начните регулярно передавать по [API](https://yandex.ru/support/webmaster/ru/search-appearance/hotels/about) данные об отелях, доступности и стоимости номеров, а также о бронированиях, совершенных после перехода с универсальных ответов на сайт агрегатора.

   > Для работы с API нужно использовать авторизационный токен. Узнайте его у вашего менеджера.

4. Предоставьте логотип вашей организации для размещения внутри тематического блока. Формат: векторная иконка, SVG.
5. Пройдите проверку работоспособности интеграции.

**Как работает интеграция**

1. Агрегатор заранее передает данные об объектах, доступности на даты и стоимости номеров через API. Данные автоматически сопоставляются с данными от других агрегаторов, подключенных к тематическим блокам.
2. На основании полученных от агрегаторов данных формируется блок с ценовыми предложениями для каждого конкретного объекта. Предложения показываются пользователю в порядке возрастания стоимости (первым отображается предложение с наименьшей стоимостью). По каждому объекту выводится не больше 3 ценовых предложений*.
3. Пользователь, переходя по ссылке из тематического блока, попадает на лендинг агрегатора с описанием соответствующего варианта размещения на указанные даты с указанием количества проживающих. Если даты не указаны, то по умолчанию отдается контекст +2 дня от текущей даты, 1 ночь.
4. Если пользователь совершил бронирование по указанной ссылке, агрегатор передает по API информацию о совершенном бронировании.

*\* Для популярных направлений без указания даты ценовые предложения агрегаторов могут выводиться сразу после поиска, для непопулярных — пользователю может потребоваться указать даты заезда/выезда.*

> В случае неправильного сопоставления отеля на сайте агрегатора и в Яндекс Организациях, сообщить об ошибке можно в [XLSX-файле](https://yandex.ru/support/webmaster/ru/search-appearance/data-xlsx).

## Отображение кешбэка

В результатах поиска в карточках объектов со списком предложений от партнеров может отображаться кешбэк за бронирование и оплату гостиничных услуг, который может быть использован для последующих покупок. Например, это могут быть баллы от сервиса бронирования.

**Пример отображения**

Дизайн может меняться в зависимости от конкретной программы начисления кешбэка.

Чтобы кешбэк начал отображаться в карточке объекта, нужно передавать Яндексу информацию о программах, в рамках которых он начисляется, и пользователях, для которых такие программы доступны. Информация передается через API.

**Условия подключения**

Кешбэк может отображаться в карточке товара, если соответствует условиям:

- кешбэк начисляется за текущее бронирование;
- 1 балл кешбэка равен 1 рублю.

**Как подключить**

*Шаг 1. Подготовьте данные о пользователях*

1. Передайте через API [данные о кешбэке и пользователях](https://yandex.ru/support/webmaster/ru/search-appearance/hotels/about#cashback), которым он может быть показан.
2. Настройте обновление данных не реже раза в сутки.

*Шаг 2. Передайте данные в Яндекс*

1. Заполните заявку, указав:
   - название партнера, участвовать могут только текущие партнеры;
   - для каких пользователей доступен кешбэк;
   - краткое описание программы, в рамках которой начисляется кешбэк (название программы, чему равен 1 балл и пр.).
2. Добавьте фавиконку вашей программы. Она будет отображаться в карточке товара.

   Требования к фавиконке:
   - Формат: SVG (рекомендуемый), ICO, GIF, JPEG, PNG, BMP.
   - Анимация не поддерживается.
   - Размер: 120 × 120, 32 × 32 или 16 × 16 пикселей.

**Как поиск по отелям использует данные пользователей**

По умолчанию кешбэк может отображаться для пользователей, которые на момент просмотра карточки отеля уже являются участниками программы кешбэка.

*Хеширование данных о пользователях*

При подготовке данных используйте хеширование по алгоритму [md5](https://en.wikipedia.org/wiki/MD5). При этом каждая запись должна быть захеширована отдельно.

| Поле | Описание |
| --- | --- |
| `phone_hash` | Номер телефона пользователя. Числовая строка, содержащая номер мобильного телефона с указанием кода страны. Нельзя использовать пробелы и дополнительные символы. Например: `79995551111` (а не `7 (999) 555-11-11`). |
| `emails_hash` | Адрес электронной почты пользователя. Строка латиницей, включающая символ @ и имя домена. Нельзя использовать прописные буквы. Например: `mail@yandex.ru` (а не `Mail@yandex.ru`). |

Пример записей с захешированными значениями:

```
phone_hash,emails_hash
a31259d185ad013e0a663437c605d056,78ee6d68f49d2c90397d9ff77fc3814d1
702e8494aeb560dff987eh623e71ccf8,f5ge43thaeb67df89875777e71bccf88i
```
