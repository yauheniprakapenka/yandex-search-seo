# Образовательные онлайн-курсы и уроки

> Source: https://yandex.ru/support/webmaster/ru/search-appearance/education

## Для каких сайтов

Сайты, предлагающие курсы и другие образовательные услуги, которые проводятся онлайн.

## Что добавляется в результаты поиска

Ответ с подборкой курсов, информацией о сайте-источнике и стоимости обучения. Пользователь, который ищет информацию об образовательных услугах, может сравнить несколько курсов и перейти к тому, который его заинтересовал.

Пример отображения (дизайн может меняться).

## Как настроить

Чтобы ваши предложения попадали в такие ответы, необходимо передать Яндексу информацию о них. Для этого нужно подготовить фид в формате [YML](https://yandex.ru/dev/conversion/doc/concepts/snippets.html). Стандарт YML разработан Яндексом и основан на стандарте XML. Фид — это файл, в котором вы передаете информацию о своих товарах. В нем описываются предложения (`offers`), объединенные в специальные наборы — сеты (`sets`) и категории (`categories`), к которым относится предложение.

В поисковой выдаче будет формироваться ответ с информацией из предложений.

Также предложения могут попадать в ответ автоматически на основе обработки данных поискового робота Яндекса.

**Требования к фиду**

Фид содержит информацию о площадке и проводимом онлайн обучении с детальной информацией об их свойствах. Каждый курс должен ссылаться на категорию в едином рубрикаторе курсов.

Ограничения для фида:

| Параметр | Ограничение |
| --- | --- |
| Размер YML-файла | 200 МБ |
| Общее количество изображений | 50 000 |
| Количество изображений в одном элементе `offer` | 200 |
| Количество элементов `offer` | 30 000. Данные из фида, который содержит больше предложений, для дополнительного представления использованы не будут. Сам фид загрузится с ошибкой. Чтобы предложения участвовали в поиске, разбейте фид на несколько частей. |
| Количество элементов `set` | 1 млн |
| Количество всех YML-файлов (товарные фиды, фиды услуг и предложений, RSS для контентных Турбо-страниц) суммарно для сайта и его поддоменов | 1000 |

Не дублируйте предложения с одним и тем же URL-адресом в нескольких фидах, а также не переносите предложения из одного фида в другой — данные из перенесенного предложения могут временно пропасть из поиска.

Также можно описать наборы курсов из произвольного списка курсов площадки.

[Пример фида](https://download.cdn.yandex.net/from/yandex.ru/support/ru/webmaster/files/education.xml).

### Элементы описания площадки (shop)

Минимальный набор элементов фида (обязательные отмечены звездочкой):

| Элемент | Примечание |
| --- | --- |
| `name` * | Краткое название площадки. Не больше 30 символов. |
| `url` * | URL-адрес площадки. |
| `email` * | Адрес электронной почты для обращения по вопросам онлайн-курсов. |
| `picture` * | Логотип площадки. Требования: минимальный размер — 100 × 100 пикселей (квадрат); формат PNG или SVG; логотип может быть на фоне любого цвета, не нужно дополнительно вписывать логотип в круг. Если логотип на белом фоне, максимально заполните площадь картинки логотипом. |
| `description` | Описание площадки для отображения на карточке площадки. |
| `currencies` * | Список валют, в которых указаны цены курсов. По умолчанию цены указываются в рублях (`currency id="RUR" rate="1"`). Чтобы передать другие валюты, укажите курс обмена в качестве значения атрибута `rate`. |
| `sets` | Наборы курсов, которые описываются через название и `url`. Чтобы указать, какие курсы входят в набор, используйте элемент `set-ids` внутри элемента `offer`. |

### Элементы предложения (offer)

| Элемент | Примечание |
| --- | --- |
| `name` * | Название предложения. Должно быть уникальным. Если курсы имеют одинаковые названия, то в `name` укажите разницу между ними. |
| `url` * | URL-адрес предложения. Должен быть уникальным среди всех предложений в пределах всех фидов одного и того же региона. Метки (например, UTM, Openstat, from) не делают URL уникальным. |
| `categoryId` * | Идентификатор основной категории курса из рубрикатора курсов. |
| `param name="Дополнительная категория"` | Идентификатор дополнительной категории курса из общего рубрикатора курсов, если он нужен. |
| `set-ids` | Идентификаторы сетов. Можно перечислить несколько сетов через запятую, например: `s1,s2,s3`. |
| `price` * | Стоимость за весь курс. Если фиксированная цена за курс отсутствует, то значение `0`. Если значение `0` и не указана ежемесячная цена, то курс считается бесплатным. |
| `currencyId` * | Идентификатор валюты. Например, `RUR` для рублей. |
| `param name="Ссылка на контент курса"` | URL-адрес контента курса. Внутренняя страница курса, на которой идет обучение. Не может совпадать с `url`. Ссылка нужна для оценки качества курсов при их ранжировании. Можно указать множество значений. |
| `param name="Цена по скидке"` | Число. |
| `param name="Дата окончания скидки"` | Дата в формате [ISO 8601](https://ru.wikipedia.org/wiki/ISO_8601). |
| `param name="Цена за подписку"` | `true` или `false` (по умолчанию). Укажите `true`, если курс доступен по подписке. Цена подписки должна быть указана в элементе `price`. |
| `param name="Оплата в рассрочку"` | Число. Указывает период рассрочки. По умолчанию в месяцах. С помощью атрибута `unit` можно указать: день или месяц. |
| `param name="Ежемесячная цена"` | Число. Только для указания ежемесячной оплаты курса, не допускается указание стоимости оплаты в месяц в рассрочку. |
| `param name="Ежемесячная цена по скидке"` | Число. Наличие скидки для ежемесячной оплаты курса. |
| `param name="Дата окончания ежемесячной скидки"` | Дата в формате [ISO 8601](https://ru.wikipedia.org/wiki/ISO_8601). |
| `param name="Ближайшая дата"` | Дата в формате [ISO 8601](https://ru.wikipedia.org/wiki/ISO_8601). Обязательно для форматов обучения: `самостоятельно с наставником` и `в группе с наставником`. |
| `param name="Продолжительность"` * | Число. С помощью атрибута `unit="единица"` можно указать: час, день, месяц. |
| `param name="План"` * | Строка. Описывает этапы программы обучения. Элемент должен повторяться несколько раз, для курса должно быть указано 3 и больше элементов. Название этапа указывается в атрибуте `unit`. Длительность этапа в часах — в атрибуте `hours`. Значение `param` описывает содержание этапа. Порядок этапов указывается через атрибут `order`. |
| `param name="Формат обучения"` | `Самостоятельно` (по умолчанию), `Самостоятельно с наставником`, `В группе с наставником`, `С преподавателем`. |
| `param name="Есть видеоуроки"` | `true` или `false` (по умолчанию). |
| `param name="Есть текстовые уроки"` | `true` или `false` (по умолчанию). |
| `param name="Есть вебинары"` | `true` или `false` (по умолчанию). |
| `param name="Есть домашние работы"` | `true` или `false` (по умолчанию). |
| `param name="Есть тренажеры"` | `true` или `false` (по умолчанию). |
| `param name="Есть сообщество"` | `true` или `false` (по умолчанию). |
| `param name="Сложность"` | `Для новичков` (по умолчанию), `Для опытных`. |
| `param name="Тип обучения"` | `Курс` (по умолчанию), `Профессия`. |
| `param name="Есть бесплатная часть"` | `true` или `false` (по умолчанию). |
| `param name="С трудоустройством"` | `true` или `false` (по умолчанию). Только для типа обучения `профессия`. |
| `param name="Результат обучения"` | `Сертификат`, `Диплом`, `Удостоверение`. |
| `param name="Часы в неделю"` | Число. Ожидаемая интенсивность занятий. |
| `param name="Классы"` | Строка. Список классов для курсов школьного образования. Можно через запятую и диапазоны. Например, `1,2,5-7,9`. |
| `picture` | Ссылка на логотип курса. |
| `description` * | Описание курса: о чем, кому подходит. |

### Рубрикатор категорий

Чтобы пользователи могли увидеть ваши курсы в результатах поиска по указанным в поисковом запросе категориям или выбрали подходящий курс в сформированном ответе, укажите для каждого курса идентификатор категории из рубрикатора категорий. Курс может относиться к разным категориям, поэтому можно указать дополнительную категорию курса с помощью `param name="Дополнительная категория"`.

Пользователи с большей вероятностью найдут курс в узкой категории «Веб-разработка», чем в корневой категории «Программирование», поэтому для `categoryId` лучше указывать идентификатор узкой категории.

Пример:

```xml
<categories>
    <category id="100">Программирование</category>
    <category id="101" parentId="100">Веб-разработка</category>
    <category id="102" parentId="100">Android-разработка</category>
    <category id="103" parentId="100">iOS-разработка</category>
    <category id="104" parentId="100">Разработка на Python</category>
    <category id="105" parentId="100">Разработка на Go</category>
</categories>
```

[Рубрикатор категорий](https://yastatic.net/s3/doc-binary/src/support/products/education_rubricator.xml).

[Подробно о работе с фидом](https://yandex.ru/support/webmaster/ru/feed/upload).

### Как передать фид

Загрузить фид можно в Вебмастере или с помощью API Вебмастера.

В Вебмастере:

Авторизуйтесь на Яндексе. [Добавьте сайт](https://yandex.ru/support/webmaster/ru/service/quick-start) в Яндекс Вебмастер и [подтвердите права](https://yandex.ru/support/webmaster/ru/service/rights#how-to) на управление или [получите доступ](https://yandex.ru/support/webmaster/ru/service/rights-management#delegation) для вашего аккаунта у пользователя с ролью **Владелец**.

1. Перейдите на страницу **Услуги и предложения в поиске** → **Фиды и ошибки**.
2. Нажмите **Загрузить фид**.
3. Выберите категорию бизнеса **Образование**, если данные касаются образовательных курсов или уроков, которые проводятся онлайн.
4. Укажите регион. Например, если предложения в фиде доступны на одинаковых условиях во всех регионах, выберите **Россия**.
5. В поле **Ссылка на файл с предложениями** укажите URL вида `https://example.com/feed.yml`.

   Если на вашем сайте настроена авторизация для доступа к YML-файлу, вы можете передавать логин и пароль вместе с URL, по которому он доступен. Например: `http://yandex:WE9h4FfBml@example.com/feed.yml`.

6. Нажмите **Готово**.

Подробно см. [документацию](https://yandex.ru/dev/webmaster/doc/dg/concepts/feeds.html).

Яндекс Вебмастер проверит фид. Если он содержит ошибки, в сервисе на странице **Услуги и предложения в поиске** → **Фиды и ошибки** появится сообщение об ошибках. Чтобы узнать подробности, нажмите напротив фида **Ошибки**.

Исправьте ошибки — в течение некоторого времени Яндекс Вебмастер проверит фид снова.

Также информация о сайте и предложениях будет [проверена службой контроля качества](https://yandex.ru/support/webmaster/ru/feed/education) в течение нескольких дней. Фид может быть отклонен за [нарушение правил](https://yandex.ru/support/webmaster/ru/feed/education).

## Условия

Сайт несет ответственность за корректность данных, соответствие предложений тематике, а также за распространение незаконной информации. В случае нарушения условий Яндекс имеет право не использовать данные сайта для изменения представления ответа в поисковой выдаче. См. [подробные условия](https://yandex.ru/legal/search_partner_integration_conditions).

Положение ответа в поисковой выдаче определяется общими принципами ранжирования: более высокие позиции получают страницы, наиболее релевантные запросу. Порядок карточек внутри ответа определяется с учетом данных о взаимодействии пользователей с карточками для максимизации конверсии и профицита.

Мы стремимся показывать в результатах поиска информацию, которая будет полезна конкретному пользователю. Чтобы при ранжировании предложений внутри описанных на этой странице ответов учитывать данные о конверсиях, рекомендуем установить на вашем сервисе [Яндекс Метрику](https://metrika.yandex.ru). Это позволит сделать персонализацию результатов поиска более эффективной.

[Подробнее о событиях в Яндекс Метрике](https://yandex.ru/support/webmaster/ru/feed/goals#events).
