# Определение телефонных номеров

> Source: https://yandex.ru/support/webmaster/ru/search-appearance/callerid

## Для каких сервисов

Сервисы, которые дают возможность пользователям получить дополнительную информацию о номерах телефонов, с которых пользователям сервиса поступали звонки или на которые пользователи звонили самостоятельно.

## Что добавляет в результаты поиска

Содержит ответ с дополнительной информацией о номере телефона, например название организации. Позволяет перейти к детальной информации о номере телефона на сервисе партнера.

Предложения от партнеров внутри ответа отображаются в случайном порядке. В момент отображения ответа не может быть показано больше 3 предложений партнеров.

## Как настроить

> **Важно**
> Если вас не устраивает информация в ответе, воспользуйтесь [формой обратной связи](https://yandex.ru/support2/yandex-app-android/ru/troubleshooting/callerid-form).

Чтобы ваша информация попадала в такие ответы, отправьте заявку на подключение на [partner-features-planned@yandex-team.ru](mailto:partner-features-planned@yandex-team.ru) и укажите в ней:

- название сервиса;
- название вашей компании;
- ваши фамилию, имя, email и телефон;
- ссылку на публичную документацию сервиса с указанием обязательной информации.

Дождитесь ответа менеджера, затем настройте API согласно спецификации, которую получите от менеджера.

## Условия

Сервис несет ответственность за корректность предоставленных данных, их соответствие тематике, а также за распространение незаконной информации. В случае нарушения условий, Яндекс имеет право не использовать данные сервиса для изменения представления ответа в поисковой выдаче. Подробнее читайте в [Условиях подключения](https://yandex.ru/legal/search_partner_integration_conditions/).

Данные о номере телефона, которые предоставляет сервис, должны быть основаны на достоверно верифицируемых входящих или исходящих вызовах пользователей по указанному номеру. Также должна быть возможность включения дополнительной информации, полученной в рамках проверок поведенческих факторов каждого номера телефона.

Сервис партнера, на который пользователь переходит по ссылке для просмотра детальной информации о номере телефона, должен показывать для каждого конкретного номера телефона минимальный набор обязательных данных:

- номер телефона в международном формате;
- данные о вердикте (отзыве) о номере телефона со стороны сервиса (может включать, например, название организации);
- название оператора связи, которому принадлежит номер телефона;
- ссылка для просмотра детальной информации о номере телефона на сервисе партнера (должна быть уникальной для каждого номера телефона).

> **Примечание**
> Вердикт (отзыв) о номере телефона не должен содержать в себе персональных данных физических лиц.

В публичной документации сервиса должна быть отображена информация:

- о сборе и порядке обработки данных, на основе которых выносится вердикт (отзыв) о номере телефона;
- о порядке установки и настройки сервиса;
- о порядке оставления отзывов пользователями о номере телефона;
- о возможности обращения владельцев номеров телефона за изменением и уточнением вердикта (отзыва) о номере телефона в сервисе (с указанием контактов для обращения).
