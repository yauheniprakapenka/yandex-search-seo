# Рекомендации событий β

> Source: https://yandex.ru/support/webmaster/ru/search-appearance/activities

> **Важно**
> Дополненное отображение рекомендованных событий закрылось 16 июня 2025 года.

## Для каких сайтов

Для сайтов, продающих билеты на развлекательные услуги: сайты, которые продают билеты на собственные события, и сайты-агрегаторы с возможностью покупки билетов на сервисе.

## Что добавляет в результаты поиска

Ответ с информацией о рекомендуемых пользователю местах и событиях, включая дату и время проведения.

## Как настроить

Чтобы ваши предложения попадали в такие ответы, необходимо передавать Яндексу актуальную информацию о них. Для этого нужно подготовить и разместить на своем сайте фид в формате YML и передать ссылку на него в Вебмастере. [Стандарт YML](https://yandex.ru/support/partnermarket/export/yml.html) разработан Яндексом и основан на стандарте XML.

Названия элементов `shop` и `offer` нужны для обратной совместимости с YML-фидами и не несут дополнительной смысловой нагрузки.

### Ограничения для фида

| Параметр | Ограничение |
| --- | --- |
| Размер YML-файла | 200 МБ |
| Общее количество изображений | 50 000 |
| Количество изображений в одном элементе `offer` | 200 |
| Количество элементов `offer` | 30 000. Данные из фида, который содержит больше предложений, для дополнительного представления использованы не будут. Сам фид загрузится с ошибкой. Чтобы предложения участвовали в поиске, разбейте фид на несколько частей. |
| Количество элементов `set` | 1 млн |
| Количество всех YML-файлов (товарные фоды, фиды услуг и предложений, RSS для контентных Турбо-страниц) суммарно для сайта и его поддоменов | 1000 |

> Не дублируйте предложения с одним и тем же URL-адресом в нескольких фидах, а также не переносите предложения из одного фида в другой — данные из перенесенного предложения могут временно пропасть из поиска.

### Формат фида

#### Описание shop — информация об источнике

| Элемент | Тип | Описание | Обязательно |
| --- | --- | --- | --- |
| `name` | String | Название источника. Отображается в списке цен и в подписи описания события. | Да |
| `url` | String | Ссылка на сайт источника. Домен должен совпадать с доменом события (`offer`). | Да |
| `picture` | String | Ссылка на логотип источника. Отображается рядом с именем источника в списке цен. Рекомендуемый размер — 32 × 32 пикселей, рекомендуемый формат — PNG. Размер влияет на качество отображения в поиске. | Да |
| `categories` | List\[String\] | Список категорий в фиде. Категория — это общее описание события, формат его проведения. Примерами категории могут быть: `Кино`, `Спектакль`, `Концерт`, `Мастер-класс`. Категория определяет раздел, в который попадет событие, и влияет на качество рекомендаций. Для события может быть только одна категория. С помощью тегов можно дать более точную характеристику события. Можно взять категории и их `categoryId` из примера фида. Категории, для которых отсутствуют события в вашем фиде, добавлять не надо. | Да |

#### Описание offer — информация о событии (предложении)

Предложение — это отдельный элемент расписания. Он должен содержать информацию о событии, о месте и времени проведения. Если это длительное событие, например, выставка, то достаточно указать время окончания события: `param name="end_date"`. Если событие неоднократное, то следует создать несколько предложений с одинаковым `param name="event_id"` и другими полями, но с отличающимся расписанием.

| Элемент | Тип | Описание | Обязательно |
| --- | --- | --- | --- |
| `categoryId` | Int | Идентификатор категории события. Берется из списка `categories` в описании `shop`. Используется для категоризации, фильтрации и релевантных рекомендаций событий. | Да |
| `currencyId` | String | Символьный код валюты в формате [ISO 4217](https://en.wikipedia.org/wiki/ISO_4217). Например: USD, RUB, EUR. | Да |
| `price` | Float | Минимальная цена билетов на событие. Если вход бесплатный, укажите 0 и в значение `param name="is_free"` укажите `true`. Если указан только 0, цена считается неопределенной. | Да |
| `name` | String | Название события на русском языке. Отображается в превью события и в подробной информации. | Да |
| `description` | String | Полное описание события с HTML-разметкой. Отображается в подробной информации о событии. | Да |
| `url` | String | Ссылка на страницу события. | Да |
| `picture` | String | Ссылки на оригинальные изображения события. | Да |
| `param name="short_name"` | String | Короткое название события на русском языке. Отображается на превью события в поиске. | Нет |
| `param name="short_description"` | String | Короткое описание события с HTML-разметкой. Пока не используется. | Нет |
| `param name="event_id"` | String | Уникальный идентификатор события. Используется для построения рекомендаций. | Да |
| `param name="tags"` | String | Список тегов события, разделенных точкой с запятой, например: `мелодрама;комедия`. Используется для фильтрации событий и построения персональных рекомендаций. Теги влияют на качество рекомендаций. | Нет |
| `param name="participants"` | String | Список участников события в формате: `Имя участника 1,Роль участника 1;Имя участника 2,Роль участника 2`. | Нет |
| `param name="age_restriction"` | String | Возрастное ограничение. Возможные значения: `0+`, `6+`, `12+`, `16+`, `18+`. | Да |
| `param name="videos"` | String | Список ссылок на видео о событии. Первое видео используется в качестве превью в карточке события. | Нет |
| `param name="is_free"` | Boolean | Признак бесплатного события. Значение по умолчанию — `false`. | Нет |
| `param name="is_online"` | Boolean | Признак онлайн-события. | Нет |
| `param name="has_tickets"` | Boolean | Доступна ли покупка билетов на данное событие. Если вход свободный, укажите `true`. Значение по умолчанию — `true`. | Нет |
| `param name="place_name"` | String | Название места проведения. | Да |
| `param name="place_address"` | String | Полный адрес места проведения: населенный пункт, улица, дом. | Да |
| `param name="place_city"` | String | Город места проведения. | Да |
| `param name="place_country_code"` | String | Код страны места проведения в формате [ISO-3166 alpha-2](https://en.wikipedia.org/wiki/ISO_3166-1_alpha-2). Сейчас поддерживается только регион RU. | Да |
| `param name="place_lon"` | Float | Долгота места проведения. | Нет |
| `param name="place_lat"` | Float | Широта места проведения. | Нет |
| `param name="place_timezone"` | String | Временная зона места проведения в формате [IANA](https://en.wikipedia.org/wiki/IANA). | Да |
| `param name="place_phones"` | String | Список телефонов организаторов события. | Нет |
| `param name="place_urls"` | String | Список ссылок на сайты места проведения. | Нет |
| `param name="start_date"` | String | Дата начала события по местному времени, в формате `YYYY-MM-DD` ([ISO-8601](https://en.wikipedia.org/wiki/ISO_8601)). | Нет (только при условии заданного `end_date`) |
| `param name="start_time"` | String | Время начала события по местному времени, в формате `HH:MM:SS` ([ISO-8601](https://en.wikipedia.org/wiki/ISO_8601)). | Нет |
| `param name="duration_min"` | Int | Длительность события в минутах. | Нет |
| `param name="end_date"` | String | Дата конца события по местному времени, в формате `YYYY-MM-DD` ([ISO-8601](https://en.wikipedia.org/wiki/ISO_8601)). Важно для корректной фильтрации продолжительных событий, например выставок. | Нет (только при условии заданного `start_date`) |
| `param name="end_time"` | String | Время конца события по местному времени, в формате `HH:MM:SS`. | Нет |
| `param name="prices"` | Float | Список цен билетов на это время в этом месте. Список целых чисел, разделённых точкой с запятой, например: `100;200;300`. | Нет |
| `param name="offer_url"` | String | Ссылка для покупки билетов на событие. Если поле не задано, то используется ссылка на страницу события (`url`). | Нет |

### Как передать фид

**В Вебмастере:**

1. Авторизуйтесь на Яндексе. [Добавьте сайт](https://yandex.ru/support/webmaster/ru/service/quick-start) в Яндекс Вебмастер и [подтвердите права](https://yandex.ru/support/webmaster/ru/service/rights#how-to) на управление или [получите доступ](https://yandex.ru/support/webmaster/ru/service/rights-management#delegation) для вашего аккаунта у пользователя с ролью **Владелец**.
2. Перейдите на страницу **Услуги и предложения в поиске** → **Фиды и ошибки**.
3. Нажмите **Загрузить фид**.
4. Выберите категорию бизнеса **Чем заняться**.
5. Укажите регион. Например, если предложения в фиде доступны на одинаковых условиях во всех регионах, выберите **Россия**.
6. В поле **Ссылка на файл с предложениями** укажите URL вида `https://example.com/feed.yml`.

   > Если на вашем сайте настроена авторизация для доступа к YML-файлу, вы можете передавать логин и пароль вместе с URL, по которому он доступен. Например: `http://yandex:WE9h4FfBml@example.com/feed.yml`.

7. Нажмите **Готово**.

**С помощью API Вебмастера:**

Подробно см. [документацию](https://yandex.ru/dev/webmaster/doc/dg/concepts/feeds.html).

Яндекс Вебмастер проверит фид. Если он содержит ошибки, в Вебмастере на странице **Услуги и предложения в поиске** → **Фиды и ошибки** рядом с фидом появится сообщение об ошибках. Чтобы открыть их, нажмите **Посмотреть**. Исправьте ошибки — в течение некоторого времени Вебмастер проверит фид снова.
