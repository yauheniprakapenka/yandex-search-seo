# Исполнители

> Source: https://yandex.ru/support/webmaster/ru/search-appearance/services

## Для каких сайтов

Информационные сайты, на которых размещаются предложения услуг от исполнителей.

## Что добавляется в результаты поиска

Содержит предложения от исполнителей. Для каждого предложения указана цена, а также рейтинг и количество отзывов у исполнителя. Такой ответ помогает пользователю увидеть самую важную информацию о мастерах, сравнить их между собой и выбрать того, который наиболее подходит для решения задачи.

Список формируется с учетом расположения, цен, отзывов и других факторов.

Пример отображения (дизайн может меняться).

## Как настроить

Чтобы ваши предложения попадали в такие ответы, необходимо передать Яндексу информацию о них. Для этого нужно подготовить фид в формате [YML](https://yandex.ru/support/webmaster/ru/feed/upload). Стандарт YML разработан Яндексом и основан на стандарте XML. Фид — это файл, в котором вы передаете информацию о своих предложениях. В нем описываются предложения (`offers`), объединенные в специальные наборы — сеты (`sets`).

Сет отличается от другого обязательного элемента фида — [категории](https://yandex.ru/support/partnermarket/elements/categories.html) (`category`). Категория может быть только одна. Сетов может быть больше одного, так как одно и то же предложение может принадлежать разным сетам. Сеты, к которым принадлежит предложение, перечисляются через запятую.

В поисковой выдаче будет дополняться сниппет, URL которого совпадает с URL, заданным в сете. Сниппет дополняется информацией из предложений, которые входят в сет. Формат предложения должен соответствовать определенным [требованиям](https://yandex.ru/support/partnermarket/offers.html). Вся дополнительная информация о предложении указывается в элементе [param](https://yandex.ru/support/partnermarket/elements/param.html) — универсальном элементе с текстовым контентом.

Ограничения для фида:

| Параметр | Ограничение |
| --- | --- |
| Размер YML-файла | 200 МБ |
| Общее количество изображений | 50 000 |
| Количество изображений в одном элементе `offer` | 200 |
| Количество элементов `offer` | 30 000. Данные из фида, который содержит больше предложений, для дополнительного представления использованы не будут. Сам фид загрузится с ошибкой. Чтобы предложения участвовали в поиске, разбейте фид на несколько частей. |
| Количество элементов `set` | 1 млн |
| Количество всех YML-файлов (товарные фиды, фиды услуг и предложений, RSS для контентных Турбо-страниц) суммарно для сайта и его поддоменов | 1000 |

Не дублируйте предложения с одним и тем же URL-адресом в нескольких фидах, а также не переносите предложения из одного фида в другой — данные из перенесенного предложения могут временно пропасть из поиска.

> Совет: Не обязательно формировать файл для всего контента и включать все предложения. Достаточно сформировать его для тех сетов (URL), которые необходимо дополнить в результатах поиска.

**Требования к фиду**

Фид содержит предложения с информацией о конкретных услугах от конкретного исполнителя. Например, сет «Ремонт и строительство в Москве» содержит предложения «Бестмастер» и «ИП Иванов».

[Пример фида](https://edu.s3.yandex.net/sample/services.yml).

Минимальный набор элементов **предложения** (обязательные отмечены звездочкой):

| Элемент | Примечание |
| --- | --- |
| `name` * | Имя исполнителя, название организации или ИП. |
| `url` * | URL-адрес предложения. Должен быть уникальным среди всех предложений в пределах всех фидов одного и того же региона. Метки (например, UTM, Openstat, from) не делают URL уникальным. |
| `price` * | Стоимость. С помощью атрибута `from="true"` можно указать, что задана минимальная оплата. |
| `currencyId` * | Идентификатор валюты. Например, `RUR` для рублей. |
| `categoryId` * | Идентификатор категории. |
| `set-ids` * | Идентификаторы сетов. Можно перечислить несколько сетов через запятую, например: `s1,s2,s3`. |
| `picture` * | Ссылка на логотип или фотографию исполнителя. Ссылки не должны повторяться в предложениях, однако вы можете загрузить идентичную фотографию по другой ссылке. |
| `description` * | Название услуги, профессия исполнителя и пр. |
| `param name="Рейтинг"` * | Число. Для нового исполнителя или при отсутствии рейтинга указывайте `0`. |
| `param name="Число отзывов"` * | Число. |
| `param name="Годы опыта"` * | Число. |
| `param name="Регион"` * | Строка. Можно указать страну, область, город, район города, станцию метро. |
| `param name="Конверсия"` * | Число. Произвольное значение. Чем больше, тем лучше предложение. |
| `param name="Ссылка на телефон"` | Строка. |
| `param name="Ссылка на чат"` | Строка. |
| `param name="Ссылка на создание заказа"` | Строка. Если она не совпадает с URL-адресом предложения. |
| `param name="Ссылка на профиль исполнителя"` | Строка. |
| `sales_notes` | Заметки. Например: «Цена договорная», «Цена за метр». |
| `expiry` | Срок гарантии. Подробнее см. [Список и описание элементов](https://yandex.ru/support/partnermarket/offers.html#offers__list). |
| `param name="Исполнитель проверен"` | `true` или `false` (по умолчанию). |
| `param name="Организация"` | `true` или `false` (по умолчанию). |
| `param name="Выполняется удаленно"` | `true` или `false` (по умолчанию). |
| `param name="Выполняется по адресу исполнителя"` | `true` или `false` (по умолчанию). |
| `param name="Выполняется по адресу заказчика"` | `true` или `false` (по умолчанию). |
| `param name="Бригада"` | `true` или `false` (по умолчанию). |
| `param name="Об исполнителе"` | Строка. |
| `param name="Отзыв на исполнителя - X"` | Строка. X — номер отзыва (от 1 до 5). С помощью атрибута `unit` можно указать оценку отзыва, например, `unit="4.9"`. |
| `param name="Другая услуга исполнителя - X"` | Строка. X — номер услуги (от 1 до 5). |

Вы можете создавать собственные необязательные элементы `param`. Часть информации из этих элементов может не отображаться в текущих форматах обогащения выдачи. Но эта информация будет учитываться в будущем при ранжировании предложений в сете и может появиться в новых форматах обогащения выдачи.

Особенности фида: имена исполнителей в одном сете не должны повторяться (значение параметра `name`).

**Как передать фид**

Загрузить фид можно в Вебмастере или с помощью API Вебмастера.

В Вебмастере:

Авторизуйтесь на Яндексе. [Добавьте сайт](https://yandex.ru/support/webmaster/ru/service/quick-start) в Яндекс Вебмастер и [подтвердите права](https://yandex.ru/support/webmaster/ru/service/rights#how-to) на управление или [получите доступ](https://yandex.ru/support/webmaster/ru/service/rights-management#delegation) для вашего аккаунта у пользователя с ролью **Владелец**.

1. Перейдите на страницу **Услуги и предложения в поиске** → **Фиды и ошибки**.
2. Нажмите **Загрузить фид**.
3. Выберите категорию бизнеса **Исполнители**, если вы передаете информацию об исполнителях бытовых и других услуг. Например, перевозка мебели.
4. Укажите регион. Например, если предложения в фиде доступны на одинаковых условиях во всех регионах, выберите **Россия**.
5. В поле **Ссылка на файл с предложениями** укажите URL вида `https://example.com/feed.yml`.

   Если на вашем сайте настроена авторизация для доступа к YML-файлу, вы можете передавать логин и пароль вместе с URL, по которому он доступен. Например: `http://yandex:WE9h4FfBml@example.com/feed.yml`.

6. Нажмите **Готово**.

Подробно см. [документацию](https://yandex.ru/dev/webmaster/doc/dg/concepts/feeds.html).

Яндекс Вебмастер проверит фид. Если он содержит ошибки, в сервисе на странице **Услуги и предложения в поиске** → **Фиды и ошибки** появится сообщение об ошибках. Чтобы узнать подробности, нажмите напротив фида **Ошибки**.

Исправьте ошибки — в течение некоторого времени Яндекс Вебмастер проверит фид снова.

Также информация о сайте и предложениях будет [проверена службой контроля качества](https://yandex.ru/support/webmaster/ru/feed/executors) в течение нескольких дней. Фид может быть отклонен за [нарушение правил](https://yandex.ru/support/webmaster/ru/feed/executors).

## Условия

Сайт несет ответственность за корректность данных, соответствие предложений тематике, а также за распространение незаконной информации. В случае нарушения условий Яндекс имеет право не использовать данные сайта для изменения представления ответа в поисковой выдаче. См. [подробные условия](https://yandex.ru/legal/search_partner_integration_conditions).

Данные из фида могут обогащать органический результат вашего сервиса в поиске, когда это увеличивает [профицит](https://yandex.ru/support/webmaster/ru/search-quality) (метрику полезности для пользователя) поисковой выдачи.

Такое обогащение предоставляется только для страниц подходящего формата: содержащих список объектов.

Положение ответа в поисковой выдаче определяется общими принципами ранжирования: более высокие позиции получают страницы, наиболее релевантные запросу. Порядок карточек внутри ответа определяется с учетом данных о взаимодействии пользователей с карточками для максимизации конверсии и профицита.

Мы стремимся показывать в результатах поиска информацию, которая будет полезна конкретному пользователю. Чтобы при ранжировании предложений внутри описанных на этой странице ответов учитывать данные о конверсиях, рекомендуем установить на вашем сервисе [Яндекс Метрику](https://metrika.yandex.ru). Это позволит сделать персонализацию результатов поиска более эффективной.

[Подробнее о событиях в Яндекс Метрике](https://yandex.ru/support/webmaster/ru/feed/goals#events).
