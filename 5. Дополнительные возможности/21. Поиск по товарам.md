# Поиск по товарам

> Source: https://yandex.ru/support/webmaster/ru/search-appearance/popular-products

## Для каких сайтов

Интернет-магазины и маркетплейсы.

## Что добавляет в результаты поиска

Содержит список из предложений товаров, которые подходят под запрос пользователя. Список формируется автоматически на основе обработки данных поискового робота или переданных фидов. Подробнее см. в Справке [Яндекс Товаров](https://yandex.ru/support2/merchants/ru/connect/form-feed).

## Как настроить

Такие ответы формируются автоматически на основе обработки данных поискового робота. Также есть возможность передать актуальные данные в Яндекс в структурированном виде, для этого используются фиды — специальные файлы с информацией о товарах (при формировании ответа в числе прочего используются данные фидов, которые Яндекс получил от партнеров при использовании иных сервисов, например Яндекс Директа).

Вы можете передать Яндексу структурированную информацию о товарах с помощью фида в формате [YML](https://yandex.ru/support2/merchants/ru/connect/form-feed).

### Как создать фид

Генерацию YML-фида поддерживают основные системы управления сайтами (CMS).

Чтобы подключить интернет-магазин к сервисам и технологиям Яндекса, сгенерируйте ссылку на данные о товарах в формате YML с помощью плагина для вашего сайта. Обычно плагины размещаются в каталоге CMS.

> **Примечание**
> Если вы не можете настроить генерацию самостоятельно, обратитесь к сотруднику, который отвечает за поддержку вашего сайта.

- **Используйте готовый плагин для вашего сайта** — [посмотрите список плагинов](https://yandex.ru/support/products/connect/form-feed.html#form-feed__step1).
- **Создайте YML-фид вручную** — этот вариант подходит для разработчиков. Как создать YML-фид см. в Справке [Яндекс Товаров](https://yandex.ru/support2/merchants/ru/connect/form-feed).

### Как передать фид

Передать фид можно двумя способами:

**В Яндекс Товарах**

1. Перейдите в [личный кабинет](https://merchants.yandex.ru/analytics) Яндекс Товаров на страницу **Товарные фиды**.
2. На вкладке **Список фидов** нажмите **Добавить** → **Указать ссылку на файл**.
3. В поле **Название фида** отредактируйте название фида. По умолчанию в поле устанавливается название в формате `Фид от <чч.мм.гггг>`.
4. Нажмите на поле **Регионы продажи** и выберите из выпадающего списка регионы продажи.
   - Чтобы посмотреть регионы, из которых состоит регион, нажмите на значок раскрытия.
   - Чтобы выбрать все регионы, нажмите **Выбрать все**.
   - Чтобы удалить выбранный регион:
     - в поле **Регионы продажи** справа от его названия нажмите на значок удаления;
     - в выпадающем списке отмените выбор региона.
5. В поле **Ссылка на фид** укажите ссылку на фид. Например: `https://example.com/feed.yml`.

   > **Если на вашем сайте настроена авторизация для доступа к товарному фиду:**
   > 1. Включите опцию **Доступ защищен паролем**.
   > 2. Укажите логин и пароль.

6. Нажмите **Добавить**.

**С помощью API Вебмастера**

Подробно см. [документацию](https://yandex.dev/webmaster/doc/ru/concepts/feeds).

Фид будет проверен Яндекс Товарами. Если он содержит ошибки, в [личном кабинете](https://merchants.yandex.ru/analytics) Яндекс Товаров на странице **Товарные фиды** изменится статус фида. Чтобы ознакомиться с ошибками, нажмите на строчку с фидом и перейдите на вкладку **Ошибки и рекомендации**. Исправьте ошибки — в течение пяти дней сервис проверит фид и обновит его статус.

Также информацию о сайте и предложениях в течение пяти дней проверит служба качества. Фид может быть отклонен за нарушение правил. Чтобы ознакомиться с ошибками, нажмите на строчку с фидом и перейдите на вкладку **Ошибки и рекомендации**. Исправьте ошибки и нажмите **Перепроверить**.

В случае нарушения условий Яндекс имеет право не использовать данные сайта для изменения представления ответа в поисковой выдаче. См. [подробные условия](https://yandex.ru/legal/search_partner_integration_conditions).

Мы стремимся показывать в результатах поиска информацию, которая будет полезна конкретному пользователю. Чтобы при ранжировании предложений внутри описанных на этой странице ответов учитывать данные о конверсиях, рекомендуем установить на вашем сервисе [Яндекс Метрику](https://metrika.yandex.ru). Это позволит сделать персонализацию результатов поиска более эффективной.
