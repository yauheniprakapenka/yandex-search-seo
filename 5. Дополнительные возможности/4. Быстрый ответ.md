## Для каких сайтов

Интернет-энциклопедии, научно-популярные и тематические сайты, сайты вопросов и ответов.

## Что добавляет в результаты поиска

Содержит краткий информативный ответ на запрос пользователя.

Быстрые ответы бывают разных форматов: текст, иллюстрация, номер телефона и т. п., а также их группировка. Обычно такие ответы располагаются над результатами поиска или рядом с поисковыми результатами. Также они могут отображаться в виде связанных вопросов по теме. В этом случае быстрые ответы располагаются среди результатов поиска.

Задача быстрых ответов — увеличивать [профицит](https://yandex.ru/support/webmaster/ru/search-quality) (метрику полезности для пользователя) поисковой выдачи.

Ответы содержат активную ссылку на сайт-источник. Пользователь может перейти по ссылке, чтобы получить более подробную информацию.

Быстрые ответы формируются с помощью различных алгоритмов Яндекса.

## Быстрый ответ с YandexGPT

Часть быстрых ответов генерируется с помощью языковой модели YandexGPT. YandexGPT в режиме реального времени находит несколько самых подходящих источников по запросу пользователя. Затем нейросеть обобщает сведения в каждом из них, в том числе, если нужный для ответа текст находится в разных частях страницы. После этого YandexGPT выбирает из получившихся вариантов наиболее полезный ответ.

Такие быстрые ответы генерируются только для РФ.

Если вы не хотите, чтобы информация с вашего сайта попадала в быстрые ответы с YandexGPT, добавьте для YandexAdditional или YandexAdditionalBot запрет в файл [robots.txt](https://yandex.ru/support/webmaster/ru/controlling-robot/robots-txt).

Пример:

```
User-agent: YandexAdditionalBot
Disallow: /cats/mycat.html # ограничивает отображение контента страницы в быстрых ответах с YandexGPT
```

Изменение будет учтено по мере обновления поисковых данных, в течение 2–14 дней.

## Как настроить

Быстрые ответы формируются автоматически из страниц, которые проиндексированы Яндексом.

Вероятность того, что веб-страница попадет в быстрый ответ, повышается, если информация на ней тщательно структурирована, качественно и грамотно изложена.
