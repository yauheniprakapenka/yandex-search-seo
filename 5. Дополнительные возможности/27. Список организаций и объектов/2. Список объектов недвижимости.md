# Список объектов недвижимости

> Source: https://yandex.ru/support/webmaster/ru/search-appearance/object

Сайты с объявлениями о продаже или аренде объектов недвижимости могут передавать Яндексу информацию о своих объектах в формате XML-фида.

## Что такое XML-фид

Объявления о продаже или аренде объектов недвижимости появляются в Поиске после индексирования сайтов. Чтобы ускорить или уточнить индексирование, вы можете создать XML-фид с данными об объектах и передать его Яндексу.

## Как добавить XML-фид

Чтобы добавить фид, заполните форму и добавьте ссылку на фид, который отвечает [требованиям](#req).

## Требования к XML-фиду

### Заголовок документа

XML-документ должен начинаться со стандартного XML-заголовка с нулевого символа первой строки.

```xml
<?xml version="1.0" encoding="UTF-8"?>
```

### Корневой элемент

Корневой элемент XML-фида должен содержать элемент `generation-date` с датой создания фида и элементы `offer`, в каждом из которых должна находиться информация из одного объявления.

Чтобы указать пространство имен в XML, используйте атрибут `xmlns="http://webmaster.yandex.ru/schemas/feed/metarealty/2026-03"`.

```xml
<supplementing-metarealty-feed xmlns="http://webmaster.yandex.ru/schemas/feed/metarealty/2026-03">
  <generation-date>2010-10-05T16:36:00+04:00</generation-date>
  <offer internal-id="example">
  ...
  </offer>
  ...
</supplementing-metarealty-feed>
```

### Формат даты

Все даты и время следует указывать согласно стандарту [ISO 8601](https://ru.wikipedia.org/wiki/ISO_8601). В общем случае — в формате `YYYY-MM-DDTHH:mm:ss+00:00`, где:

- `YYYY` — год;
- `MM` — месяц;
- `DD` — день;
- `HH` — час;
- `mm` — минута;
- `ss` — секунда;
- `+00:00` — указание часового пояса (для Москвы — `+03:00`).

### Элементы фида

#### Общая информация об объявлении

У элемента `offer` есть обязательный атрибут `internal-id`, который должен быть уникальным для каждого объявления. Первым дочерним элементом внутри `offer` обязательно должен быть `url`.

```xml
<offer internal-id="А1245">
  <url>https://example.com/12345</url>
  ...
</offer>
```

| Элемент | Обязательный | Описание |
| --- | --- | --- |
| `url` | Да | URL страницы с объявлением. Должен быть первым элементом внутри `offer`. |
| `type` | Да | Тип сделки: «продажа», «аренда». |
| `category` | Да | Категория объекта: «дача»/«коттедж», «дом», «дом с участком», «участок», «часть дома», «квартира»/«flat», «комната»/«room», «гараж»/«garage». |
| `garagetype` | Нет | Категория гаража (обязательный для гаражей): «гараж», «машиноместо», «бокс». |
| `location` | Да | Расположение объекта. Вложенные элементы: `address`, `latitude`, `longitude`, `apartment`. |
| `address` | Да | Адрес объекта — улица и номер здания. Внутри `location`. |
| `apartment` | Нет | Номер квартиры. Внутри `location`. |
| `latitude` | Нет | Географическая широта. Внутри `location`. |
| `longitude` | Нет | Географическая долгота. Внутри `location`. |

3. Сайт несет ответственность за корректность данных, соответствие предложений тематике, а также за распространение незаконной информации. В случае нарушения условий Яндекс имеет право не использовать данные сайта для изменения представления ответа в поисковой выдаче. См. [подробные условия](https://yandex.ru/legal/search_partner_integration_conditions).
4. Работа интернет-сервиса, предложения, должны соответствовать законам и нормативным актам, принятым в России.
