# Инвестиции

> Source: https://yandex.ru/support/webmaster/ru/search-appearance/quotations

## Для каких сайтов

Поставщики финансовых данных — биржи, информационные агентства, аналитические платформы и брокерские сервисы, предоставляющие котировки акций и прогнозы доходности.

## Что добавляет в результаты поиска

Содержит информацию об акциях. Из такого ответа пользователь в наглядной форме получает сведения о динамике стоимости ценной бумаги. Нажав кнопку в таком ответе, можно перейти на сайт партнера, чтобы купить ценную бумагу или получить о ней более подробную информацию. Предложения от партнеров внутри ответа отображаются в случайном порядке.

Пример отображения (дизайн может меняться):

- Котировки акций
- Прогнозы цен на акции

## Котировки акций

### Как настроить

Для представления от брокерской организации актуальной информации партнеру необходимо подготовить файл, который будет содержать данные о ценных бумагах в JSON-формате.

- Один партнер может предоставить только один файл.
- После публикации файла вы можете вносить в него изменения. Следите за актуальностью данных и регулярно обновляйте файл. Яндекс будет регулярно обходить файл и обновлять информацию в ответе.

**Передача данных в Яндекс**

Подготовьте файл и передайте ссылку на него в Яндекс через форму внизу страницы.

Чтобы ваш файл был обработан корректно, он должен соответствовать требованиям:

- Файл должен соответствовать формату JSON.
- Файл должен быть доступен по протоколу HTTPS на домене брокера. Пример ссылки на файл: `https://yoursite.ru/feed.json`.
- Если для доступа к файлу используется авторизация, укажите логин и пароль при передаче ссылки на файл.

**Формат данных**

Файл должен содержать название сервиса, ссылку на главную страницу и описание контента. Количество единиц контента в одном файле не ограничено.

```json
{
  "serviceName": "Брокер N",
  "url": "https://yoursite.ru",
  "logo_url": "https://yoursite.ru/logo",
  "items": [{
    ...
    объекты, описывающие ценные бумаги
    ...
  }]
}
```

Описание параметров:

| Ключ | Значение | Тип данных | Обязательный при создании |
| --- | --- | --- | --- |
| `serviceName` | Название сервиса на русском или английском языке. Это имя будет отображаться в дополненном представлении в Поиске. | Строка | Да |
| `url` | Ссылка на главную страницу сайта. | Строка | Да |
| `logo_url` | Логотип компании. | Строка | Да |
| `items` | Массив данных о ценных бумагах. | Массив JSON-объектов | Да |

Данные (`items`):

```json
{
    "ticker": "YNDX",
    "isin": "NL0009805522",
    "display_name": "Яндекс",
    "logo_url": "//...url",
    "url": "//...url",
    "currency_code": "RUB",
    "exchange": "MOEX",
    "type": "STOCK",
    "price": "5901.92",
    "price_delta_relative": "-15",
    "price_delta_absolute": "-0.25301",
    "update_ts": "1637068580",
    "candles": {
      "allTime": [{"ts": "", "value": ""}],
      "year": [{"ts": "", "value": ""}],
      "month": [{"ts": "", "value": ""}],
      "week": [{"ts": "", "value": ""}],
      "day": [{"ts": "", "value": ""}]
    },
    "about": [
      {
        "author": "MyAuthorName",
        "avatar_url": "//...url",
        "post_url": "//...url",
        "timestamp": 1636097657,
        "text": "информация об акциях $YNDX ..."
      }
    ]
}
```

| Ключ | Значение | Тип данных | Обязательный при создании |
| --- | --- | --- | --- |
| `ticker` | Тикер ценной бумаги | Строка | Да |
| `isin` | Международный идентификатор ценной бумаги (International Securities Identification Number) | Строка | Да |
| `display_name` | Отображаемое имя эмитента | Строка | Да |
| `logo_url` | Ссылка на картинку | Строка | Да |
| `url` | Ссылка на бумагу на сервисе | Строка | Да |
| `currency_code` | В какой валюте торгуется бумага (USD, RUB, ...) | Строка | Да |
| `exchange` | Биржа (MOEX, SPBEX, ...) | Строка | Да |
| `type` | Тип ценной бумаги (сейчас поддерживаются только акции — STOCK) | Строка | Да |
| `price_delta_relative` | Изменение цены относительное (относительно прошлого дня) | Строка | Да |
| `price_delta_absolute` | Изменение цены абсолютное (относительно прошлого дня) | Строка | Да |
| `update_ts` | Время, в которое зафиксирована цена | Строка | Да |
| `candles` | Данные о свечах | JSON-объект | Да |
| `candles.allTime` | Дневные свечи за все время | Массив JSON-объектов — `candle` | Да |
| `candles.year` | Дневные свечи за последний год | Массив JSON-объектов — `candle` | Да |
| `candles.month` | Дневные свечи за последний месяц | Массив JSON-объектов — `candle` | Да |
| `candles.week` | Часовые свечи за последнюю неделю | Массив JSON-объектов — `candle` | Да |
| `candles.day` | 5-минутные свечи за последний день | Массив JSON-объектов — `candle` | Да |
| `about` | Новости про данную ценную бумагу | Массив JSON-объектов — `related_info` | Нет |

**Свеча** (`candle`):

```json
{
  "ts": "1636097657",
  "value": "123.45"
}
```

| Ключ | Значение | Тип данных | Обязательный при создании |
| --- | --- | --- | --- |
| `ts` | Timestamp свечи | Строка | Да |
| `value` | Цена | Строка | Да |

**Связанная информация** (`related_info`):

```json
{
  "author": "MyAuthorName",
  "avatar_url": "//...url",
  "post_url": "//...url",
  "timestamp": 1636097657,
  "text": "информация об акциях $YNDX ..."
}
```

| Ключ | Значение | Тип данных | Обязательный при создании |
| --- | --- | --- | --- |
| `author` | Имя автора | Строка | Да |
| `avatar_url` | Ссылка на картинку | Строка | Нет |
| `post_url` | Ссылка на пост | Строка | Да |
| `timestamp` | Timestamp поста (в секундах) | Целое число | Да |
| `text` | Содержимое поста (не более 200 символов) | Строка | Да |

## Прогнозы цен на акции

### Как настроить

Информация о прогнозах цен на акции передается в фиде формата [YML](https://yandex.ru/support2/merchants/ru/connect/form-feed). Стандарт YML разработан Яндексом и основан на стандарте XML.

Фид с прогнозами должен содержать актуальную информацию о рекомендациях аналитиков по ценным бумагам, включая цели, рекомендации, сроки действия и дополнительную аналитическую информацию.

Пример фида:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<stock_recommendations version="1.0">
 <updated_at>2024-11-15T10:00:00Z</updated_at>
 <analyst>Инвестиционная аналитическая компания</analyst>
 <recommendation>
   <ticker>SBER</ticker>
   <company_name>Сбербанк России Публичное акционерное общество</company_name>
   <recommendation>BUY</recommendation>
   <target_price>245.50</target_price>
   <date>2024-11-15</date>
   <valid_until>2025-02-15</valid_until>
   <price_change>18.2</price_change>
   <report_url>https://sberinvest.ru/research/sber-2024</report_url>
 </recommendation>

 <recommendation>
   <ticker>GAZP</ticker>
   <company_name>Газпром Публичное акционерное общество</company_name>
   <recommendation>HOLD</recommendation>
   <target_price>120.00</target_price>
   <date>2024-11-14</date>
   <valid_until>2025-02-14</valid_until>
   <price_change>5.0</price_change>
   <report_url>https://tinkoff.ru/research/gazprom-2024</report_url>
 </recommendation>

 <recommendation>
   <ticker>YNDX</ticker>
   <company_name>Яндекс Публичное акционерное общество</company_name>
   <recommendation>SELL</recommendation>
   <target_price>3500.00</target_price>
   <date>2024-11-13</date>
   <valid_until>2024-12-13</valid_until>
   <price_change>-10.5</price_change>
   <report_url>https://vtbcapital.ru/research/yandex-2024</report_url>
 </recommendation>

</stock_recommendations>
```

Описание элементов фида:

| Элемент | Тип | Описание | Обязательность |
| --- | --- | --- | --- |
| `updated_at` | string (ISO 8601) | Дата обновления информации. | Да |
| `analyst` | string | Автор прогноза (название инвестиционной компании). | Да |
| `ticker` | string | Тикер ценной бумаги в принятом на российском рынке формате. Примеры: `SBER`, `GAZP`, `YNDX`. | Да |
| `company_name` | string | Полное наименование компании. | Да |
| `recommendation` | string | Рекомендация аналитика: `BUY` — покупать; `HOLD` — удерживать; `SELL` — продавать. | Да |
| `target_price` | number | Прогнозная цена. | Да |
| `date` | string (ISO 8601) | Дата публикации прогноза в формате `YYYY-MM-DD`. | Да |
| `valid_until` | string (ISO 8601) | Дата окончания действия прогноза в формате `YYYY-MM-DD`. | Да |
| `report_url` | string | URL к полному отчету аналитика. | Да |
| `currency` | string | Валюта цены: возможные значения — `RUB`. | Да |

## Условия

Сайт несет ответственность за корректность данных, соответствие предложений тематике, а также за распространение незаконной информации. В случае нарушения условий Яндекс имеет право не использовать данные сайта для изменения представления ответа в поисковой выдаче. См. [подробные условия](https://yandex.ru/legal/search_partner_integration_conditions).

**Требования к сервису партнера**

- Сервис действует на территории Российской Федерации.
- Сервис действует в соответствии с законодательством Российской Федерации, в том числе законодательством о рынке ценных бумаг. На сервисе не предлагается совершение сделок, не соответствующих действующему законодательству.
- На сервисе можно приобретать ценные бумаги только через профессионального участника рынка ценных бумаг, который имеет лицензию на брокерское и депозитарное обслуживание, действующую на территории Российской Федерации.
- Обмен информацией между клиентом и профессиональным участником рынка ценных бумаг, выполняющим распоряжение клиента на совершение сделки, осуществляется непосредственно на сервисе, без переадресации на другие сервисы (в т. ч. по технологии iframe).
- Партнер должен являться правообладателем информации, передаваемой в рамках интеграции Яндексу, либо обладать необходимыми полномочиями для использования указанной информации Яндексом.
