# Транспортные средства

> Source: https://yandex.ru/support/webmaster/ru/search-appearance/cars

## Для каких сайтов

Сайты по продаже легковой, коммерческой и мототехники.

## Что добавляет в результаты поиска

Содержит карточки с предложениями транспортных средств, которые подходят под запрос пользователя, и предоставляет удобно структурированную, точную и полезную информацию об объявлениях. Нажав на карточку, пользователь перейдет на сайт партнера и увидит все подходящие объявления. Для более конкретизированных запросов (например, об определенной модели) ответ может содержать подробности о комплектациях, модификациях и ценах.

## Как настроить

Чтобы ваши предложения попадали в такие ответы, необходимо передать Яндексу информацию о них. Для этого нужно подготовить фид в формате [YML](https://yandex.ru/support/webmaster/ru/feed/upload). Стандарт YML разработан Яндексом и основан на стандарте XML. Фид — это файл, в котором вы передаете информацию о своих предложениях. В нем описываются предложения (`offers`), объединенные в специальные наборы — сеты (`sets`).

### Ограничения для фида

| Параметр | Ограничение |
| --- | --- |
| Размер YML-файла | 200 МБ |
| Общее количество изображений | 50 000 |
| Количество изображений в одном элементе `offer` | 200 |
| Количество элементов `offer` | 30 000. При превышении фид загрузится с ошибкой — разбейте фид на несколько частей. |
| Количество элементов `set` | 1 млн |
| Количество всех YML-файлов суммарно для сайта и его поддоменов | 1000 |

> Не дублируйте предложения с одним и тем же URL-адресом в нескольких фидах, а также не переносите предложения из одного фида в другой — данные из перенесенного предложения могут временно пропасть из поиска.

Сет отличается от другого обязательного элемента фида — [категории](https://yandex.ru/support/partnermarket/elements/categories.html) (`category`). Категория может быть только одна. Сетов может быть больше одного, так как одно и то же предложение может принадлежать разным сетам. Сеты, к которым принадлежит предложение, перечисляются через запятую.

В поисковой выдаче будет дополняться сниппет, URL которого совпадает с URL, заданным в сете. Сниппет дополняется информацией из предложений, которые входят в сет. Формат предложения должен соответствовать определенным [требованиям](https://yandex.ru/support/partnermarket/offers.html). Вся дополнительная информация о предложении указывается в элементе [param](https://yandex.ru/support/partnermarket/elements/param.html).

> **Совет**
> Не обязательно формировать файл для всего контента. Достаточно сформировать его для тех сетов (URL), которые необходимо дополнить в результатах поиска.

### Требования к фиду

Фид может содержать разные виды предложений:
- Конкретное предложение (например, определенный автомобиль или мотоцикл).
- Подборка (например, «Toyota в Москве»). Характеристики: минимальная цена, число объявлений в подборке, адрес и другие параметры.

[Пример фида](https://edu.s3.yandex.net/sample/cars.yml).

### Элементы предложения

Минимальный набор элементов предложения (обязательные отмечены \*):

| Элемент | Примечание |
| --- | --- |
| `name` \* | Название предложения. |
| `url` \* | URL-адрес предложения. Должен быть уникальным среди всех предложений в пределах всех фидов одного региона. Метки (UTM, Openstat, from) не делают URL уникальным. |
| `price` \* | Стоимость. С помощью атрибута `from="true"` можно указать минимальную оплату. |
| `currencyId` \* | Идентификатор валюты (например, `RUR` для рублей). |
| `categoryId` \* | Идентификатор категории. |
| `set-ids` \* | Идентификаторы сетов через запятую (например, `s1,s2,s3`). |
| `picture` \* | Фотографии транспортного средства или автодилера, до 10 штук. Ссылки не должны повторяться. |
| `param name="Конверсия"` \* | Число. Произвольное значение. Чем больше, тем лучше предложение. |
| `vendor` | Название производителя. Для дилера — через запятую. |
| `description` | Описание. |
| `param name="Число объявлений"` | Число. Наличие показывает, что предложение — подборка. |
| `param name="Число объявлений во всех регионах"` | Число. |
| `param name="Число отзывов"` | Число. |
| `param name="Ссылка на отзывы"` | Строка. |
| `param name="Ссылка на характеристики"` | Строка. |
| `param name="Ссылка на комплектации"` | Строка. |
| `param name="Опубликовано"` | Дата в формате [ISO 8601](https://ru.wikipedia.org/wiki/ISO_8601). |
| `param name="Размещено дилером"` | `true` или `false` (по умолчанию). |
| `param name="Год создания"` | Число. |
| `param name="Годы создания"` | Два числа через дефис (например, `2020-2021`). Для подборки. |
| `param name="Пробег"` | Число, км. Если ТС новое — `0`. |
| `param name="Комплектация"` | Строка (например, `318i Sport Line Edition 21`). |
| `param name="Двигатель, литры"` | Число. |
| `param name="Двигатель, л.с."` | Число. |
| `param name="Двигатель, тип"` | Атмосферный / Турбированный. |
| `param name="Топливо"` | Бензин / Дизель / Гибрид / Электро / Водород / Пропан. |
| `param name="Коробка передач"` | Автомат / Автоматическая / Механика / Механическая / Робот / Вариатор. |
| `param name="Привод"` | Передний / Задний / Полный. |
| `param name="Состояние"` | Не требует ремонта / Нуждается в ремонте / Не на ходу. |
| `param name="Повреждения"` | Строка. |
| `param name="Адрес"` | Строка. Для дилеров. |
| `param name="Широта"` | Число. Для дилеров. |
| `param name="Долгота"` | Число. Для дилеров. |

Вы можете создавать собственные необязательные элементы `param`.

### Особенности фида подборки конкретных объявлений и моделей

Для формирования подборки конкретных объявлений или моделей сет должен содержать не меньше четырех предложений. В каждом предложении должно быть хотя бы одно изображение, оно не должно повторяться в других предложениях. URL сета не должен совпадать с URL предложений. Для формирования подборки моделей укажите параметр `param name="Число объявлений"`. Для подборки объявлений этот параметр должен отсутствовать.

### Особенности фида подборки комплектаций

Чтобы смогла сформироваться подборка комплектаций, фид должен содержать предложение, URL которого совпадает с URL сета (но не входит в него), не менее чем с четырьмя изображениями. URL-адреса других предложений (строк таблицы) не должны совпадать с URL сета и должны содержать параметры: `param name="Двигатель, литры"`, `param name="Коробка передач"`, `param name="Двигатель, л.с."`.

### Как передать фид

**В Вебмастере:**

1. Авторизуйтесь на Яндексе. [Добавьте сайт](https://yandex.ru/support/webmaster/ru/service/quick-start) в Яндекс Вебмастер и [подтвердите права](https://yandex.ru/support/webmaster/ru/service/rights#how-to) на управление или [получите доступ](https://yandex.ru/support/webmaster/ru/service/rights-management#delegation) для вашего аккаунта у пользователя с ролью **Владелец**.
2. Перейдите на страницу **Услуги и предложения в поиске** → **Фиды и ошибки**.
3. Нажмите **Загрузить фид**.
4. Выберите категорию бизнеса **Транспортные средства**.
5. Укажите регион.
6. В поле **Ссылка на файл с предложениями** укажите URL вида `https://example.com/feed.yml`.

   > **Если на вашем сайте настроена авторизация:**
   > Передавайте логин и пароль вместе с URL. Например: `http://yandex:WE9h4FfBml@example.com/feed.yml`.

7. Нажмите **Готово**.

**С помощью API Вебмастера:** см. [документацию](https://yandex.ru/dev/webmaster/doc/dg/concepts/feeds.html).

Яндекс Вебмастер проверит фид. Если он содержит ошибки, на странице **Услуги и предложения в поиске** → **Фиды и ошибки** появится сообщение об ошибках. Исправьте ошибки — Вебмастер проверит фид снова.

Также информация о сайте и предложениях будет [проверена службой контроля качества](https://yandex.ru/support/webmaster/ru/feed/transport) в течение нескольких дней. Фид может быть отклонен за нарушение правил.

## Условия

Сайт несет ответственность за корректность данных, соответствие предложений тематике, а также за распространение незаконной информации. В случае нарушения условий Яндекс имеет право не использовать данные сайта для изменения представления ответа в поисковой выдаче. См. [подробные условия](https://yandex.ru/legal/search_partner_integration_conditions).

Данные из фида могут обогащать органический результат вашего сервиса в поиске, когда это увеличивает [профицит](https://yandex.ru/support/webmaster/ru/search-quality) (метрику полезности для пользователя) поисковой выдачи.

Такое обогащение предоставляется только для страниц подходящего формата: содержащих список объектов.

Положение ответа в поисковой выдаче определяется общими принципами ранжирования: более высокие позиции получают страницы, наиболее релевантные запросу. Порядок карточек внутри ответа определяется с учетом данных о взаимодействии пользователей с карточками для максимизации конверсии и профицита.

Мы стремимся показывать в результатах поиска информацию, которая будет полезна конкретному пользователю. Чтобы при ранжировании предложений учитывать данные о конверсиях, рекомендуем установить на вашем сервисе [Яндекс Метрику](https://metrika.yandex.ru). [Подробнее о событиях в Яндекс Метрике](https://yandex.ru/support/webmaster/ru/feed/goals#events).
