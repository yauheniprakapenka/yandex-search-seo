## Для каких сайтов

Популярные среди пользователей Поиска сайты с несколькими разделами.

## Что добавляет в результаты поиска

Содержит ссылки на основные разделы сайта. Отображается, когда пользователь ищет конкретный ресурс. Помогает быстро попасть в нужный раздел сайта и тем самым экономит самый ценный ресурс пользователя — время.

При ответе на навигационный запрос, например, *пушкинский музей*, быстрые ссылки могут быть показаны в развернутом виде, когда каждая из них снабжена своим небольшим сниппетом.

## Как настроить

Быстрые ссылки формируются автоматически. Робот Яндекса определяет наиболее посещаемые разделы сайта и создает быстрые ссылки.

Проверить, сформированы ли ссылки для вашего ресурса, можно в [Яндекс Вебмастере](https://webmaster.yandex.ru/) (**Представление в поиске** → **Быстрые ссылки**).

Некоторые параметры (имя, порядок, отображение одной или всех ссылок в ответе) для навигационного ответа можно [изменить](https://yandex.ru/support/webmaster/ru/search-results/quick-links-result#settings).

## Условия

Быстрые ссылки формируются при следующих условиях:

- короткие и понятные названия страниц точно отражают их содержание;
- быстрые ссылки создаются только из внутренних ссылок сайта;
- разделы и подразделы выделены в меню или являются самыми популярными переходами со страницы, для которой формируются быстрые ссылки.
