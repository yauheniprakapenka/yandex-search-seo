# Строгая микроразметка — Каталоги

> Source: https://yandex.ru/support/webmaster/ru/supported-schemas/catalogs

Чтобы данные из семантической разметки страницы при обходе роботом имели максимальный приоритет по сравнению с данными из других источников, размечайте списки товаров по схеме [OfferCatalog](https://schema.org/OfferCatalog) с вложенными объектами, соответствующими схеме [Offer](https://schema.org/Offer).

## Поддерживаемые поля схемы

Все поддерживаемые поля являются обязательными.

**Свойства [OfferCatalog](https://schema.org/OfferCatalog):**

- `name` ([Text](https://schema.org/Text)) — название каталога;
- `description` ([Text](https://schema.org/Text)) — описание каталога;
- `image` ([URL](https://schema.org/URL)) — общая картинка каталога. Не является объектом типа [ImageObject](https://schema.org/ImageObject).

На странице должен быть только один список товаров, размеченный по схеме [OfferCatalog](https://schema.org/OfferCatalog), без вложенных списков.

**Свойства [Offer](https://schema.org/Offer):**

- `url` ([URL](https://schema.org/URL)) — ссылка на страницу товара;
- `name` ([Text](https://schema.org/Text)) — название товара;
- `description` ([Text](https://schema.org/Text)) — описание товара;
- `image` ([URL](https://schema.org/URL)) — картинка товара. Не является объектом типа [ImageObject](https://schema.org/ImageObject).
- `availability` ([URL](https://schema.org/URL)) — доступность товара для заказа;
- `price` ([Text](https://schema.org/Text) или [Number](https://schema.org/Number)) — цена товара;
- `priceCurrency` ([Text](https://schema.org/Text)) — валюта.

## Пример корректной разметки

**Schema.org (Microdata):**

```html
<ul itemscope itemtype="https://schema.org/OfferCatalog">
   <span itemprop="name">Каталог</span>
   <span itemprop="description">Описание каталога</span>
   <img src="http://www.example.com/image.jpg" itemprop="image">
   <li itemprop="itemListElement" itemscope itemtype="https://schema.org/Offer">
      <div>
         <span itemprop="name">Товар</span>
         <span itemprop="description">Описание товара</span>
         <link itemprop="url" href="www.example.com/product/1">
         <img src="http://www.example.com/image1.jpg" itemprop="image">
         <meta itemprop="price" content="7150.00">
         <meta itemprop="priceCurrency" content="RUB">
         <link itemprop="availability" href="http://schema.org/InStock">
      </div>
   </li>
   <li itemprop="itemListElement" itemscope itemtype="https://schema.org/Offer">
      <div>
         <span itemprop="name">Другой товар</span>
         <span itemprop="description">Описание другого товара</span>
         <link itemprop="url" href="www.example.com/product/2">
         <img src="http://www.example.com/image2.jpg" itemprop="image">
         <meta itemprop="price" content="750.00">
         <meta itemprop="priceCurrency" content="RUB">
         <link itemprop="availability" href="http://schema.org/InStock">
      </div>
   </li>
</ul>
```

**JSON-LD:**

```json
<script type="application/ld+json">
{
  "@context": "https://schema.org/",
  "@type": "OfferCatalog",
  "name": "Название каталога",
  "image": "http://www.example.com/image.jpg",
  "description": "Описание каталога",
   "itemListElement": [
    {
      "@type": "Offer",
      "name": "Товар",
      "description": "Описание товара",
      "url": "www.example.com/product/1",
      "price": "7150.00",
      "priceCurrency": "RUB",
      "image": "http://www.example.com/image1.jpg",
      "availability": "https://schema.org/InStock"
    },
    {
      "@type": "Offer",
      "name": "Другой товар",
      "description": "Описание другого товара",
      "url": "www.example.com/product/2",
      "price": "750.00",
      "priceCurrency": "RUB",
      "image": "http://www.example.com/image2.jpg",
      "availability": "https://schema.org/InStock"
    }
  ]
}
</script>
```

> **Внимание**
>
> Обработка данных в формате [JSON-LD](https://yandex.ru/support/webmaster/ru/json-ld/about) не гарантируется.

[Проверить](https://webmaster.yandex.ru/site/tools/microtest/) правильность разметки можно с помощью валидатора.
