# Строгая микроразметка — Товары

> Source: https://yandex.ru/support/webmaster/ru/supported-schemas/strict-microdata-offers

Чтобы данные из семантической разметки страницы при обходе роботом имели максимальный приоритет по сравнению с данными из других источников, размечайте товарные страницы по схеме [Product](https://schema.org/Product) со значением свойства [offers](https://schema.org/offers), соответствующим схеме [Offer](https://schema.org/Offer) или [AggregateOffer](https://schema.org/AggregateOffer).

Подробнее см. в Справке [Яндекс Товаров](https://yandex.ru/support/merchants/ru/microdata).
