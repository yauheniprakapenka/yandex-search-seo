# Рефераты

> Source: https://yandex.ru/support/webmaster/ru/supported-schemas/essay

Информация о рефератах и подобных работах, которая размещается на вашем сайте, может использоваться в сниппетах на страницах поисковой выдачи Яндекса. Чтобы поисковый робот распознал такие данные, размечайте соответствующие страницы по схеме [`CreativeWork`](http://schema.org/CreativeWork).

## Поддерживаемые типы разметки и поля схемы

| Свойство | Тип | Описание | Обязательный |
|---|---|---|---|
| `learningResourceType` | [Text](http://schema.org/Text) | Вид работы. Поддерживаются: `AcademicThesis` (дипломная), `BookReport` (сочинение по книге), `Coursework` (курсовая), `Dissertation` (диссертация), `Examination` (контрольная), `StudentEssay` (сочинение), `StudentLaboratoryWork` (лабораторная), `StudentReport` (доклад), `StudentSummary` (реферат). | Да |
| `description` | [Text](http://schema.org/Text) | Краткое описание работы. Рекомендуемый объем — от 50 до 150 символов. | Да |
| `name` или `headline` | [Text](http://schema.org/Text) | Название или заголовок работы. Если указаны оба свойства, в сниппет попадает название из свойства `name`. | Нет |
| `author` | [Text](http://schema.org/Text), [Organization](http://schema.org/Organization) или [Person](http://schema.org/Person) | Автор работы. Если используются типы `Organization` или `Person`, данные берутся из свойства `name`. Если разметка содержит несколько свойств `author`, в сниппет попадет первое. | Нет |
| `genre` | [Text](http://schema.org/Text) | Жанр работы. | Нет |

## Пример разметки

```html
<div itemscope itemtype="http://schema.org/CreativeWork">
   <img itemprop="image" alt="essay cover" src="essay.jpg" />
   <meta itemprop="learningResourceType" content="StudentEssay">
   <span itemprop="name">Сказки Пушкина</span>
   <span itemprop="author">Иван Петров</span>,
   <span itemprop="description">Александр Сергеевич Пушкин как выдающийся, великий русский поэт, драматург и прозаик. Общая характеристика творчества Пушкина в середине 20-х годов XIX века. История создания сказок. Образный мир и исторические корни сюжетов поэтических произведений.</span>
</div>
```

[Проверьте](https://webmaster.yandex.ru/site/tools/microtest/) правильность разметки с помощью валидатора.
