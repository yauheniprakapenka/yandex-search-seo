# Программы

> Source: https://yandex.ru/support/webmaster/ru/supported-schemas/software

Чтобы сайт, посвященный программам, получил структурированные сниппеты в поисковой выдаче Яндекса, добавьте специальную разметку на страницы с описанием.

Для формирования сниппета Яндекс поддерживает следующие типы [стандарта Schema.org](http://schema.org/):

- [SoftwareApplication](http://schema.org/SoftwareApplication)
- [MobileApplication](http://schema.org/MobileApplication)
- [WebApplication](http://schema.org/WebApplication)
- [VideoGame](http://schema.org/VideoGame)

## Свойства

| Свойство | Тип | Описание | Обязательный |
|---|---|---|---|
| `description` | [Text](http://schema.org/Text) | Краткое и содержательное описание программного продукта. | Да |
| `applicationSubCategory` | [Text](http://schema.org/Text) | Категория программы. Например, «Плееры», «Гонки», «Онлайн-игра». В поле могут быть указаны несколько слов, в сниппете будут использоваться первые несколько значений так, чтобы их общая длина не превышала 24 символов. | Нет |
| `fileSize` | [Integer](https://schema.org/Integer) | Размер. Если в поле указано только число, размер будет показываться в килобайтах. Вы можете указать единицы измерения (KB, MB, GB) — в таком случае размер будет показываться с указанной единицей. | Нет |
| `interactionCount` | [Text](http://schema.org/Text) | Количество скачиваний. Указывается как `<meta itemprop="interactionCount" content="UserDownloads:XXX" />`, где `XXX` — общее число скачиваний. | Нет |
| `operatingSystem` | [Text](http://schema.org/Text) | Операционная система. Возможные значения: `win`, `windows X` (где X — версия ОС), `xp`, `vista` (для ОС Windows), `Windows Mobile` (для ОС Windows Mobile), `Mac` (для Mac OS), `iOs`, `iPhone`, `iPad` (для iOs), `Android` (для Android). Чтобы указать несколько версий одной ОС, перечислите их через запятую (например, `Windows 7, 8, XP, Vista`). Чтобы указать несколько ОС, разделите значения знаком `|` (например, `Windows 8 | Android | iOS`). | Нет |
| `price` и `priceCurrency` | [Number](https://schema.org/Number), [Text](http://schema.org/Text) | Стоимость и валюта. Указываются как свойства вложенного типа `Offer`. Чтобы указать валюту, используйте коды в соответствии с [ISO 4217](http://www.iso.org/iso/currency_codes) (например, RUB обозначает рубли). Если значение стоимости равно 0, в сниппете показывается значение «Бесплатно». | Нет |

Для формирования сниппета на странице необходимо указать минимум два необязательных свойства. Если поисковый робот Яндекса решит, что обычный сниппет более информативный, чем структурированный, то на Поиске будет использоваться обычный сниппет.

## Пример разметки

```html
<div itemscope itemtype="http://schema.org/SoftwareApplication">
    <div itemprop="description">Skype — это бесплатная программа, благодаря которой вы сможете бесплатно общаться по телефону через сеть интернет.</div>
    <div itemprop="offers" itemscope itemtype="http://schema.org/Offer"> Статус программы:
        <meta itemprop="price" content="0"/>Бесплатная</div>
    <div>Размер:<span itemprop="fileSize">38912</span> KB</div>
    <div>Система:<span itemprop="operatingSystem">Windows 7, 8, XP, Vista | Android | ‎iOS</span></div>
    <meta itemprop="interactionCount" content="UserDownloads:2129972" />
</div>
```

[Проверьте](https://webmaster.yandex.ru/site/tools/microtest/) правильность разметки с помощью валидатора.

> **Внимание**
>
> Яндекс не гарантирует, что полученные данные появятся в результатах поиска. Яндекс может использовать информацию, которая размечена в формате [Schema.org](https://schema.org/), полностью или частично, отдельно или вместе с информацией, полученной из других источников. Информация может быть использована на любом сервисе Яндекса.
