# Навигационные цепочки

> Source: https://yandex.ru/support/webmaster/ru/supported-schemas/navigation-links

Навигационная цепочка — это ряд ссылок на разделы сайта, к которым относится найденная страница. Она помогает пользователю Поиска быстро оценить объем информации на сайте или тип контента, и быстро перейти в нужный раздел.

Навигационная цепочка может формироваться на основе микроразметки [Schema.org](https://yandex.ru/support/webmaster/ru/schema-org/intro-schema-org).

Для формирования навигационной цепочки используйте на сайте микроразметку типа [BreadcrumbList](https://schema.org/BreadcrumbList) в формате [JSON-LD](https://yandex.ru/support/webmaster/ru/json-ld/about), которая соответствует стандарту [Schema.org](https://schema.org/).

## Рекомендуемые поля схемы

Ниже описаны поля схемы [BreadcrumbList](https://schema.org/BreadcrumbList), значения которых учитываются Яндексом. В скобках указан тип данных Schema.org, которому должно соответствовать значение свойства.

- `name` ([Text](https://schema.org/Text)) — название элемента;
- `url` ([URL](https://schema.org/URL)) — адрес элемента;
- `position` ([Integer](https://schema.org/Integer)) — последовательность элемента в цепочке.

Примеры использования микроразметки посмотрите [на официальном сайте Schema.org](https://schema.org/BreadcrumbList#examples).

## Условия формирования навигационной цепочки

Навигационные цепочки могут сформироваться, если:

- Микроразметка не содержит ошибки. Чтобы проверить код, воспользуйтесь [валидатором в Вебмастере](https://webmaster.yandex.ru/site/tools/microtest/).
- Для всех элементов, кроме последнего, указан абсолютный (URL) или относительный путь на соответствующий раздел сайта.
  - Пример абсолютного адреса: `https://example.com/dresses/real`.
  - Пример относительного адреса: `/dresses/real`.
- При использовании URL, в том числе в последнем элементе, домен совпадает с адресом сайта, на который встраивается разметка.
- Абсолютные адреса используют схемы HTTPS или HTTP.
- Текст элементов навигационной цепочки заполнен. Если в тексте есть [эмодзи](https://ru.wikipedia.org/wiki/Эмодзи), при обработке они будут удалены и не отобразятся в результатах поиска.
- В свойстве `position` указаны числа. При использовании нечисловых значений цепочка не сформируется. Вы можете не использовать `position`.

Промежуточные элементы, выделенные свойством `name`, могут исключаться из навигационной цепочки, если:

- Длина элемента меньше четырех символов, не считая эмодзи и пробелов, или, наоборот, слишком большая.
- Элемент указывает на главную страницу.
- Элементов в цепочке слишком много. В этом случае отобразится только несколько последних элементов. Рекомендуем включать в цепочку до трех элементов.

> **Внимание**
>
> Яндекс не гарантирует, что полученные данные появятся в результатах поиска. Яндекс может использовать информацию, которая размечена в формате [Schema.org](https://schema.org/), полностью или частично, отдельно или вместе с информацией, полученной из других источников. Информация может быть использована на любом сервисе Яндекса.
