# Описание элементов, обрабатываемых Яндексом

> Source: https://yandex.ru/support/webmaster/ru/hcard/yandex

## Обязательные элементы

Чтобы карточка организации корректно обрабатывалась Яндексом, она должна строго соответствовать формату hCard. В частности, корневым элементом карточки должен быть элемент класса `vcard`. Остальные элементы (свойства) располагаются внутри корневого.

Чтобы карточка могла быть загружена в базу данных Яндекс Бизнеса, она обязательно должна содержать следующие свойства: `fn` и `org`, `adr`, `tel`.

### fn и org

Название организации. Согласно стандарту hCard, для карточек, описывающих организации, значения свойств `fn` и `org` должны совпадать. Рекомендуется пометить название сразу двумя классами в одном элементе:

```html
<span class="fn org">...</span>
```

### adr

Адрес организации. Адрес должен быть достаточно подробным, чтобы его можно было найти на карте. Карточки обрабатываются только для четырех стран: Россия, Украина, Беларусь, Казахстан.

Для элемента класса `adr` обрабатываются следующие вложенные свойства:

- `country-name` — страна;
- `region` — субъект федерации + район;
- `locality` — населенный пункт;
- `street-address` — улица, дом, корпус, строение и т. п.;
- `extended-address` — подъезд, этаж, офис, название торгового/бизнес-центра и т. п.;
- `postal-code` — почтовый индекс.

Для правильного распознавания адреса необходимо указание населенного пункта (`locality`). Если название не определяет населенный пункт однозначно, требуется также указание региона (`region`).

> Рекомендуется размечать только фактические («как вас найти»), а не юридические адреса.

Карточка может содержать несколько адресов (если организация имеет несколько отделений с одинаковыми названиями и контактными данными). Если филиалы имеют различные названия и телефоны, рекомендуется создать отдельную карточку для каждого.

### tel

Номер телефона (с кодом города). Предпочтительный формат: `+{код страны} ({код города}) {номер}`, например: `+7 (890) 123-45-67`. Можно использовать элемент `<abbr>` для отображения номера в другом формате.

В одной карточке можно указать несколько телефонных номеров.

```html
<div class="vcard">
  <div>
    <a class="fn org url" href="http://www.cafe.com">Кафе Ромашка</a>
  </div>
  <div class="adr">
    <span class="locality">г. Солнечный</span>,
    <span class="street-address">просп. Романтиков, д. 21</span>
  </div>
  <div class="tel">Телефон:
    <abbr class="value" title="+ 7 (890) 123-45-67">123-45-67</abbr>
  </div>
  <div class="tel">
    <abbr class="type" title="fax">Факс:</abbr>
    <abbr class="value" title="+ 7 (890) 123-45-89">123-45-89</abbr>
  </div>
</div>
```

## Поддерживаемые элементы

Кроме обязательных свойств, Яндекс обрабатывает следующие свойства:

### category

Род деятельности организации. Наличие этого свойства облегчает отнесение организации к рубрике Яндекс Бизнеса. В одной карточке можно указать несколько категорий:

```html
<div class="vcard">
  <div>
    <span class="category">Кафе</span>-<span class="category">кулинария</span>
    <span class="fn org">Ромашка</span>
  </div>
  ...
</div>
```

Можно добавить невидимую категорию с помощью `value-title`:

```html
<span class="category">
  <span class="value-title" title="кафе"> </span>
</span>
```

### email

Электронный адрес. В одной карточке можно указать несколько. Можно отображать как текст или как ссылку:

```html
<a class="email" href="mailto:cafe@cafe.com">romashka@romashka-cafe.ru</a>
```

### geo

Географические координаты в градусах. Облегчает геокодирование. В карточке может быть не более одного элемента `geo`. Необходимы вложенные свойства:

- `latitude` — широта;
- `longitude` — долгота.

```html
<span class="geo">
  <span class="latitude">
    <span class="value-title" title="55.792188"> </span>
  </span>
  <span class="longitude">
    <span class="value-title" title="37.764956"> </span>
  </span>
</span>
```

### url

Ссылка на официальный сайт организации. Предпочтительно — на главную страницу. При добавлении в Яндекс Бизнес будет выбран только один URL.

```html
<a class="url" href="...">...</a>
```

Или невидимый:

```html
<span class="url"><span class="value-title" title="..."> </span></span>
```

### workhours

Время работы организации. Свойство не предусмотрено стандартом hCard, добавлено Яндексом в качестве расширения.

Рекомендуемые форматы:

- пн. — пт. 9:00–18:00
- пн. — пт. 9:00–18:00, обед 13:00–14:00, сб — вс 10:00–17:00
- ежедн. 10:00–24:00
- круглосуточно

```html
<div>Мы работаем <span class="workhours">ежедневно с 11:00 до 24:00</span></div>
```

## Прочие элементы

Остальные свойства, предусмотренные форматом hCard, в настоящее время игнорируются Яндексом. Однако вы можете включить их в карточку, если хотите сделать эти данные доступными другим сервисам. Полный список свойств — в [официальной спецификации](http://microformats.org/wiki/hcard#Property_List).
