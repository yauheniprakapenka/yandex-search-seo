# Микроформат hRecipe

> Source: https://yandex.ru/support/webmaster/ru/hrecipe/general

hRecipe — стандарт (X)HTML-разметки кулинарных рецептов, разработанный международной инициативной группой. Эта разметка позволяет автоматически обрабатывать размещенные на страницах сайта рецепты, извлекая из текста семантические элементы (ингредиенты блюда, способ приготовления, время приготовления). При этом разметка не видна посетителям сайта и не влияет на отображение информации на странице.

Например, на странице сайта размещен следующий рецепт:

**Курица в пиве с рисом**

Ингредиенты: 1 курица, 0,5 л пива, соль, перец, специи по вкусу.

Способ приготовления: Курицу нарезать на кусочки, выложить в форму для запекания, посолить, поперчить, добавить специи по вкусу. Курицу залить пивом, поставить в духовку. Запекать при температуре 180 градусов в течение 40-45 минут.

HTML-код страницы, размеченной с помощью формата hRecipe:

```html
<div class="hrecipe">
    <h1 class="fn">Курица в пиве с рисом</h1>
    <h2>Ингредиенты</h2>
    <ul>
        <li class="ingredient">
            <span class="amount">1</span>
            <span class="name">курица</span>
        </li>
        <li class="ingredient">
            <span class="value">0.5</span>
            <span class="type">л</span>
            <span class="name">пива</span>
        </li>
        <li class="ingredient">
            <span class="name">соль</span>
        </li>
        <li class="ingredient">
            <span class="name">перец</span>
        </li>
        <li class="ingredient">
            <span class="name">специи</span>
            <span class="amount">по вкусу</span>
        </li>
    </ul>
    <h2>Способ приготовления</h2>
    <ul class="instructions">
        <li class="instruction">Курицу нарезать на кусочки, выложить в форму для запекания,
            посолить, поперчить, добавить специи по вкусу.</li>
        <li class="instruction">Курицу залить пивом, поставить в духовку.</li>
        <li class="instruction">Жарить при температуре 180 градусов в течение 40-45 минут.</li>
    </ul>
</div>
```

Проект спецификации формата hRecipe находится на сайте [http://microformats.org/wiki/hRecipe](http://microformats.org/wiki/hRecipe).

О полях, обрабатываемых Яндексом, см. в разделе [Описание элементов hRecipe](https://yandex.ru/support/webmaster/ru/hrecipe/yandex-supported).

hRecipe-разметка обрабатывается одновременно с индексацией вашего сайта поисковым роботом Яндекса. Извлеченные данные проходят проверку на корректность и в дальнейшем могут использоваться для отображения элементов рецепта в [результатах поиска](https://yandex.ru/support/webmaster/ru/search-appearance/recipe).

> **Примечание**
>
> Данные, размеченные форматом hRecipe, становятся общедоступными и могут быть извлечены и использованы любыми сервисами.
