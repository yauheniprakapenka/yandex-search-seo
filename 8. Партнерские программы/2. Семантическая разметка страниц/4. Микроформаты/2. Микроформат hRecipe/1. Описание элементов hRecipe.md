# Описание элементов hRecipe

> Source: https://yandex.ru/support/webmaster/ru/hrecipe/yandex-supported

## Общие требования

Чтобы рецепты с вашего сайта могли быть извлечены Яндексом, на одной странице должен находиться только один рецепт — элемент корневого класса `hrecipe`, и этот рецепт должен являться основным содержанием страницы. Остальные элементы (свойства рецепта) располагаются внутри корневого.

Данные, содержащиеся в рецепте, должны полностью отображаться на странице и быть видимы посетителю сайта.

Яндекс обрабатывает как стандартные свойства формата, так и собственные расширения.

## Обязательные элементы

### fn

Название рецепта или блюда. Значением может быть только текст.

```html
<span class="fn">Курица в пиве с рисом</span>
```

### ingredient

Ингредиент и его объем/количество. Рецепт может содержать один или несколько ингредиентов. Классом `ingredient` следует пометить каждый ингредиент.

Вложенные свойства:

- `name` — название продукта (расширение Яндекса);
- `type` и `value` — единица измерения и количество;
- `amount` — количество в произвольном формате (расширение Яндекса). Используется вместо `type` и `value`.

```html
<span class="ingredient">
  <span class="amount">1</span>
  <span class="name">курица</span>
</span>
```

```html
<span class="ingredient">
  <span class="value">0.5</span>
  <span class="type">л</span>
  <span class="name">пива</span>
</span>
```

## Рекомендуемые элементы

### instructions

Инструкции по приготовлению блюда. Не более одного элемента класса `instructions`. Рекомендуется включать только сами указания, без заголовка.

Отдельные пункты можно пометить классом `instruction` (расширение Яндекса):

```html
<ul class="instructions">
  <li class="instruction">Курицу нарезать на кусочки...</li>
  <li class="instruction">Курицу залить пивом...</li>
  <li class="instruction">Жарить при температуре 180 градусов...</li>
</ul>
```

Допускается вкладывать внутрь `instructions` свойства `photo` и `result-photo`.

### yield

Количество порций. Не более одного элемента. Только текст.

```html
<span>Блюдо рассчитано на <span class="yield">3 человек</span>.</span>
```

### duration

Длительность приготовления в формате [ISO 8601](http://en.wikipedia.org/wiki/ISO_8601#Durations).

```html
<span class="duration"><span class="value-title" title="PT1H30M"> </span>полтора часа</span>
```

### photo и result-photo

Фотография готового блюда или этапа приготовления. Может быть несколько элементов `photo`. Один из них (фото готового блюда) должен быть помечен также классом `result-photo` (расширение Яндекса). Значением является значение атрибута `src` элемента `<img>`.

### author

Автор рецепта. Может быть несколько. Значением может быть текст или карточка [hCard](https://yandex.ru/support/webmaster/ru/hcard/general).

```html
<span class="author vcard">
  <a class="fn url" href="http://ivanov.narod.ru/">Иванов</a>
</span>
```

### nutrition

Энергетическая или пищевая ценность блюда. Может быть несколько элементов. Вложенные свойства (расширения Яндекса):

- `calories` — калорийность;
- `fat` — жиры;
- `saturatedFat` — насыщенные жиры;
- `unsaturatedFat` — ненасыщенные жиры;
- `carbohydrates` — углеводы;
- `sugar` — сахар;
- `fiber` — клетчатка;
- `protein` — белки;
- `cholesterol` — холестерин;
- `servingSize` — размер порции.

```html
<div>
  100 г блюда содержат
  <span class="nutrition">
    Энергетическая ценность: <span class="calories">240 ккал</span>
    Белки: <span class="protein">18 г.</span>
    Жиры: <span class="fat">10 г.</span>
    Углеводы: <span class="carbohydrates">70 г.</span>
  </span>
</div>
```

## Расширения (свойства, не предусмотренные стандартом hRecipe)

### category

Тип блюда. Не более одного элемента. Только текст.

```html
<span class="category">Горячее блюдо</span>
```

### sub-category

Подтип блюда. Не более одного элемента. Только текст.

### cuisine-type

Национальная кухня. Не более одного элемента. Только текст.

### weight

Вес готового блюда. Не более одного элемента. Только текст.

```html
<div>Вес блюда составит <span class="weight">1,5 кг</span></div>
```
