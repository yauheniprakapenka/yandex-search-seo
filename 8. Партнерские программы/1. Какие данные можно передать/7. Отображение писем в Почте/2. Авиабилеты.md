# Авиабилеты

> Source: https://yandex.ru/support/webmaster/ru/mail/flight

Письма, которые клиенты получают от вас, могут быть оформлены специальным образом в списке входящих сообщений. Для этого необходимо добавить в письмо информацию о бронировании или билете с помощью разметки [Schema.org](https://yandex.ru/support/webmaster/ru/schema-org/what-is-schema-org).

## Как разметить письма

1. Учтите [требования Яндекса](https://yandex.ru/support/mail/web/letter/create/send-many-letters.html) к массовым рассылкам. Убедитесь, что домен, с которого будут рассылаться письма, соответствует требованиям.
2. Используйте тип [FlightReservation](#svoystva-tipa-flightreservation-kotorye-podderzhivaet-yandeks-pochta) стандарта Schema.org, который поддерживает Яндекс Почта, и один из форматов описания данных: [Microdata](https://yandex.ru/support/webmaster/ru/schema-org/what-is-schema-org) и [JSON-LD](https://yandex.ru/support/webmaster/ru/json-ld/about).
3. Проверьте правильность разметки с помощью [валидатора](https://webmaster.yandex.ru/site/tools/microtest/).

Если вы выполнили все действия, но разметка не работает, напишите в форму внизу раздела:

1. Выберите тему «Виджеты (выделение писем в списке писем)».
2. В сообщении укажите домен, с которого будут рассылаться письма.
3. Дождитесь ответа службы поддержки.

## Примеры разметки

Вы можете использовать проверенные примеры для разметки ваших писем:

- Примеры в формате JSON-LD следует вставлять в элемент `head` в HTML-коде письма.
- Микроразметку добавьте как дополнительные атрибуты к элементам в HTML-коде письма.

### Подтверждение покупки билета

Письмо с подтверждением покупки билета обычно содержит маршрутную квитанцию.

JSON-LD:

```json
<script type="application/ld+json">
{  
  "@context": "http://schema.org",  
  "@type": "FlightReservation",  
  "reservationId": "RXJ34P",  
  "reservationStatus": "http://schema.org/Confirmed",  
  "reservationFor": 
  {    
    "@type": "Flight",    
    "flightNumber": "110",    
    "provider":     
    {            
     "@type": "Airline",            
     "name": "Aeroflot",            
     "iataCode": "SU"        
    },       
    "departureAirport": 
    {      
      "@type": "Airport",      
      "name": "Domodedovo",      
      "iataCode": "DME"    
    },    
    "departureTime": "2017-03-04T20:15:00-08:00",    
    "arrivalAirport": 
    {      
      "@type": "Airport",      
      "name": "Simferopol",      
      "iataCode": "SIP"    
    },    
    "arrivalTime": "2017-03-05T06:30:00-05:00"  
  }
}
</script>
```

## Свойства типа FlightReservation, которые поддерживает Яндекс Почта

### Обязательные

| Свойство | Тип | Описание |
|---|---|---|
| `reservationId` | [Text](https://schema.org/Text) | Номер бронирования. |
| `reservationStatus` | [ReservationStatus](https://schema.org/reservationStatus) | Статус бронирования. Возможные значения см. ниже. |
| `reservationFor` | [Flight](https://schema.org/Flight) | Информация о рейсе, на который пассажир забронировал билет. |
| `reservationFor.arrivalAirport` | [Airport](https://schema.org/Airport) | Информация об аэропорте назначения. Поле может содержать также значение типа [Text](https://schema.org/Text) (например, «Domodedovo»). |
| `reservationFor.arrivalAirport.iataCode` | [Text](https://schema.org/Text) | Код IATA аэропорта назначения (например, «SU»). |
| `reservationFor.arrivalAirport.name` | [Text](https://schema.org/Text) | Название аэропорта назначения. |
| `reservationFor.arrivalTime` | [DateTime](https://schema.org/DateTime) | Время прибытия рейса в аэропорт назначения. |
| `reservationFor.departureAirport` | [Airport](https://schema.org/Airport) | Информация об аэропорте отправления. Поле может содержать также значение типа [Text](https://schema.org/Text) (например, «Domodedovo»). |
| `reservationFor.departureAirport.iataCode` | [Text](https://schema.org/Text) | Код IATA аэропорта вылета рейса (например, «SU»). |
| `reservationFor.departureAirport.name` | [Text](https://schema.org/Text) | Название аэропорта отправления. |
| `reservationFor.departureTime` | [DateTime](https://schema.org/DateTime) | Время отправления рейса. |
| `reservationFor.flightNumber` | [Text](https://schema.org/Text) | Номер рейса. |

### Необязательные

| Свойство | Тип | Описание |
|---|---|---|
| `additionalTicketText` | [Text](https://schema.org/Text) | Дополнительная информация о посадочном талоне. |
| `boardingGroup` | [Text](https://schema.org/Text) | Информация о посадке, специфическая для авиакомпании. |
| `bookingAgent` | [Organization](https://schema.org/Organization) или [Person](https://schema.org/Person) | Информация об агенте, который бронирует билет. |
| `bookingAgent.name` | [Text](https://schema.org/Text) | Название или имя агента, который бронирует билет. |
| `bookingAgent.url` | [URL](https://schema.org/url) | Адрес сайта агента, который бронирует билет. |
| `bookingTime` | [DateTime](https://schema.org/DateTime) | Время бронирования билета. |
| `modifiedTime` | [DateTime](https://schema.org/DateTime) | Время последнего обновления данных рейса. |
| `potentialAction` | [ConfirmAction](https://schema.org/ConfirmAction), [CancelAction](https://schema.org/CancelAction) или [CheckInAction](https://schema.org/CheckInAction) | Возможные действия с бронью (например, подтверждение, отмена или регистрация). |
| `potentialAction.target` | [EntryPoint](https://schema.org/EntryPoint) | Указатель на действие при бронировании билета (обычно это ссылка на сайт). |
| `reservationFor.provider` | [Airline](https://schema.org/Airline) | Информация об авиакомпании, которая выполняет рейс. |
| `reservationFor.provider.name` | [Text](https://schema.org/Text) | Название авиакомпании. |
| `reservationFor.provider.iataCode` | [Text](https://schema.org/Text) | IATA-код авиакомпании. |
| `reservationFor.arrivalGate` | [Text](https://schema.org/Text) | Номер выхода в аэропорте прибытия. |
| `reservationFor.arrivalTerminal` | [Text](https://schema.org/Text) | Терминал аэропорта прибытия. |
| `reservationFor.boardingTime` | [DateTime](https://schema.org/DateTime) | Время начала посадки на рейс. |
| `reservationFor.departureGate` | [Text](https://schema.org/Text) | Номер выхода в аэропорте отправления. |
| `reservationFor.departureTerminal` | [Text](https://schema.org/Text) | Терминал аэропорта отправления. |
| `reservationFor.webCheckinTime` | [DateTime](https://schema.org/DateTime) | Время начала онлайн-регистрации на рейс. |
| `ticketDownloadUrl` | [URL](https://schema.org/url) | Адрес страницы, на которой можно загрузить посадочный талон. |
| `ticketNumber` | [Text](https://schema.org/Text) | Номер билета. |
| `ticketPrintUrl` | [URL](https://schema.org/url) | Адрес страницы, на которой можно распечатать посадочный талон. |
| `url` | [URL](https://schema.org/url) | Адрес страницы с информацией о бронировании. |

### Значения свойства reservationStatus

- `http://schema.org/ReservationConfirmed` — покупка билета подтверждена;
- `http://schema.org/ReservationCancelled` — рейс отменен;
- `http://schema.org/ReservationHold` — бронирование ожидает оплаты;
- `http://schema.org/ReservationPending` — бронирование ожидает подтверждения.
