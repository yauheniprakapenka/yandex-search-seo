# Интернет-покупки

> Source: https://yandex.ru/support/webmaster/ru/mail/order

Письма, которые клиенты получают от вас, могут быть оформлены специальным образом в списке входящих сообщений. Для этого необходимо добавить в письмо информацию о заказе с помощью разметки [Schema.org](https://yandex.ru/support/webmaster/ru/schema-org/what-is-schema-org).

Письмо об отмене заказа будет выделяться в списке писем серым цветом. Все предыдущие письма по этому заказу будут также выделены серым, если в них верно указан номер и статус заказа.

## Как разметить письма

1. Учтите [требования Яндекса](https://yandex.ru/support/mail/web/letter/create/send-many-letters.html) к массовым рассылкам. Убедитесь, что домен, с которого будут рассылаться письма, соответствует требованиям.
2. Используйте тип Order стандарта Schema.org, который поддерживает Яндекс Почта, и один из форматов описания данных: [Microdata](https://yandex.ru/support/webmaster/ru/schema-org/what-is-schema-org) и [JSON-LD](https://yandex.ru/support/webmaster/ru/json-ld/about).
   - Разметку в формате JSON-LD следует вставлять в элемент `head` в HTML-коде письма.
   - Микроразметку добавьте как дополнительные атрибуты к элементам в HTML-коде письма.
3. Проверьте правильность разметки с помощью [валидатора](https://webmaster.yandex.ru/site/tools/microtest/).

Если вы выполнили все действия, но разметка не работает, напишите в форму внизу раздела:

1. Выберите тему «Виджеты (выделение писем в списке писем)».
2. В сообщении укажите домен, с которого будут рассылаться письма.
3. Дождитесь ответа службы поддержки.

## Пример разметки письма с информацией о заказе

Чтобы уведомить клиента о том, что заказ подтвержден, укажите в разметке письма свойство *orderStatus* со значением `http://schema.org/OrderProcessing`. Если вы хотите сообщить о другом статусе заказа, выберите соответствующее значение свойства orderStatus.

JSON-LD:

```json
<script type="application/ld+json">
{
  "@context": "http://schema.org",
  "@type": "Order",
  "merchant": {
    "@type": "Organization",
    "name": "Страна чудес"
  },
  "orderNumber": "12345678",
  "orderStatus": "http://schema.org/OrderProcessing", 
  "priceCurrency": "RUB", 
  "price": "240",
  "expectedArrivalUntil": "2013-03-12T12:00:00-08:00",
  "trackingNumber": "3453291231",
  "trackingUrl": "http://example.com/track/3453291231",
  "url": "https://example.com/edit.html/orderID=12345678",
  "acceptedOffer": {
    "@type": "Offer",
    "itemOffered": {
      "@type": "Product",
      "name": "Ягодный чай от Шляпника"
    }
  }
}
</script>
```

Microdata:

```html
<div itemscope itemtype="http://schema.org/Order">
  <div itemprop="merchant" itemscope itemtype="http://schema.org/Organization">
    <meta itemprop="name" content="Страна чудес"/>
  </div>
  <link itemprop="orderStatus" href="http://schema.org/OrderProcessing"/>
  <meta itemprop="orderNumber" content="12345678"/>
  <meta itemprop="priceCurrency" content="RUB"/>
  <meta itemprop="price" content="240"/>
  <link itemprop="url" href="https://example.com/edit.html/orderID=12345678"/>
  <meta itemprop="expectedArrivalUntil" content="2013-03-12T12:00:00-08:00"/>
  <meta itemprop="trackingNumber" content="3453291231"/>
  <link itemprop="trackingUrl" href="http://example.com/track/3453291231"/>
  <div itemprop="acceptedOffer" itemscope itemtype="http://schema.org/Offer">
    <div itemprop="itemOffered" itemscope itemtype="http://schema.org/Product">
      <meta itemprop="name" content="Ягодный чай от Шляпника"/>
    </div>
    <meta itemprop="price" content="240"/>
    <meta itemprop="priceCurrency" content="RUB"/>
  </div>
</div>
```

## Свойства типа Order, которые поддерживает Яндекс Почта

| Свойство | Тип | Описание |
|---|---|---|
| `acceptedOffer` | [Offer](http://schema.org/Offer) | Продукты или бронирования услуг, включенные в заказ. |
| `acceptedOffer.itemOffered` | [Product](http://schema.org/Product) или [Reservation](http://schema.org/Reservation) | Конкретный продукт или бронирование услуги в заказе. |
| `acceptedOffer.itemOffered.name` | [Text](https://schema.org/Text) | Название продукта или услуги. |
| `expectedArrivalUntil` | DateTime | Ожидаемая дата доставки. |
| `merchant` | [Organization](http://schema.org/Organization) или [Person](http://schema.org/Person) | Тип продавца — магазин или частное лицо. Поле может также содержать строку (например, «Шляпник»). |
| `merchant.name` | [Text](https://schema.org/Text) | Имя (название) продавца. |
| `orderNumber` | [Text](https://schema.org/Text) | Номер заказа. |
| `orderStatus` | [OrderStatus](http://schema.org/OrderStatus) | Статус заказа. Возможные значения см. ниже. |
| `priceCurrency` | [Text](https://schema.org/Text) | Валюта. |
| `price` | [Number](http://schema.org/Number) или [Text](https://schema.org/Text) | Стоимость продукта или сумма заказа. |
| `trackingNumber` | [Text](https://schema.org/Text) | Номер отслеживания заказа. |
| `trackingUrl` | [URL](http://schema.org/URL) | Ссылка на страницу отслеживания заказа. |
| `url` | [URL](http://schema.org/URL) | Ссылка на страницу заказа или личный кабинет. |

### Значения свойства orderStatus

- `http://schema.org/OrderProcessing` — заказ подтвержден и обрабатывается;
- `http://schema.org/OrderCancelled` — заказ отменен;
- `http://schema.org/OrderDelivered` — заказ доставлен;
- `http://schema.org/OrderInTransit` — заказ доставляется;
- `http://schema.org/OrderPaymentDue` — срок оплаты заказа истекает;
- `http://schema.org/OrderPickupAvailable` — возможен самовывоз;
- `http://schema.org/OrderProblem` — проблема с заказом;
- `http://schema.org/OrderReturned` — заказ возвращен.
