# Отображение даты в сниппете

> Source: https://yandex.ru/support/webmaster/ru/search-results/date

Дата публикации полезна для новостных сообщений или записей в блогах. С ней пользователю проще понять, насколько актуальна информация на странице.

Есть два способа передавать Яндексу дату публикации: через URL или метатег `article:published_time`. Можно использовать оба способа одновременно.

**URL**

Настройте формирование URL так, чтобы в нем присутствовала дата. Она может содержаться в виде определенного шаблона, например:

- `/yyyy/mm/dd/`
- `/yyyy-mm-dd/`

**Метатег**

Используйте на странице специальный метатег `article:published_time`.

Например: `<meta name='article:published_time' content='2023-10-07T00:00:00+03:00'/>`. Дата указывается в формате [ISO 8601](https://ru.wikipedia.org/wiki/ISO_8601).

При индексировании страниц поисковый робот извлечет указанные даты. После этого они могут использоваться в поисковой выдаче.
