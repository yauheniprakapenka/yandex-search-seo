# Фавиконка

> Source: https://yandex.ru/support/webmaster/ru/search-results/favicon

- [Как установить фавиконку](#как-установить-фавиконку)
- [Как фавиконка может отображаться на сервисах Яндекса](#как-фавиконка-может-отображаться-на-сервисах-яндекса)
- [Как изменить или удалить фавиконку](#как-изменить-или-удалить-фавиконку)

Фавиконка — это небольшая картинка, которая может отображаться:

- в [сниппете](https://yandex.ru/support/webmaster/ru/search-results/site-description);
- в результатах поиска Яндекса;
- рядом с адресом сайта в адресной строке браузера;
- рядом с названием сайта в **Избранном** или в **Закладках** браузера.

Она помогает пользователям быстрее находить ваш сайт и повышает его узнаваемость в поисковой выдаче.

## Как установить фавиконку

### Шаг 1. Разместите фавиконку на сайте

1. Поместите файл с именем `favicon` в корневой каталог сайта.

   **Рекомендации по формату, размеру и виду фавиконки**

   Размер: 120 × 120, 32 × 32 или 16 × 16 пикселей.

   Формат: SVG (рекомендуется), ICO, GIF, JPEG, PNG, BMP. Анимация не поддерживается.

   > **Совет**
   >
   > Размер 120 × 120 пикселей или формат SVG позволяют отображать логотип сайта четче и заметнее на сервисах Яндекса.

2. Добавьте в HTML-код главной страницы сайта, в элемент `head`, ссылку на размещенный файл.

   ```html
   <head>
       ...
       <link rel="icon" href="https://example.com/favicon.ico" type="image/x-icon">
       ...
   </head>
   ```

   | Атрибут | Описание | Возможные значения |
   | --- | --- | --- |
   | `rel` | Тип ресурса | `icon`; `shortcut icon`. |
   | `href` | Адрес файла | Для описания кириллического адреса фавиконки используйте [Punycode](https://ru.wikipedia.org/wiki/Punycode). Например, для адреса `https://мой-сайт.рф/favicon.ico` нужно указать `https://xn----8sbzclmxk.xn--p1ai/favicon.ico`. |
   | `type` | Тип передаваемых данных. Зависит от формата файла | `image/svg+xml` — для формата SVG; `image/x-icon` или `image/vnd.microsoft.icon` — для формата ICO; `image/gif` — для формата GIF; `image/jpeg` — для формата JPEG; `image/png` — для формата PNG; `image/bmp` — для формата BMP. |

   Если в HTML-коде страницы ссылка на фавиконку прописана несколько раз, робот может выбрать любую из этих фавиконок.

3. Проверьте, отображается ли фавиконка в браузере при просмотре страниц сайта.

### Шаг 2. Проверьте доступность фавиконки для робота Яндекса

1. Убедитесь, что:
   - Файл доступен по прямой ссылке (ответ сервера 200 OK) — воспользуйтесь инструментом [Проверка ответа сервера](https://webmaster.yandex.ru/tools/server-response/).
   - Файл не запрещен для индексирования (например в `robots.txt` с помощью директивы [Disallow](https://yandex.ru/support/webmaster/ru/robot-workings/allow-disallow#disallow)). Может быть запрещен не сам файл, а каталог, в котором он размещается.
2. Внесите изменения, если это необходимо.
3. Проверьте, что робот загрузил файл. Это может произойти, когда робот посетит ваш сайт. В течение нескольких дней после добавления фавиконки на сайт перейдите в Яндекс Вебмастер, на страницу **Оптимизация сайта** → **Диагностика сайта**. Если на странице отображается предупреждение о проблемах с фавиконкой, следуйте указаниям:

   | Ошибка | Решение |
   | --- | --- |
   | Файл отвечает HTTP-кодом, отличным от 200 OK | [Проверьте ответ сервера](https://webmaster.yandex.ru/tools/server-response/). Ответ должен соответствовать 200 OK. Другие статусы ответа см. в разделе [Проверка ответа сервера](https://yandex.ru/support/webmaster/ru/indexing-options/server-response). |
   | Файл перенаправляет на другой адрес | |
   | Неправильный тип данных | Проверьте значение параметра `type` в ссылке на файл. Он должен соответствовать формату файла. |

   Чтобы убедиться, что фавиконка загружена, на странице **Оптимизация сайта** → **Диагностика сайта** нажмите **Посмотреть всё, что проверяет Вебмастер** и найдите предупреждение о фавиконке. Если отображается статус **Всё в порядке**, значит робот обработал файл.

### Шаг 3. Проверьте отображение фавиконки в выдаче

Если робот загрузил фавиконку, она появится в результатах поиска в течение двух недель.

Чтобы фавиконка корректно отображалась в поисковой выдаче, рекомендуем выбрать изображение, которое будет выглядеть одинаково хорошо в темной и светлой темах оформления. Цвет фона фавиконки не всегда влияет на отображение и может быть как прозрачным, так и заполненным.

## Как фавиконка может отображаться на сервисах Яндекса

Для отображения может использоваться любая фавиконка, если она доступна для робота и отвечает требованиям сервиса, на котором должна быть показана. Так, если на сайте есть фавиконки разных размеров или форматов, сервисы Яндекса могут использовать любую из них.

Робот может скачать фавиконку в том числе из тега [apple-touch-icon](https://developer.apple.com/library/archive/documentation/AppleApplications/Reference/SafariWebContent/ConfiguringWebApplications/ConfiguringWebApplications.html).

Если во время обхода сайт недоступен для робота, в поисковой выдаче вместо вашей фавиконки может отобразиться фавиконка вашего хостинга.

## Как изменить или удалить фавиконку

Чтобы фавиконка изменилась в результатах поиска, обновите файл фавиконки на сайте.

Чтобы удалить фавиконку из поиска, удалите файл с сайта. Изменения заработают в течение двух недель после очередного посещения сайта роботом.

Чтобы изменения быстрее появились в результатах поиска, отправьте главную страницу сайта (где [размещена](#шаг-1-разместите-фавиконку-на-сайте) ссылка на фавиконку) на [переобход](https://yandex.ru/support/webmaster/ru/robot-workings/site-reindex): перейдите в Яндекс Вебмастер на страницу **Индексирование** → **Переобход страниц**. Фавиконка обновится в результатах поиска в течение трех дней.
