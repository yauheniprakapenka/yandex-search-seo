# Настройка событий для дополненного представления в поиске Яндекса

> Source: https://yandex.ru/support/webmaster/ru/feed/goals

- [События в Метрике для отслеживания действий посетителей](#события-в-метрике-для-отслеживания-действий-посетителей)

Сайт привлекает больше посетителей, если отвечает на их запросы. Насколько хорошо сайт решает задачи посетителей, можно отслеживать с помощью специальных событий. Например, как часто посетители заказывают обратный звонок или оформляют заказ.

Перечисленные ниже события помогают более точно отслеживать важные действия на вашем сайте. Для каждой категории бизнеса подобраны наиболее подходящие ей события. Они учитываются при [формировании дополненного представления](https://yandex.ru/support/webmaster/ru/feed/about) в поисковой выдаче Яндекса.

Для отслеживания событий нужно создать соответствующие [цели](https://yandex.ru/support/metrica/general/goals.html) в Яндекс Метрике:

1. Убедитесь, что на вашем сайте установлен счетчик Метрики. Если нет, [создайте и установите его](https://yandex.ru/support/metrica/quick-start.html).
2. Настройте [цель типа JavaScript-событие](https://yandex.ru/support/metrica/general/goal-js-event.html). В качестве идентификатора цели используйте значение из таблицы ниже.

Данные начнут передаваться в Метрику, когда посетители сайта будут выполнять целевые действия.

## События в Метрике для отслеживания действий посетителей

Выберите категорию бизнеса, к которой относится ваш сайт:

### Услуги

| Событие | Идентификатор цели |
|---|---|
| Посетитель открыл форму заявки | `ym-open-leadform` |
| Посетитель заполнил и отправил заявку | `ym-submit-leadform` |
| Посетитель получил отклик на заявку | `ym-get-response` |
| Посетитель связался с исполнителем | `ym-contact-constractor` |
| Посетитель открыл чат | `ym-open-chat` |
| Посетитель отправил сообщение в чате | `ym-send-message` |
| Посетитель посмотрел контакты исполнителя | `ym-show-contacts` |
| Посетитель договорился с исполнителем | `ym-agree-constractor` |
| Исполнитель выполнил услугу | `ym-complete-order` |

### Недвижимость

| Событие | Идентификатор цели |
|---|---|
| Посетитель зарегистрировался на сайте | `ym-register` |
| Посетитель посмотрел контакты | `ym-show-contacts` |
| Посетитель заполнил контактную информацию | `ym-submit-contacts` |
| Посетитель оставил заявку на размещение объявления | `ym-submit-leadform` |
| Посетитель написал в чат | `ym-send-message` |
| Заявка на размещение объявления подтверждена | `ym-successful-lead` |
| Посетитель получил отклик на объявление | `ym-get-response` |
| Посетитель договорился о встрече с арендодателем | `ym-agree-meeting` |
