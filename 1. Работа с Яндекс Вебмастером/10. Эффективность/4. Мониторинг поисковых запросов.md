# Мониторинг поисковых запросов

> Source: https://yandex.ru/support/webmaster/ru/service/popular-queries

С помощью Яндекс Вебмастера можно узнать, по каким поисковым запросам ваш сайт уже отображается в результатах поиска Яндекса. Для одного сайта доступно до 150 000 запросов.

Данные сгруппированы по поисковым запросам и URL.

**По поисковым запросам**

Чтобы увидеть показы по запросам, вверху таблицы выберите **Запрос**. Под каждым запросом отображается самый высокочастотный по показам URL для этого запроса.

**По URL**

Чтобы увидеть показы по URL, вверху таблицы выберите **URL**. Под каждым URL отображается самый высокочастотный запрос для этого URL.

Для работы с поисковыми запросами в Вебмастере доступны следующие показатели:

**Показы**

Появление ссылки на сайт в результатах поиска Яндекса по некоторому запросу. Показом не является потенциальное появление ссылки на второй и последующих страницах результатов поиска, если пользователь эти страницы не открывал.

Статистика показов включает данные из *органической выдачи* и *динамических мест*.

**Клики**

Переход посетителя на сайт со страницы результатов поиска Яндекса.

Статистика кликов включает данные из *органической выдачи* и *динамических мест*.

**CTR**

Отношение числа кликов на сниппет к числу его показов, измеряется в процентах. Можно сказать, что этот показатель говорит о привлекательности сниппета страницы сайта.

**Позиция**

Место, на котором появляется ссылка на сайт в поисковой выдаче Яндекса в ответ на поисковый запрос пользователя.

Информация о позиции сайта может отсутствовать, если в заданный период:

- сайт не отображался в результатах поиска по указанному поисковому запросу;
- указанный поисковый запрос не был ни разу введен;
- пользователи не нашли сайт в результатах поиска.

Чтобы определить причину отсутствия информации о позиции сайта, обратите внимание на показатель **Спрос**. Если он равен нулю, пользователи не вводили поисковый запрос. Если значение больше нуля, но позиция не определена, вероятно, пользователи не нашли сайт в результатах поиска или его нет по поисковому запросу.

**Спрос**

Показывает, насколько часто пользователи Яндекса задают поисковый запрос. Если сайт отображается на первой странице больше одного раза, сумма показов сайта может оказаться больше спроса. Например, для навигационных запросов, где пользователь ищет конкретный сайт и поисковая система показывает несколько результатов с одного сайта.

> **Примечание**
>
> При просмотре статистики по URL данные по спросу не отображаются — спрос доступен в разрезе поисковых запросов. Фильтрация по спросу также работает только при просмотре статистики по запросам.

Данные по показателям отображаются на графике. Вы можете добавить показатель или построить график по каждому показателю отдельно.

Чтобы посмотреть данные за конкретную дату, наведите на нее указатель. Рядом с ним появится подсказка с информацией по показателям на эту дату.

## Фильтрация

Чтобы получить более детальную статистику по запросам в разных разрезах, используйте следующие виды фильтрации:

### Фильтрация по поисковым запросам

Если нужно выбрать или исключить запросы с определенными словами, используйте фильтры «включает», «не включает» или «точное соответствие». Чтобы задать более сложные условия, можно использовать [регулярные выражения](https://yandex.ru/support/webmaster/ru/service/regexp).

Фильтр «содержится в группе» можно использовать, чтобы отфильтровать строки, соответствующие ранее созданным группам запросов (поддерживаются только группы из списка запросов и группы, созданные одним или несколькими фильтрами на текст запроса).

В результате при добавлении фильтра по поисковым запросам в таблице отобразятся:

- в представлении **Запрос** — все запросы, которые соответствуют условию, с самыми высокочастотными страницами для них;
- в представлении **URL** — все страницы, которые отображаются в результатах поиска по указанным запросам.

### Фильтрация по URL страниц

Чтобы увидеть данные по конкретной странице или группе страниц, тоже можно использовать опции «включает», «не включает», «точное соответствие» или [регулярные выражения](https://yandex.ru/support/webmaster/ru/service/regexp). Во всех случаях условие применяется к внутреннему пути страницы: без указания протокола, префикса, домена.

В результате при добавлении фильтра по URL в таблице отобразятся:

- в представлении **Запрос** — все запросы, по которым в результатах поиска отображаются указанные страницы. При этом страницы могут отображаться в результатах поиска по разным запросам. При использовании фильтра по URL в представлении **Запрос** в выборку попадут URL с высокочастотными запросами, даже если вы отфильтровали их;
- в представлении **URL** — все страницы, которые соответствуют условию, с самыми высокочастотными запросами для них.

### Фильтрация по показателям

Для показов, кликов, позиции, CTR и спроса можно указать условие (больше, больше или равно, меньше, меньше или равно, равно) в заданном интервале дат. В результате в таблице останутся только строки, в которых показатель соответствовал условию за все даты выбранного интервала.

### Фильтрация по временному интервалу

Чтобы получить данные за определенный период, используйте фильтр **Интервал мониторинга**. В нем можно выбрать следующие временные интервалы:

- последние две недели с детализацией данных по дням;
- последние 18 месяцев, для каждого из которых рассчитано среднее значение.

Если на сайте несколько страниц, которые релевантны запросу:

- клики и показы суммируются;
- позиция в поиске считается как средняя;
- CTR рассчитывается по общей сумме кликов и показов.

> **Примечание**
>
> При просмотре статистики по URL данные по спросу не отображаются — спрос доступен в разрезе поисковых запросов. Фильтрация по спросу также работает только при просмотре статистики по запросам.

## Что можно делать с помощью мониторинга

Мониторинг поисковых запросов помогает следить за видимостью сайта в поиске:

### Проверить динамику позиций сайта

1. Выберите показатель **Позиция**.
2. (Опционально) Укажите регион, в котором продвигаете сайт.
3. (Опционально) Выберите тип устройства пользователей Поиска Яндекса, например, если проверяете мобильную версию сайта.

### Сравнить динамику показов и спроса

Это поможет понять, является ли изменение видимости сайта в поиске следствием сезонного изменения спроса.

1. Выделите сегмент запросов или URL страниц, которые хотите сравнить.
2. Выберите показатели **Спрос** и **Показы** и сравните данные. Для удобства можно использовать выгрузку в формате XLS.

### Найдите запросы, набирающие популярность

1. Выделите нужный сегмент запросов или страниц.
2. Выберите показатель **Спрос** и посмотрите динамику популярности запросов. Для удобства можно использовать выгрузку в формате XLS.

---

> *Органическая выдача* — стандартные показы сниппетов в результатах поисковой выдачи.
>
> *Динамические места* — дополнительные места в выдаче, на которых могут показаться объявления из Директа. Дают возможность получать дополнительные клики и конверсии за счет повышения видимости страницы. Подробнее — в [Справке Директа](https://yandex.ru/support/direct/ru/general/dynamic-places).
