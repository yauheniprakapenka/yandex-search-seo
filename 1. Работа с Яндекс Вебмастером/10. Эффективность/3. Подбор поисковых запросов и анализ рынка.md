Вебмастер поможет вам подобрать целевые ключевые слова и быстро погрузиться в конкурентную среду, что упростит и ускорит продвижение сайта.

> **Примечание**
>
> Вебмастер показывает сотни миллионов уникальных запросов. Характеристики запросов (спрос, клики и конкурентность) представляют среднемесячные значения за прошлый год. Популярность и позиции сайтов и страниц в поиске по подобранным запросам представляют усредненные значения за прошедший месяц. Данные обновляются ежемесячно.

## Для чего

**Подбор поисковых запросов**

Инструмент поможет:

- по ключевому слову подобрать для вас подходящие запросы среди сотен миллионов уникальных запросов пользователей поиска;
- найти дополнительные запросы, которые содержат неочевидные ключевые слова и формулировки;
- проанализировать потенциал запросов и выбрать самые удачные формулировки для продвижения вашего сайта.

**Анализ рынка**

Инструмент поможет:

- найти страницы, которые уже популярны по этим запросам в поиске;
- оценить, подходит ли вам эта ниша;
- изучить и перенять опыт коллег по рынку.

## Для кого

Подбор поисковых запросов упростит вам работу, если вы:

- маркетолог и занимаетесь продвижением товаров и услуг в интернете;
- специалист по поисковой оптимизации;
- специалист онлайн-рекламы и digital-маркетинга.

## Как использовать

### Одиночный запрос

**Подберите запросы**

1. В поле **Одиночный запрос** введите основные слова запроса, которые характеризуют вашу нишу.

   Чтобы в результатах подборки отображалась определенная форма слова, используйте символ `!` перед запросом.

   Если запрос состоит из нескольких слов, ставьте восклицательный знак перед каждым словом, форму которого не хотите изменять. Например, `!купить !моющий !пылесос`.

2. В поле **Слова-минус** добавьте стоп-слова, чтобы исключить нецелевые для вас запросы.

   Например, если вы занимаетесь розничной продажей новых пылесосов и не хотите видеть в подборке запросы об оптовых продажах, продажах подержанных пылесосов или инструкциях к пылесосам, добавьте стоп-слова «опт», «б/у», «инструкции».

   Если вы хотите, чтобы форма слова не менялась, используйте восклицательный знак `!`.

3. Опционально: выберите регион и тип устройства, для которого вы будете проводить анализ.
4. В блоке **Запросы пользователей** на вкладке **Основные** просмотрите популярные запросы. Они включают ключевые слова, которые вы искали. Вебмастер отсортировал их по убыванию количества переходов.

   Вы можете нажать на интересующие запросы: после этого вы будете перенаправлены на страницу с уточненной подборкой.

   Рядом с запросами находятся четыре столбца:

   **Кластер**

   Показывает самый частотный запрос из кластера по количеству показов.

   > **Примечание**
   >
   > *Кластеризация* — это автоматическая группировка поисковых запросов, которые близки по смыслу или по интенту (намерению пользователя). Используйте кластеры запросов для продвижения сайта в поисковой выдаче по выбранной тематике.

   **Конкурентность**

   Помогает отличить высококонкурентные запросы от менее конкурентных при продвижении сайтов в топ-10 результатов поиска:

   - высокая — красный;
   - умеренная — желтый;
   - низкая — зеленый;
   - нет данных — серый.

   **Спрос**

   Показывает, *сколько раз* пользователи делали такой запрос.

   **Клики**

   Показывает, *сколько* пользователей переходит по ссылкам в результатах поиска.

   Спрос, клики и конкурентность помогут выбрать ключевые слова для оптимизации и продвижения сайта.

5. Изучите запросы на вкладке **Дополнительные**. Они помогут вам найти неочевидные запросы, например, «пылесос с влажной уборкой» как дополнение к запросу «моющий пылесос».

**Оцените нишу**

В блоке **Популярные сайты в поиске Яндекса** в разделе **Сайты** посмотрите список популярных сайтов, чтобы проанализировать рынок.

Оцените, насколько подборка сайтов соответствует вашей нише.

**Перенимайте опыт**

1. Изучите подборку популярных страниц.
2. Проанализируйте данные о популярных сайтах.

   Используйте и адаптируйте эти данные, чтобы оптимизировать и продвигать свой сайт.

### Запрос по группе URL

**Подберите запросы**

1. В поле **Запрос по группе URL** введите список URL, которые вас интересуют. URL следует указывать только от подтвержденных вами сайтов. Можно добавить до 50 URL.
2. Опционально: выберите регион и тип устройства, для которого вы будете проводить анализ.

**Оцените нишу**

В блоке **Популярные сайты в поиске Яндекса** в разделе **Сайты** посмотрите список популярных сайтов, чтобы проанализировать рынок.

Оцените, насколько подборка сайтов соответствует вашей нише.

**Перенимайте опыт**

1. Изучите подборку популярных страниц.

   В разделе **Страницы** рядом с URL-адресами есть столбец **Запросы**. В нем показана подборка поисковых запросов, по которым страница появлялась в результатах поиска за последний месяц. Запросы разделены на основные и дополнительные. Чтобы увидеть подборку, кликните на число запросов в столбце.

2. Проанализируйте данные о популярных сайтах.

   Используйте и адаптируйте эти данные, чтобы оптимизировать и продвигать свой сайт.
