# Статистика страниц в поиске

> Source: https://yandex.ru/support/webmaster/ru/service/urls

- [Доступные показатели](#доступные-показатели)
- [Какие задачи можно решить с помощью статистики страниц](#какие-задачи-можно-решить-с-помощью-статистики-страниц)

С помощью Вебмастера вы можете узнать, насколько хорошо страницы сайта привлекают посетителей из результатов поиска Яндекса. Эта информация поможет оценить эффективность [сниппетов страниц](https://yandex.ru/support/webmaster/ru/search-results/site-description) и сделать их более информативными при необходимости.

В Вебмастере отображаются первые 3000 страниц сайта не ниже 50 позиции в поисковой выдаче.

Статистика доступна на странице **Эффективность** → **Статистика страниц**.

## Доступные показатели

Для анализа можно использовать множество показателей. По умолчанию отображается несколько:

- *показы*
- *клики*
- *CTR*

Статистика показов и кликов включает данные из *органической выдачи* и *динамических мест*.

Данные обновляются ежедневно. Представленная в Вебмастере статистика может отличаться от данных других сервисов Яндекса. О расчете и отображении показателей см. в разделе [Аналитика поисковых запросов](https://yandex.ru/support/webmaster/ru/service/queries-analytic).

## Какие задачи можно решить с помощью статистики страниц

### Узнать, на какие страницы сайта чаще переходят в определенном регионе

1. Выберите регион из списка. В списке представлены регионы, в которых был хотя бы один показ сайта на первых 50 позициях в результатах поиска. Регионы отсортированы по количеству показов.
2. Отсортируйте данные по кликам.

### Определить, сниппеты каких страниц эффективнее на разных устройствах пользователей

1. Выберите тип устройства из списка **Все устройства**.
2. Отсортируйте данные по кликам или CTR.

### Оценить эффективность определенной страницы сайта

Указать страницу можно несколькими способами:

**Выбрать из списка «Все страницы»**

Начните вводить адрес страницы или выберите ее из списка.

**Нажать на адрес страницы в таблице отчета**

Нажмите на адрес страницы в таблице отчета.

При просмотре отчета по выбранной странице в нем отобразятся все показатели, доступные в Вебмастере.

### Сравнить страницы по одному показателю

Выберите из списка показатель, по которому хотите построить отчет. Например, *средняя позиция*.

> **Совет**
>
> Если вы заметили, что позиция сайта или число показов снизилось, посмотрите, как можно [определить причину изменений](https://yandex.ru/support/webmaster/ru/site-indexing/rank-diy).

---

> *Показ* — появление ссылки на сайт в результатах поиска Яндекса по некоторому запросу. Показом не является потенциальное появление ссылки на второй и последующих страницах результатов поиска, если пользователь эти страницы не открывал.
>
> *Клик* — переход посетителя на сайт со страницы результатов поиска Яндекса.
>
> *CTR* — отношение числа кликов на сниппет к числу его показов, измеряется в процентах. Можно сказать, что этот показатель говорит о привлекательности сниппета страницы сайта.
>
> *Позиция сайта* — номер на страницах результатов поиска Яндекса, которому соответствует ссылка, ведущая на ваш сайт. В течение дня сайт может занимать разные позиции по одной поисковой фразе, поэтому сервис показывает среднее значение за весь день.
>
> *Органическая выдача* — стандартные показы сниппетов в результатах поисковой выдачи.
>
> *Динамические места* — дополнительные места в выдаче, на которых могут показаться объявления из Директа. Дают возможность получать дополнительные клики и конверсии за счет повышения видимости страницы. Подробнее — в [Справке Директа](https://yandex.ru/support/direct/ru/general/dynamic-places).
