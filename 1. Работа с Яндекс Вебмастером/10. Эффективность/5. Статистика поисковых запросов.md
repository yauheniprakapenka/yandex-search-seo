# Статистика поисковых запросов

> Source: https://yandex.ru/support/webmaster/ru/service/statistics

- [Какие задачи можно решить с помощью статистики запросов](#какие-задачи-можно-решить-с-помощью-статистики-запросов)
  - [Узнайте больше](#узнайте-больше)

[Статистика поисковых запросов](https://webmaster.yandex.ru/site/search/statistics/) помогает следить за состоянием сайта в поисковой выдаче, например:

- отслеживать динамику *средней позиции сайта*;
- узнавать, какие запросы приводят больше трафика на сайт.

При анализе можно учесть регион, в котором вы продвигаете сайт, а также тип устройства пользователя.

Статистика отображается по группам запросов. Вы можете формировать заданные сервисом группы, создавать собственные, а также добавлять поисковые запросы в Вебмастер.

| Название | Описание | Анализ определенного запроса |
|---|---|---|
| **Группа** | Содержит статистику по группам запросов, заданным сервисом и сформированным вручную на странице [Управление группами поисковых запросов](https://yandex.ru/support/webmaster/ru/service/search-queries). | — |
| **Популярные запросы** | Содержит статистику по фразам с наибольшим количеством показов, по которым сайт отображался в результатах поиска за последние три месяца (учитываются первые 3000 запросов). | **Избранные запросы** |
| **Избранные запросы** | Содержит статистику по фразам из группы [Избранные](https://yandex.ru/support/webmaster/ru/service/search-queries#group). Добавляйте в эту группу наиболее важные запросы, чтобы получать детальную статистику по ним. | |

Для анализа доступно множество показателей, по умолчанию отображается несколько:

- *показы*
- *клики*
- *CTR*

Статистика показов и кликов включает данные из *органической выдачи* и *динамических мест*.

Данные обновляются ежедневно. Представленная в Вебмастере статистика может отличаться от данных других сервисов Яндекса. О расчете и отображении показателей см. в разделе [Аналитика поисковых запросов](https://yandex.ru/support/webmaster/ru/service/queries-analytic).

## Какие задачи можно решить с помощью статистики запросов

### Узнать, какие запросы приводят больше трафика на сайт

Чтобы сориентироваться, какая группа запросов приводит больше посетителей на сайт, обратите внимание на CTR.

### Отследить динамику средней позиции сайта

Чтобы увидеть общую динамику показателя, выберите из списка **Ср. позиция**. Чтобы отследить динамику по определенным запросам, выберите группу **Популярные запросы** или **Избранные**.

### Узнать статистику в определенном регионе

Выберите из списка регион, в котором отслеживаете данные. В списке представлены регионы, в которых был хотя бы один показ сайта на первых 50 позициях в результатах поиска. Регионы отсортированы по количеству показов.

### Отследить все показатели по группе запросов

Нажмите на название группы или выберите ее из списка. Чтобы отследить показатели по одному запросу, выберите группу **Популярные запросы** или **Избранные**.

> **Совет**
>
> Если вы заметили, что позиция сайта или число показов снизилось, посмотрите, как можно [определить причину изменений](https://yandex.ru/support/webmaster/ru/site-indexing/rank-diy).

---

> *Показ* — появление ссылки на сайт в результатах поиска Яндекса по некоторому запросу. Показом не является потенциальное появление ссылки на второй и последующих страницах результатов поиска, если пользователь эти страницы не открывал.
>
> *Клик* — переход посетителя на сайт со страницы результатов поиска Яндекса.
>
> *CTR* — отношение числа кликов на сниппет к числу его показов, измеряется в процентах. Можно сказать, что этот показатель говорит о привлекательности сниппета страницы сайта.
>
> *Позиция сайта* — номер на страницах результатов поиска Яндекса, которому соответствует ссылка, ведущая на ваш сайт. В течение дня сайт может занимать разные позиции по одной поисковой фразе, поэтому сервис показывает среднее значение за весь день.
>
> *Органическая выдача* — стандартные показы сниппетов в результатах поисковой выдачи.
>
> *Динамические места* — дополнительные места в выдаче, на которых могут показаться объявления из Директа. Дают возможность получать дополнительные клики и конверсии за счет повышения видимости страницы. Подробнее — в [Справке Директа](https://yandex.ru/support/direct/ru/general/dynamic-places).
