# Проблемы, связанные с оптимизацией сайта для мобильных устройств

> Source: https://yandex.ru/support/webmaster/ru/diagnosis/mobile

Просмотрите [рекомендации по оптимизации сайтов для мобильных устройств](https://yandex.ru/support/webmaster/ru/recommendations/mobile-site).

| Описание проблемы в интерфейсе | Решение |
| --- | --- |
| Сайт не может быть признан оптимизированным для мобильных устройств, поскольку не оптимизирована главная страница. | Посмотрите детальную информацию по ситуации в Вебмастере на странице **Инструменты** → **Проверка мобильных страниц**. Здесь можно проверять на оптимизацию для мобильных устройств отдельные страницы вашего сайта. |
| Сайт не может быть признан оптимизированным для мобильных устройств, поскольку не удалось загрузить главную страницу для проверки. Проверьте настройки сервера и при необходимости обратитесь к хостинг-провайдеру. | Скорее всего, в момент проверки главной страницы сайта страница была недоступна.<br><br>Проверьте главную страницу сайта с помощью инструмента **Инструменты** → **Проверка мобильных страниц**. Если данная проверка будет пройдена успешно, отправьте сайт на перепроверку на странице **Оптимизация сайта** → **Диагностика сайта**: нажмите кнопку **Проверить** около рекомендации «Сайт не оптимизирован для мобильных устройств». |
| Сайт не может быть признан оптимизированным для мобильных устройств, поскольку удалось загрузить менее 90% запрошенных для проверки страниц. Проверьте настройки сервера и при необходимости обратитесь к хостинг-провайдеру. | Скорее всего, в момент проверки страниц сайта они были недоступны.<br><br>Запустите проверку отдельных страниц с помощью инструмента **Инструменты** → **Проверка мобильных страниц**. Если данная проверка будет пройдена успешно, отправьте сайт на перепроверку на странице **Оптимизация сайта** → **Диагностика сайта**: нажмите кнопку **Проверить** около рекомендации «Сайт не оптимизирован для мобильных устройств». |
| Многие страницы не оптимизированы для мобильных устройств. | Для признания сайта оптимизированным под мобильные устройства алгоритмами допускается определенный порог неоптимизированных страниц, который вычисляется динамически в зависимости от количества проиндексированных страниц вашего сайта.<br><br>Если вы видите данное сообщение, значит для сайта этот порог был превышен. Рекомендуем внести правки на страницы из представленного в интерфейсе списка.<br><br>После внесения изменений проверьте отдельные страницы с помощью инструмента **Инструменты** → **Проверка мобильных страниц**. Если данная проверка будет пройдена успешно, отправьте сайт на повторную проверку на странице **Оптимизация сайта** → **Диагностика сайта**: нажмите кнопку **Проверить** около рекомендации «Сайт не оптимизирован для мобильных устройств». |
| Многие страницы с различным контентом перенаправляют на одну и ту же страницу мобильной версии сайта. | Не рекомендуем устанавливать перенаправление с ряда страниц основной версии сайта на одну и ту же страницу мобильной версии, так как это может ввести в заблуждение посетителей мобильных ресурсов.<br><br>В Вебмастере указан список страниц, которые, имея различное содержание, перенаправляют на одну и ту же страницу мобильной версии.<br><br>В данной ситуации рекомендуем устанавливать перенаправление страниц на соответствующие страницы мобильной версии. Если это невозможно (например, весь контент с нескольких страниц собран на одной странице мобильной версии), то можно оставить перенаправление только с главной страницы или с тех страниц, для которых это сделать приемлемо. |
| Не удалось загрузить страницы для проверки, сайт не может быть признан оптимизированным для мобильных устройств. | Это значит, что мобильный робот Яндекса не смог получить доступ к страницам вашего сайта. Проверьте:<br><br>- [Ответ сервера](https://webmaster.yandex.ru/tools/server-response/) при обращении к страницам сайта.<br>- Файл [robots.txt](https://yandex.ru/support/webmaster/ru/controlling-robot/robots-txt). В нем может быть указан запрет на индексирование для мобильного робота. В логах сервера мобильный робот Яндекса представляется так: `Mozilla/5.0 (iPhone; CPU iPhone OS 8_1 like Mac OS X) AppleWebKit/600.1.4 (KHTML, like Gecko) Version/8.0 Mobile/12B411 Safari/600.1.4 (compatible; YandexMobileBot/3.0; +http://yandex.com/bots)`. |
| В поиске нет пригодных для проверки страниц, поэтому сайт невозможно проверить и признать оптимизированным для мобильных устройств. | Обратитесь в службу поддержки для помощи по данному вопросу. |
