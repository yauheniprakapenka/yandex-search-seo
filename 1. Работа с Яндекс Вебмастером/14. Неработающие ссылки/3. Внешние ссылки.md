# Внешние ссылки

> Source: https://yandex.ru/support/webmaster/ru/site-indexing/external-links

- [Просмотр информации](#просмотр-информации)
- [Фильтрация данных](#фильтрация-данных)
- [Вопросы и ответы](#вопросы-и-ответы)

На странице [Внешние ссылки](https://webmaster.yandex.ru/site/links/incoming/) представлен список неработающих [внешних ссылок](https://yandex.ru/support/webmaster/ru/service/glossary#external-link), которые ведут на ваш сайт с других сайтов. Робот Яндекса регулярно проверяет наличие и работоспособность внешних ссылок.

Информация о неработающих внешних ссылках представлена в виде таблицы и может включать в себя:

- URL страницы, на которой установлена ссылка на ваш сайт;
- [ИКС ресурса](https://yandex.ru/support/webmaster/ru/site-quality-index);
- URL страницы, на которую ведет ссылка;
- HTTP-статус — [4xx](https://yandex.ru/support/webmaster/ru/error-dictionary/http-codes#client-4xx) и [5xx](https://yandex.ru/support/webmaster/ru/error-dictionary/http-codes#server-5xx) (если HTTP-статус страниц изменится, через некоторое время информация о них пропадет из Яндекс Вебмастера);
- текст ссылки на ресурсе;
- дату, когда робот Яндекса обнаружил ссылку на ресурсе.

> **Примечание**
>
> Появление в списке большого количества внешних ссылок не влияет на состояние сайта в поиске, если вы не используете техники, направленные на обман поисковых систем. Чтобы удалить ссылки на ваш сайт с ресурса, вы можете обратиться к владельцу этого ресурса или к его хостинг-провайдеру.

## Просмотр информации

По умолчанию данные в таблице сортируются по ИКС. Вы можете отсортировать список неработающих ссылок по дате обнаружения ссылки или с помощью [фильтрации](#фильтрация-данных).

Чтобы найти ресурс с наибольшим количеством ссылок на сайт, включите опцию **Группировать по сайтам**.

> **Примечание**
>
> Для одного сайта может отображаться до 200 000 внешних ссылок.

## Фильтрация данных

Сервис позволяет быстро найти информацию о странице с помощью фильтрации, нажав значок фильтра. Фильтровать данные можно по всем представленным параметрам. Например, можно использовать фильтрацию по URL:

### С указанием определенного фрагмента URL

Позволяет составить список ссылок, адрес которых содержит определенный фрагмент. Выберите из списка значение **Содержит** и в поле укажите нужное значение.

### С указанием специальных символов

Позволяет использовать специальные символы, чтобы задавать не строгое соответствие строки, а ее начало, подстроку и более сложные условия с применением регулярных выражений. Чтобы использовать их, выберите из списка значение **Условие**, а само условие введите в поле. Можно добавить несколько условий — каждое из них должно начинаться с новой строки.

Для условий доступны правила:

- выполнять любое из условий (соответствует оператору «ИЛИ»);
- выполнять все условия (соответствует оператору «И»).

### Символы, используемые для фильтрации

| Символ | Описание | Пример |
|---|---|---|
| `*` | Соответствует любому количеству любых символов | Отобразить данные по всем страницам, которые начинаются с `https://example.com/tariff/`, включая указанную страницу: `/tariff/*` |
| `@` | Выбранные данные содержат указанную строку (но не обязательно строго соответствуют) | Отобразить данные по всем страницам, URL которых содержит указанную строку: `@tariff` |
| `~` | Условие является регулярным выражением | Отобразить данные по страницам, URL которых удовлетворяет [регулярному выражению](https://yandex.ru/support/webmaster/ru/service/regexp). Например: `~table\|sofa\|bed` |
| `!` | Отрицание условия | Исключить данные по страницам, URL которых начинается со строки `https://example.com/tariff/`: `!/tariff/*` |

При использовании символов не учитывается регистр.

Символы `@`, `!`, `~` могут использоваться только в начале строки, для них доступны следующие сочетания:

| Оператор | Пример |
|---|---|
| `!@` | Исключить данные по страницам, URL которых содержит tariff: `!@tariff` |
| `!~` | Исключить данные по страницам, URL которых удовлетворяет условиям регулярного выражения |

## Вопросы и ответы

### Ваш робот пытается скачать страницы моего сайта по битым ссылкам. Почему?

Робот берет ссылки с других страниц, значит, на одной из них указаны некорректные ссылки на ваш сайт. Возможно, вы изменили структуру сайта и ссылки, стоявшие на других веб-страницах, стали некорректными.

### Почему робот обращался к несуществующим страницам/поддоменам моего сайта?

Вероятно, что робот где-либо обнаружил ссылки на них и попытался проиндексировать. Для того чтобы робот индексировал только полезные страницы сайта, несуществующие поддомены и страницы должны быть недоступны или возвращать код ошибки 404.

### На мой сайт ссылаются некачественные сайты

При разработке алгоритмов ранжирования мы постарались свести к минимуму возможность повлиять на индексирование или ранжирование сайта извне. Если вы не хотите, чтобы пользователи приходили на ваш сайт по таким ссылкам, пожалуйста, обратитесь к владельцам сайтов, на которых они размещены, или к хостинг-провайдерам, на серверах которых расположены эти сайты. Если ссылки будут удалены, информация о них пропадет из Яндекс Вебмастера автоматически.

### Количество входящих ссылок на мой сайт резко возросло

Робот отслеживает изменения на сайтах, и, если на каких-то страницах появились ссылки на ваш сайт, информация об этом будет отражена в Яндекс Вебмастере на странице **Неработающие ссылки** → **Внешние ссылки**.

### На странице больше нет ссылки на мой сайт, но она отображается в Яндекс Вебмастере

Ссылки отображаются в Яндекс Вебмастере до тех пор, пока они хранятся в базе поисковой системы. Если ссылки на ваш сайт уже удалены с каких-то страниц, то информация о них со временем автоматически пропадет из Яндекс Вебмастера. Это произойдет по мере того, как робот переиндексирует страницы, где ранее располагались ссылки.

### На мой сайт размещена ссылка, но она не отображается в сервисе

Ссылка может не отображаться в Яндекс Вебмастере, если:

- Страница, на которой расположена ссылка на ваш сайт, неизвестна роботу.
- Ссылка может вести на неглавный адрес вашего сайта: по другому протоколу (HTTP или HTTPS), с префиксом www или без него.
- Если на ресурсе размещено несколько ссылок, которые ведут на одну и ту же страницу вашего сайта и содержат одинаковый текст, то в Яндекс Вебмастере отобразится только одна из этих ссылок.
- Ссылка оформлена как строка текста, то есть по ней нельзя перейти, кликнув мышью (например, `www.yandex.com`).
- Ссылка не ведет непосредственно на ваш сайт, а делает это через промежуточную страницу с редиректом (в том числе ссылка из социальной сети).
- Ссылка появилась на странице недавно. Робот еще не проиндексировал эту страницу.
