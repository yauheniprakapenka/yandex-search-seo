# Переходы по неработающим ссылкам

> Source: https://yandex.ru/support/webmaster/ru/site-indexing/broken-links

На странице [Переходы по неработающим ссылкам](https://webmaster.yandex.ru/site/links/broken/) указаны ссылки, по которым переходят пользователи и попадают на несуществующие страницы. Списки ссылок формируются на основе обезличенных данных о переходах в Яндекс Браузере.

На вкладках перечислены переходы по неработающим ссылкам:

- **внешним** — это ссылки на несуществующие страницы вашего сайта, размещенные на других сайтах;
- **внутренним** — это ссылки со страниц вашего сайта на несуществующие страницы вашего сайта;
- **исходящим** — это ссылки со страниц вашего сайта на несуществующие страницы других сайтов.

Информация о переходах по неработающим ссылкам в каждой из вкладок представлена в виде таблицы и может включать в себя:

- URL страницы, на которой установлена ссылка;
- URL страницы, на которую ведет ссылка;
- HTTP-статус — [4xx](https://yandex.ru/support/webmaster/ru/error-dictionary/http-codes#client-4xx) и [5xx](https://yandex.ru/support/webmaster/ru/error-dictionary/http-codes#server-5xx) (если HTTP-статус страниц изменится, через некоторое время информация о них пропадет из Вебмастера);
- текст ссылки на ресурсе;
- дату последней проверки роботом Яндекса.

Данные о переходах по неработающим ссылкам на каждой вкладке можно выгрузить в формате XLS или CSV.
