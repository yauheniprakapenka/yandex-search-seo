# Неработающие ссылки

> Source: https://yandex.ru/support/webmaster/ru/site-indexing/info-broken-links

- [Виды неработающих ссылок](#виды-неработающих-ссылок)
- [Причины, по которым ссылки могут не отображаться в разделе](#причины-по-которым-ссылки-могут-не-отображаться-в-разделе)

Неработающая ссылка на сайте — это ссылка, которая не осуществляет перенаправление на нужную страницу или ресурс либо ведет к ошибке.

Чтобы контент вашего сайта отображался по корректным ссылкам, важно периодически проверять и исправлять неработающие ссылки.

Для проверки неработающих ссылок на сайте в Яндекс Вебмастере существует инструмент Проверка неработающих ссылок. С его помощью вы можете отследить появление новых ссылок и выявить все виды неработающих ссылок, найти ошибки и исправить их.

Данные о неработающих ссылках формируются со страниц, которые известны роботу Яндекса. Некоторые ссылки [могут не отображаться в Яндекс Вебмастере](#причины-по-которым-ссылки-могут-не-отображаться-в-разделе).

## Виды неработающих ссылок

### Неработающие ссылки без переходов

Неработающие ссылки, по которым пользователь не пытается перейти, могут быть результатом ошибок в коде сайта, неверных ссылок или удаленных страниц.

Неработающие ссылки без переходов по ним пользователем могут быть:

- [внешние](https://yandex.ru/support/webmaster/ru/site-indexing/external-links) — это ссылки на страницы вашего сайта со страниц других сайтов;
- [внутренние](https://yandex.ru/support/webmaster/ru/site-indexing/links-to-website) — это ссылки на страницы вашего сайта с других страниц вашего сайта.

### Переходы по неработающим ссылкам

Переход по ссылке — это действие, когда пользователь нажимает ссылку для перехода на другой сайт или страницу. Переходы по неработающим ссылкам перенаправляют пользователя на страницы с информацией о недоступности ресурса. Ошибки в результате таких переходов возникают из-за удаления страницы или неправильного URL. Подробнее смотрите на странице [Переходы по неработающим ссылкам](https://yandex.ru/support/webmaster/ru/site-indexing/broken-links).

## Причины, по которым ссылки могут не отображаться в разделе

Ниже перечислены причины, по которым некоторые ссылки могут не показываться:

- Страница, на которой расположена ссылка на ваш сайт, неизвестна роботу Яндекса.
- Ссылка может вести на неглавный адрес вашего сайта: по другому протоколу (HTTP или HTTPS), с префиксом www или без него.
- Если на ресурсе размещено несколько ссылок, которые ведут на одну и ту же страницу вашего сайта и содержат одинаковый текст, то в Яндекс Вебмастере отобразится только одна из этих ссылок.
- Ссылка оформлена как строка текста, то есть по ней нельзя перейти, кликнув мышью (например, `www.example.com`).
- Ссылка не ведет непосредственно на ваш сайт, а делает это через промежуточную страницу с редиректом (в том числе ссылка из социальной сети).
- Ссылка появилась на странице недавно — по ней еще не переходили пользователи.
