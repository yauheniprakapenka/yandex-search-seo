# Уведомления

> Source: https://yandex.ru/support/webmaster/ru/service/notifications

- [Настройка уведомлений](#настройка-уведомлений)
  - [Общие настройки уведомлений](#общие-настройки-уведомлений)
  - [Настройка уведомлений об одном сайте](#настройка-уведомлений-об-одном-сайте)
- [Просмотр уведомлений на сервисе](#просмотр-уведомлений-на-сервисе)

Когда вы добавите сайт в Яндекс Вебмастер или [получите права на управление сайтом](https://yandex.ru/support/webmaster/ru/service/rights-management#delegation) в сервисе, вам станет доступна информация о его изменениях в поиске. Например, вы узнаете, какие страницы появились в результатах поиска или пропали из выдачи.

Чтобы получать сообщения об изменениях, настройте уведомления по каждой отдельной теме:

## Общие

| Тема | Описание |
| --- | --- |
| Глобальные сообщения и новости сервисов для вебмастеров | Уведомления о важных изменениях на сервисе, приглашения на вебинары. |

## О сайтах

| Тема | Событие, после которого приходит уведомление |
| --- | --- |
| Еженедельная сводка по сайту | Сервис подготовил информацию об изменениях, которые произошли с сайтом. Яндекс Вебмастер предлагает краткую и полную сводку. Уведомления приходят только на почту.<br><br>Если на вашем сайте нет изменений или они незначительные, уведомления приходить не будут.<br><br>Сводка формируется за период с понедельника по воскресенье. |

**Краткая сводка**

- Ошибки на сайте.
- Изменение страниц в поиске.
- Динамика кликов по поисковым запросам.
- Динамика кликов по сайту в целом.
- Страницы, ссылки на которые набрали максимум кликов в поиске и максимум показов с понедельника по воскресенье.
- Решенные проблемы.
- Изменение [ИКС](https://yandex.ru/support/webmaster/ru/site-quality-index).
- Присвоение региона сайту.
- Изменение страниц, добавленных в [список важных](https://yandex.ru/support/webmaster/ru/service/tracking-url). Если страницы не добавлены в список важных, предлагается список [рекомендованных](https://yandex.ru/support/webmaster/ru/service/tracking-url#recommended) для отслеживания страниц.
- Появление [отзывов о вашем сайте](https://yandex.ru/support/webmaster/ru/service/reviews).
- Появление новостей в [блоге для вебмастеров](https://webmaster.yandex.ru/blog/).

**Полная сводка**

- Содержание краткой сводки.
- Дополнительная информация о Яндекс Вебмастере и других сервисах Яндекса.

| Тема | Событие, после которого приходит уведомление |
| --- | --- |
| Обновление поисковой базы | Обновление поисковой базы и индексирование страниц сайта. |
| Обновление главного адреса сайта | В качестве главного адреса сайта робот выбрал другой адрес. |
| Ошибки на сайте | При очередной проверке сайта выявлены проблемы. Решения см. в разделе [Ошибки на сайте](https://yandex.ru/support/webmaster/ru/service/site-diagnostics). |
| Рекомендации | Сервис подготовил советы, как улучшить представление сайта в результатах поиска. Подробнее об этом см. в разделе [Рекомендации](https://yandex.ru/support/webmaster/ru/diagnosis/recommendations). |
| Делегирование прав на управление сайтом | [Права на управление сайтом](https://yandex.ru/support/webmaster/ru/service/rights) получили другие пользователи Яндекс Вебмастера. Список пользователей, управляющих сайтом, можно изменить на странице **Настройки** → **Права доступа**. |
| Изменение регионов сайта | У сайта изменилась [региональная принадлежность](https://yandex.ru/support/webmaster/ru/site-geography/site-region). Узнать о региональности сайта можно на странице **Представление в поиске** → **Региональность**. |
| Изменение файла `robots.txt` | Содержимое файла изменилось с момента предыдущего обращения робота. О том, как узнать историю изменений файла, см. в разделе [Анализ robots.txt](https://yandex.ru/support/webmaster/ru/indexing-options/robots-txt-analyzer). |
| Появление поддоменов в поиске | В результатах поиска появились [поддомены](https://yandex.ru/support/webmaster/ru/diagnosis/recommendations#subdomain) вашего сайта. |
| Запросы от Метрики | Пользователь Метрики запросил [подтверждение привязки счетчика к сайту](https://yandex.ru/support/webmaster/ru/indexing-options/link-metrica). |
| Не включен обход по счетчикам Метрики | Сайт привязан к счетчику Метрики, но обход страниц еще не включен. Подробно см. в разделе [Индексирование сайта с помощью счетчика Метрики](https://yandex.ru/support/webmaster/ru/indexing-options/link-metrica#indexing-settings). Первое уведомление приходит спустя день после подтверждения запроса на привязку. |
| Обновление списка страниц, которые могут появиться в поиске по данным Метрики | Яндекс Вебмастер [обновил примеры страниц](https://yandex.ru/support/webmaster/ru/indexing-options/link-metrica). Посмотреть их можно на странице **Индексирование** → **Обход по счетчикам**. |
| Отзывы о сайтах | Пользователь Яндекса написал [отзыв о вашем сайте](https://yandex.ru/support/webmaster/ru/service/reviews). Яндекс Вебмастер регулярно проверяет появление новых отзывов. Чтобы посмотреть отзывы, перейдите на страницу **Оптимизация сайта** → **Отзывы**. |
| Обновление ИКС | Яндекс Вебмастер пересчитал индекс качества сайта. Подробнее о показателе см. в разделе [Индекс качества сайта](https://yandex.ru/support/webmaster/ru/site-quality-index). |
| Дополненное представление | При проверке YML-файлов Яндекс Вебмастер обнаружил ошибки. Посмотреть их можно на странице **Услуги и предложения в поиске** → **Фиды и ошибки**. |

Уведомления можно получать на сервис и на почту.

## О важных страницах

В Яндекс Вебмастере вы можете отдельно отслеживать страницы сайта, которые [считаете наиболее важными](https://yandex.ru/support/webmaster/ru/service/tracking-url) и получать уведомления об их изменениях в поиске.

| Тема | Событие, после которого приходит уведомление |
| --- | --- |
| Изменение заголовка страницы | Изменился заголовок, указанный в элементе [title](https://yandex.ru/support/webmaster/ru/recommendations/presentation#title). |
| Изменение даты последнего обхода | Робот посетил страницу сайта. |
| Изменение кода страницы | Робот посетил страницу сайта, при этом изменился код ответа. |
| Изменение версии страницы в поиске | Робот зафиксировал, что содержимое страницы изменилось. Уведомление содержит дату, когда робот узнал об изменениях. |
| Изменение статуса в поиске | Статус страницы изменился. Например, робот определил, что страница [маловостребованная](https://yandex.ru/support/webmaster/ru/site-indexing/low-demand), и [исключил](https://yandex.ru/support/webmaster/ru/site-indexing/excluded-pages) ее из результатов поиска. |
| Изменение тега description | Изменилось содержимое [метатега description](https://yandex.ru/support/webmaster/ru/indexing-options/description). |
| Изменение Canonical | Изменилось [указание на канонический адрес](https://yandex.ru/support/webmaster/ru/robot-workings/canonical) страницы. |

## Настройка уведомлений

Уведомления могут приходить:

- в интерфейсе Яндекс Вебмастера;
- на вашу электронную почту;
- в Telegram;
- в виде push-уведомлений в Яндекс Браузере и мобильном приложении Яндекс.

Яндекс Вебмастер позволяет настроить уведомления [сразу для всех сайтов](#общие-настройки-уведомлений), к которым у вас есть доступ на сервисе, а также [отдельно для каждого сайта](#настройка-уведомлений-об-одном-сайте).

Есть несколько статусов настройки уведомлений:

**Получать уведомления (активные статусы)**

- на сервисе
- на почту
- в виде push-уведомления*
- в Telegram*

**Не получать уведомления (неактивные статусы)**

- на сервисе
- на почту
- в виде push-уведомления*
- в Telegram*
- сообщает, что действуют [общие настройки](#общие-настройки-уведомлений). Отображается в [настройках для отдельного сайта](#настройка-уведомлений-об-одном-сайте)

Если [общие настройки](#общие-настройки-уведомлений) не действуют для определенного сайта, укажите, будете ли вы получать уведомления этого типа.

\* Настройка доступна только для некоторых тем сообщений.

Чтобы переключить статус уведомления с активного на неактивный или на статус по умолчанию, нажмите значок статуса.

### Общие настройки уведомлений

Эти настройки действуют для всех сайтов, подтвержденных в Яндекс Вебмастере для пользователя.

Чтобы изменить способ получения уведомлений:

1. В Яндекс Вебмастере внизу основного меню нажмите значок уведомлений, чтобы перейти на страницу [Уведомления](https://webmaster.yandex.ru/notifications/).
2. Нажмите кнопку **Настроить**.
3. В блоке **Адрес для почтовых уведомлений** выберите почту, на которую хотите получать уведомления от Яндекс Вебмастера. Доступные адреса соответствуют адресам в вашем Яндекс ID. Чтобы сменить адрес, выберите нужное значение из списка и нажмите кнопку **Изменить адрес**.

   Как указать адрес, которого нет в списке:

   Выберите из списка значение **Другой адрес** — откроются настройки аккаунта. Впишите почту в поле **Добавление адреса для восстановления** и нажмите кнопку **Добавить адрес**. Затем подтвердите доступ к нему. После подтверждения обновите страницу настроек в Яндекс Вебмастере. Добавленная почта появится в списке.

   Чтобы получать уведомления только на сервисе, выберите из списка значение **Не получать уведомления по почте**. В этом случае уведомления не будут приходить, даже если статус сообщения активен.

   Чтобы получать уведомления в Telegram, нажмите **Привязать аккаунт**. В мессенджере вы получите сообщение со ссылкой. При переходе по ней код подтверждения автоматически подставится в поле **Введите код подтверждения**. Нажмите **Подтвердить**.

4. Выберите нужный вам статус для каждой темы уведомлений.

### Настройка уведомлений об одном сайте

Используйте эти настройки, если хотите для конкретного сайта изменить способ получения уведомлений или набор уведомлений, отличный от [общих настроек](#общие-настройки-уведомлений).

Если вы подписаны на сообщения о всех сайтах, а хотите получать уведомления об одном или нескольких сайтах, отключите те общие уведомления, которые не нужно получать, и настройте сообщения для отдельного сайта по инструкции ниже.

1. В Яндекс Вебмастере внизу основного меню нажмите значок уведомлений, чтобы перейти на страницу [Уведомления](https://webmaster.yandex.ru/notifications/).
2. Нажмите **Настроить**.
3. В выпадающем списке в основном меню слева выберите сайт, для которого хотите настроить уведомления. Также, чтобы перейти к выбору сайта, вы можете нажать на ссылку в нижней части страницы с настройками.
4. На странице **Настройка уведомлений о сайте** выберите нужный вам статус для каждой темы уведомлений.

   Здесь можно настроить уведомления о сайте и о страницах, которые [считаете наиболее важными](https://yandex.ru/support/webmaster/ru/service/tracking-url). По умолчанию для всех тем указан статус по умолчанию. Он означает, что действуют общие настройки.

## Просмотр уведомлений на сервисе

> Примечание
>
> Уведомления об изменениях на сайте с [неглавным адресом](https://yandex.ru/support/webmaster/ru/yandex-indexing/site-addresses) могут не приходить, так как информация о них неактуальна.

Чтобы посмотреть сообщения, перейдите на страницу [Уведомления](https://webmaster.yandex.ru/notifications/). По умолчанию в списке отображаются все сообщения. Вы можете:

- просмотреть проблемы сайта;
- отфильтровать уведомления по конкретному сайту. Для этого выберите нужный сайт из выпадающего списка;
- массово выделить и удалить уведомления.
