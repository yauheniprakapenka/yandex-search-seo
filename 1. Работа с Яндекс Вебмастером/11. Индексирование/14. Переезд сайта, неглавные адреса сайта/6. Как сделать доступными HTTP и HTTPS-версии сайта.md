# Как сделать доступными HTTP и HTTPS-версии сайта

> Source: https://yandex.ru/support/webmaster/ru/yandex-indexing/protocols-avail

Может быть ситуация, когда при переходе из результатов поиска Яндекса у некоторых пользователей не поддерживается HTTPS-версия сайта. Например, на HTTPS-версии установлен сертификат Национального центра сертификации, а у пользователя он не поддержан. В этом случае Яндекс может предлагать пользователю перейти на версию сайта, доступную по протоколу HTTP, вместо HTTPS. Чтобы это происходило, проверьте условия:

- HTTPS-версия является [главным адресом сайта](https://yandex.ru/support/webmaster/ru/yandex-indexing/https-migration).

- HTTP-версия доступна пользователям и роботу Яндекса — [проверьте ответ сервера](https://yandex.ru/support/webmaster/ru/indexing-options/server-response). При необходимости уберите редирект с HTTP-версии на HTTPS.

- Содержимое HTTP-версии полностью совпадает с содержимым HTTPS-версии.
