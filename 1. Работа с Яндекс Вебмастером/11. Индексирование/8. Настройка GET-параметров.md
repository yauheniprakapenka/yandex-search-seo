# Настройка GET-параметров

> Source: https://yandex.ru/support/webmaster/ru/indexing-options/get-parameters

- [Что такое GET-параметры](#что-такое-get-параметры)
- [Как управлять GET-параметрами](#как-управлять-get-параметрами)

Инструмент Яндекс Вебмастера **Настройка GET-параметров** помогает указать роботу, какие страницы с GET-параметрами в URL надо обходить и добавлять в поиск, а какие следует из поиска исключить. Это уменьшит количество обращений поискового робота, снизит нагрузку на сайт, ускорит его индексирование и в поиске будет участвовать нужная вам страница.

## Что такое GET-параметры

GET-параметры — это параметры адреса страницы, которые добавляются, например, для анализа эффективности рекламных кампаний или отслеживания поведения посетителей на сайте.

Пример ссылки с такими параметрами:

```
https://example.com/page?utm_source=vk&utm_medium=cpc
```

Из-за GET-параметров страницы с одинаковым содержимым открываются по разным URL: с параметрами и без. Поиск такие страницы может признать дублями. [Подробно о дублях](https://yandex.ru/support/webmaster/ru/robot-workings/double)

## Как управлять GET-параметрами

Перейдите в Яндекс Вебмастер на страницу **Индексирование** → **Настройка GET-параметров**.

На странице представлен список всех параметров, которые обнаружил на сайте робот. Вы можете добавить дополнительные параметры и удалить их, если они станут неактуальны. Параметры, которые найдены роботом, удалить из списка нельзя.

Укажите в столбце **Учитывать параметр?** нужное вам значение:

- Значение не выбрано — страница индексируется роботом и может участвовать в поиске.
- **Да** — страница индексируется роботом и может участвовать в поиске.
- **Нет** — страница не индексируется роботом, в поиске не участвует.

Для параметров, которые были добавлены вручную, в столбце **Раздел сайта** можно указать, на каких страницах будет работать заданная настройка:

- **Все страницы**;
- **Главная страница**;
- определенный раздел.

Внесенные изменения вступят в силу в течение недели.

Правила индексирования страниц с GET-параметрами в URL могут быть также заданы в файле robots.txt с помощью директивы [Clean-param](https://yandex.ru/support/webmaster/ru/robot-workings/clean-param).

Если настройки в Яндекс Вебмастере на странице **Настройка GET-параметров** будут противоречить правилам в robots.txt, поисковый робот станет выполнять то правило, которое запрещает индексировать URL с GET-параметром.
