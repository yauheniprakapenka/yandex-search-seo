# Расширенная статистика по сайту

> Source: https://yandex.ru/support/webmaster/ru/service/stat-all-pages

В Вебмастере вы можете получать информацию о том, как меняется состояние сайта в поиске:

- О страницах в поиске — на странице **Индексирование**. Отображается до 50 000 изменений страниц в поиске.
- О страницах и поисковых запросах — на странице **Поисковые запросы**. Отображаются данные по первым 3000 запросов, по которым сайт отображался в поиске в течение трех месяцев.

Чтобы получать статистику без ограничений, используйте файл [Sitemap](https://yandex.ru/support/webmaster/ru/controlling-robot/sitemap). Статистику по страницам можно будет скачать в виде архива.

> **Примечание**
>
> Чтобы архив сформировался, `Sitemap` должен быть размещен на сайте и [загружен роботом](https://yandex.ru/support/webmaster/ru/indexing-options/sitemap#download).

Архив содержит данные:

- О страницах, указанных в `Sitemap`.
- О страницах, в исходном коде которых есть атрибут [rel="canonical"](https://yandex.ru/support/webmaster/ru/robot-workings/canonical) со ссылкой на страницу, указанную в `Sitemap`.

С помощью архива вы получите следующую информацию:

## Состояние страниц в поиске

Файл содержит данные о состоянии страниц в поиске на текущий момент:

- `url` — адрес страницы;
- `httpCode` — HTTP-код, полученный роботом во время последнего обхода;
- `status` — [статус страницы в поиске](https://yandex.ru/support/webmaster/ru/service/searchable#status);
- `lastAccess` — дата последнего посещения страницы роботом;
- `fromSitemap` — найден ли URL в Sitemap;
- `redirTarget` — адрес страницы для перенаправления;
- `relCanonical` — адрес основной страницы (значение [атрибута rel="canonical"](https://yandex.ru/support/webmaster/ru/robot-workings/canonical));
- `title` — заголовок страницы (содержимое HTML-элемента `title`);
- `metaDescription` — содержимое [метатега Description](https://yandex.ru/support/webmaster/ru/indexing-options/description).

Чтобы скачать архив, перейдите на страницу [Все страницы](https://webmaster.yandex.ru/site/indexing/all-pages/).

## Страницы и поисковые фразы

Статистика основана на результатах поисковой выдачи на любых устройствах по всем регионам. Архив содержит информацию о поисковых запросах, по которым сайт отображался последние семь дней. Для каждого запроса можно посмотреть:

- *клики*
- *показы*
- *среднюю позицию по показам*

Чтобы скачать архив, перейдите на страницу [Статистика запросов](https://webmaster.yandex.ru/site/search/statistics/) и выберите тип данных.

---

> *Позиция сайта* — номер на страницах результатов поиска Яндекса, которому соответствует ссылка, ведущая на ваш сайт. В течение дня сайт может занимать разные позиции по одной поисковой фразе, поэтому сервис показывает среднее значение за весь день.
>
> *Клик* — переход посетителя на сайт со страницы результатов поиска Яндекса.
>
> *Показ* — появление ссылки на сайт в результатах поиска Яндекса по некоторому запросу. Показом не является потенциальное появление ссылки на второй и последующих страницах результатов поиска, если пользователь эти страницы не открывал.
