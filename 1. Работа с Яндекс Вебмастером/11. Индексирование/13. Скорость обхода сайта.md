# Скорость обхода сайта

> Source: https://yandex.ru/support/webmaster/ru/service/crawl-rate

- [Настройки по умолчанию](#настройки-по-умолчанию)
- [Изменение скорости обхода](#изменение-скорости-обхода)

Роботы Яндекса постоянно [индексируют](https://yandex.ru/support/webmaster/ru/robot-workings/robot) сайты: обходят их и загружают страницы в свою базу.

Скорость обхода сайта — это количество запросов в секунду, которое робот отправляет на ваш сайт.

> **Примечание**
>
> Необходимо отдельно настроить скорость обхода для основного домена сайта и каждого его поддомена.

## Настройки по умолчанию

Оптимальная скорость обхода сайта рассчитывается по алгоритмам так, чтобы робот смог загрузить максимальное количество страниц без лишней нагрузки на сервер. Поэтому в Вебмастере по умолчанию включена опция **Доверять Яндексу** на странице **Индексирование** → **Скорость обхода**.

## Изменение скорости обхода

### Снижение скорости

Снижение скорости обхода сайта может потребоваться, если вы заметили большое число обращений роботов к серверу, на котором находится ваш сайт. Это может увеличивать время ответа сервера и, как следствие, снижать скорость загрузки страниц сайта. Проверить эти показатели можно с помощью [отчета Яндекс Метрики](https://yandex.ru/support/metrika/reports/timing.html).

Перед тем, как изменить скорость обхода сайта, выясните, к каким именно страницам робот обращается чаще.

- Проанализируйте логи сервера. Обратитесь к сотруднику, ответственному за сайт, или к хостинг-провайдеру.
- Посмотрите список URL в Вебмастере на странице **Индексирование** → **Статистика обхода** (установите переключатель в положение **Все страницы**). Обратите внимание, есть ли в списке технические страницы или страницы-дубли — например, с GET-параметрами.

Если вы обнаружите, что робот обращается к служебным страницам или страницам-дублям, запретите их индексирование в файле `robots.txt` с помощью [директивы Disallow](https://yandex.ru/support/webmaster/ru/robot-workings/allow-disallow). Это поможет снизить количество лишних обращений робота.

Чтобы проверить корректность установленных правил, используйте [инструмент Анализ robots.txt](https://webmaster.yandex.ru/tools/robotstxt/).

### Увеличение скорости

Вы можете увеличить скорость обхода сайта. Заданное вами значение считается рекомендованным для робота. Фактическая скорость обхода может отличаться от заданной с учетом информации о сайте, которой обладает Яндекс.

1. В Вебмастере перейдите на страницу **Индексирование** → **Скорость обхода**.
2. Включите опцию **Задать вручную**.
3. Передвиньте ползунок в нужное положение. По умолчанию он выставлен на оптимальную скорость обхода, рассчитанную для вашего сайта.
4. Сохраните изменения.
