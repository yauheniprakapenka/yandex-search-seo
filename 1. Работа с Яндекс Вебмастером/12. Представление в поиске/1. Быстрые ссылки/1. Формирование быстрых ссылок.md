Быстрые ссылки делают *сниппет* вашего сайта более информативным — с их помощью пользователи быстрее находят важную информацию.

## Условия создания быстрых ссылок

Быстрые ссылки формируются автоматически роботом Яндекса. Робот определяет наиболее посещаемые разделы сайта и создает быстрые ссылки при следующих условиях:

- короткие и понятные названия страниц точно отражают их содержание;
- ссылка создается только на основе внутренних ссылок сайта, а ее текст может состоять из названий внутренних и внешних страниц;
- разделы и подразделы выделены в меню или являются самыми популярными переходами со страницы, для которой формируются быстрые ссылки.

## Отображение быстрых ссылок

Быстрые ссылки могут отображаться для главной и для внутренних страниц сайта. Быстрые ссылки бывают в виде:

- **Ссылок**
- **[Навигационного ответа](https://yandex.ru/support/webmaster/search-appearance/navigation.html)**

Для отображения того или иного вида должны выполняться следующие условия:

| Условие | Ссылки | Навигационный ответ |
|---|---|---|
| Быстрые ссылки сформированы. [Проверьте](https://yandex.ru/support/webmaster/ru/search-results/quick-links-result#view) это в Вебмастере на странице **Представление в поиске** → **Быстрые ссылки**. | ✓ | ✓ |
| Страница входит в ТОП 5 результатов поиска. | ✓ | — |
| На выдаче нет навигационного ответа у страницы, которая находится выше по позициям. | — | ✓ |
| Алгоритмы должны посчитать страницу и ее быстрые ссылки релевантным ответом на поисковый запрос. | — | ✓ |

## Почему быстрые ссылки перестали отображаться

При очередном обходе сайта робот может удалить быструю ссылку по следующим причинам:

- робот нашел более подходящую страницу для быстрой ссылки;
- структура вашего сайта изменилась;
- сайт перестал соответствовать [условиям формирования быстрых ссылок](#условия-создания-быстрых-ссылок).
