# Проверка ответа сервера

> Source: https://yandex.ru/support/webmaster/ru/indexing-options/server-response

- [Вопросы и ответы](#вопросы-и-ответы)
- [Узнайте больше](#узнайте-больше)

С помощью инструмента [Проверка ответа сервера](https://webmaster.yandex.ru/tools/server-response/) вы можете узнать, доступны ли страницы сайта для роботов Яндекса, а также другую информацию о сайте, например, статус SSL-сертификата.

> **Внимание**
>
> Когда ответ сервера отличается от HTTP-статуса с кодом 200 OK или отображается сообщение из списка ниже, страница не может участвовать в результатах поиска.

В качестве ответа сервера могут отображаться:

- **HTTP-код** — пояснения см. в разделе [Справочник по кодам статуса HTTP](https://yandex.ru/support/webmaster/ru/error-dictionary/http-codes).
- **Статус SSL-сертификата для HTTPS-сайтов**

### Сообщения о статусе SSL-сертификата сайта

- Не найден удостоверяющий центр, выдающий сертификат
- Подпись сертификата не удалось расшифровать. Значение RSA-ключа не соответствует ожидаемому значению
- Невозможно прочитать открытый ключ
- Подпись сертификата недействительна
- Дата начала действия сертификата еще не наступила
- Истек срок действия сертификата
- Ошибка в дате начала действия сертификата
- Ошибка в дате завершения действия сертификата
- Сертификат является самозаверенным и не найден в списке доверенных сертификатов
- Цепочка сертификатов может содержать ненадежные сертификаты, но корневой сертификат не найден
- Не найден сертификат удостоверяющего центра
- Подписи не могут быть проверены, так как цепочка сертификатов содержит только один сертификат, и он не самозаверен
- Сертификат отозван
- Удостоверяющий центр недействителен
- Превышена длина цепочки сертификатов
- Некорректный [тип сертификата](https://yandex.ru/support/webmaster/ru/yandex-indexing/https-migration#sert)
- Корневой удостоверяющий центр не является доверенным
- Корневой удостоверяющий центр отклонил сертификат
- Неизвестная ошибка сертификата
- Корневой сертификат занесен в черный список
- Сертификат уже выдан другому сайту
- Отсутствует сертификат узла

Для решения проблем с SSL-сертификатом обратитесь в ваш удостоверяющий центр или к хостинг-провайдеру.

### Другие сообщения

| Сообщение | Примечание |
|---|---|
| Не удалось загрузить документ | Появляется по следующим причинам: запрос робота блокируется на стороне сервера или соединение обрывается при попытке получить ответ (проверьте, не заблокирован ли робот по IP-адресу); ошибка DNS (проверьте, что сайт доступен и DNS настроены правильно, если настройки недавно изменялись, данные обновятся в течение суток); истек срок ожидания ответа (он должен быть получен в течение трех секунд). |
| Не удалось подключиться к серверу | Произошел обрыв соединения. |
| URL запрещён к индексированию тегом `noindex` | На странице есть метатег `robots` с [директивой noindex](https://yandex.ru/support/webmaster/ru/controlling-robot/metatags#sup). |
| URL запрещён к индексированию в robots.txt | В файле `robots.txt` указана [директива Disallow](https://yandex.ru/support/webmaster/ru/robot-workings/allow-disallow), запрещающая индексирование страницы или каталога, в котором она размещена. |
| Слишком большой объём документа | Максимальный объем страницы сайта — 10 МБ. |
| Формат документа не поддерживается | Поддерживаются HTML-документы и файлы следующих типов: PDF, DOC/DOCX, XLS/XLSX, PPT/PPTX (MS Office); ODS, ODP, ODT, ODG (Open Office); RTF, TXT и SWF. |
| Некорректный код ответа | Поддерживаются [стандартные коды HTTP-статусов](https://yandex.ru/support/webmaster/ru/error-dictionary/http-codes). |
| Язык документа не распознан | [Список поддерживаемых языков](https://yandex.ru/support/webmaster/ru/yandex-indexing/locale-pages#supported-language). |
| Документ не содержит текст | Страница пуста или не содержит контент, который может быть проиндексирован роботом. |
| Содержимое страницы отсутствует | Проверьте в настройках вашего сервера: HTTP-заголовок (например, если он содержит `Content-length: 0`, то робот не сможет проиндексировать такую страницу); размер содержимого страницы (он должен быть больше 0 и соответствовать HTTP-заголовку). |

> **Примечание**
>
> Ответ, полученный с помощью инструмента «Проверка ответа сервера», может отличаться от реального ответа роботу, так как инструмент имеет другой IP-адрес. Проверить ответ можно в логах вашего сервера.

## Как проверить ответ сервера с помощью Вебмастера

1. Перейдите на страницу [Проверка ответа сервера](https://webmaster.yandex.ru/tools/server-response/).
2. В поле **Опрашиваемый URL** укажите адрес страницы, которую хотите проверить. Например, `https://example.com`.
3. В поле **Робот** выберите робота, чтобы проверить, имеет ли он доступ к странице. В раскрывающемся списке приведены основные роботы, которые посещают большинство сайтов. Когда вы выберете робота, под полем отобразится его User-agent. Подробнее см. в разделе [Роботы Яндекса в логах сервера](https://yandex.ru/support/webmaster/ru/robot-workings/check-yandex-robots#robot-in-logs).
4. Нажмите кнопку **Проверить**.

Также вы можете проверить ответ, если ваш сервер отправляет HTTP-статус с кодом 304 Not Modified в ответ на заголовок If-Modified-Since. Для этого в поле **If-Modified-Since** укажите дату и время:

- Последнего обновления проверяемой страницы. Тогда полученный ответ должен содержать HTTP-статус с кодом 200 OK.
- Другую дату — должен вернуться ответ с кодом 304 Not Modified.

## Вопросы и ответы

### Отображается статус «Документ не содержит текст» при проверке Sitemap

Статус сообщает, что робот не может проиндексировать файл как обычную страницу сайта и включить его содержимое в результаты поиска. На обработку `Sitemap` этот статус не влияет. Чтобы проверить корректность `Sitemap` используйте в Вебмастере инструмент [Анализ файлов Sitemap](https://yandex.ru/support/webmaster/ru/indexing-options/tool-sitemap).

### Отображается статус «URL запрещён к индексированию тегом noindex» при проверке Sitemap

Статус сообщает, что файл закрыт от индексирования — как правило, запрет прописан в [HTTP-заголовке X-Robots-Tag](https://yandex.ru/support/webmaster/ru/controlling-robot/metatags#meta-robots). Директива запрещает файлу появляться в результатах поиска, но не влияет на обработку содержимого `Sitemap`. Чтобы проверить корректность `Sitemap` используйте в Вебмастере инструмент [Анализ файлов Sitemap](https://yandex.ru/support/webmaster/ru/indexing-options/tool-sitemap).
