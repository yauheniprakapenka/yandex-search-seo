# XML-валидатор

> Source: https://yandex.ru/support/webmaster/ru/indexing-options/xml-validator

- [Как проверить файл](#как-проверить-файл)

[XML-валидатор](https://webmaster.yandex.ru/tools/xml-validator/) предназначен для проверки XSD-схемы XML-файла. Проверяется правильность синтаксиса, структура, модель содержания и типы данных. В XML-файле передаются данные для отображения сайта в Поиске.

Валидатор не проверяет набор элементов в фиде. Например, если в XML-файле нет обязательного для программы элемента, валидатор это не выявит. В результате фид не будет работать в партнерской программе.

Проверяйте элементы XML-файла самостоятельно, чтобы они соответствовали техническим требованиям определенной программы.

## Как проверить файл

### 1. Выберите схему валидации

В инструменте доступно несколько видов схем валидации. Выберите нужную схему.

**Врачи**

Проверьте YML-фид перед тем, как передавать данные о врачах и медицинских услугах вашего сайта в поиск Яндекса. Все требования к формату передачи данных о врачах — [в Справке](https://yandex.ru/support/webmaster/ru/search-appearance/doctors#yml).

**Недвижимость**

Валидация формата экспортного файла для сервиса [Яндекс Недвижимость](http://realty.yandex.ru/). Содержит базовую информацию об объявлениях. Ознакомьтесь с [Техническими требованиями](https://yandex.ru/support/realty/rules/content-requirements.html).

**Маркет**

Валидация формата экспортного файла YML для [поиска для интернет-магазина](https://yandex.ru/support/site/create-catalogue/create.html).

**Бизнес**

Валидация формата экспортного файла для партнерской программы [Яндекс Бизнеса](https://yandex.ru/promo/sprav-partner). Вы можете передать данные о филиалах компании для массового добавления информации в Яндекс Картах и в сниппетах Поиска. Ознакомьтесь с [Техническими требованиями](https://yandex.ru/support/business-priority/branches/basic.html#basic__xml).

По умолчанию выбраны **Врачи**. Если у вас другая схема, но вы ее не указали, отобразится ошибка:

```
Строка: 3 Позиция: 38
Подробнее
<detail>cvc-elt.1.a: Cannot find the declaration of element
'yml_catalog'.</detail>
```

Также вы можете загрузить собственную схему — выберите **Другое**.

### 2. Выберите источник XML-данных для валидации

- **Файл** — вы можете загрузить произвольный XSD-файл и провести по нему проверку ваших XML-документов. Нажмите **Выбрать файл** и загрузите файл.
- **Ссылка** — укажите URL произвольной XSD-схемы.
- **Код** — скопируйте в текстовое поле содержимое XSD-схемы. Нажмите **Проверить**.
