# Обзор инструментов

> Source: https://yandex.ru/support/webmaster/ru/indexing-options/tools

**Анализ robots.txt**

Помогает проверить, корректно ли составлен файл `robots.txt` вашего сайта, узнать, разрешен ли для индексирования определенный URL, а также просмотреть историю изменений файла. [Подробно](https://yandex.ru/support/webmaster/ru/indexing-options/robots-txt-analyzer)

**Анализ файлов Sitemap**

Помогает проверить, корректно ли сформирован файл `Sitemap` вашего сайта. После проверки файл можно загрузить в Яндекс Вебмастер, чтобы быстрее обошел его содержимое. [Подробно](https://yandex.ru/support/webmaster/ru/indexing-options/tool-sitemap)

**Проверка ответа сервера**

Помогает проверить, доступны ли страницы сайта для основных роботов Яндекса. [Подробно](https://yandex.ru/support/webmaster/ru/indexing-options/server-response)

**Удаление страниц из поиска**

Позволяет ускорить удаление определенной страницы сайта, каталога или всего сайта из результатов поиска. [Подробно](https://yandex.ru/support/webmaster/ru/yandex-indexing/removing-from-index)

**Проверка мобильных страниц**

Помогает определить, насколько отдельные страницы вашего сайта оптимизированы под мобильные устройства. [Подробно](https://yandex.ru/support/webmaster/ru/recommendations/mobile-site)

**XML-валидатор**

Помогает проверить XSD-схемы документа вашего сайта (правильность синтаксиса, структура, модель содержания и типы данных), сформированного для участия в [Партнерских программах](https://yandex.ru/support/webmaster/ru/site-content/data-transmit) Яндекса. [Подробно](https://yandex.ru/support/webmaster/ru/indexing-options/xml-validator)

**Валидатор микроразметки**

Помогает проверить микроразметку на вашем сайте: [микроформаты](https://yandex.ru/support/webmaster/ru/microformats/what-is-microformat), [Schema.org](https://yandex.ru/support/webmaster/ru/schema-org/intro-schema-org), [Open Graph](https://yandex.ru/support/webmaster/ru/open-graph/intro-open-graph), [микроданные HTML](http://www.w3.org/TR/microdata/) и [RDFa](http://www.w3.org/TR/rdfa-core/). [Подробно](https://yandex.ru/support/webmaster/ru/yandex-indexing/validator)

**Проверка IP-адреса**

Помогает проверить принадлежит ли IP-адрес поисковым роботам Яндекса. [Подробно](https://yandex.ru/support/webmaster/ru/indexing-options/ip-check)

**Проверка сертификата**

Помогает проверить информацию о выданных сайту SSL/TLS-сертификатах, в том числе Национальным удостоверяющим центром. [Подробно](https://yandex.ru/support/webmaster/ru/service/certification)
