# Валидатор микроразметки

> Source: https://yandex.ru/support/webmaster/ru/yandex-indexing/validator

- [Ошибки](#ошибки)
- [Предупреждения](#предупреждения)
- [Вопросы и ответы](#вопросы-и-ответы)

В число инструментов Яндекс Вебмастера входит [валидатор семантической разметки](https://webmaster.yandex.ru/site/tools/microtest/). Валидатор поможет убедиться, что метаданные на ваших страницах распознаются корректно. Поддерживаются [микроформаты](https://yandex.ru/support/webmaster/ru/microformats/what-is-microformat), [Schema.org](https://yandex.ru/support/webmaster/ru/schema-org/intro-schema-org), [Open Graph](https://yandex.ru/support/webmaster/ru/open-graph/intro-open-graph), [микроданные HTML](http://www.w3.org/TR/microdata/) и [RDFa](http://www.w3.org/TR/rdfa-core/).

В отличие от других валидаторов разметки ([Validator.nu](http://validator.nu/), [Structured Data Linter](http://linter.structured-data.org/) и т. п.) валидатор Яндекса также проверяет соответствие разметки требованиям сервисов Яндекса, учитывая все дополнительные типы и поля данных, введенные нами.

Чтобы проверить код страницы, введите ее адрес в поле **URL документа**, или вставьте код ниже. Затем нажмите кнопку **Проверить**.

Под заголовком **Результаты проверки** валидатор выведет данные, которые удалось распознать, или текст ошибки.

## Ошибки

| Ошибка | Описание |
|---|---|
| Страница не может быть загружена | Страница не существует, или недоступна для робота Яндекса. |
| Микроразметка не обнаружена | Валидатор не смог распознать ни одного корневого элемента разметки — из-за того, что разметки нет, или корневые элементы оформлены неверно. Например, в корневом элементе Schema.org пропущен атрибут `itemscope`. |
| Поле \<...\> отсутствует или пусто | Валидатор перечисляет обязательные поля, которые опущены в проверяемой разметке. Например, нужно обязательно указать адрес картинки, описывая ее. |
| Невозможно определить принадлежность данных полей | Возможны две причины: поля некорректно размещены; указан лишний атрибут `itemprop`. Арибуты, относящиеся к микроданным (`itemprop`, в частности) должны быть размещены внутри элемента, содержащего `itemscope` и `itemtype`. [Подробно](https://yandex.ru/support/webmaster/ru/schema-org/intro-schema-org). |
| Не выполнено обязательное условие для продуктовых сниппетов | Рекомендуем исправить данную ошибку, если вы хотите получить структурированные сниппеты в поисковой выдаче Яндекса. |
| В свойстве `content` тега `meta` не может содержаться ссылка | Для использования ссылки используйте тег `link` вместо тега `meta`. |

**Пример: Микроразметка не обнаружена**

Неправильно:

```html
<div itemtype="http://schema.org/Movie">
```

Правильно:

```html
<div itemscope itemtype="http://schema.org/Movie">
```

**Пример: Поле отсутствует или пусто**

Неправильно:

```html
<div itemscope itemtype="http://schema.org/ImageObject">
   <h2 itemprop="name">Винни-Пух</h2>
   <img src="http://example.com/image.png"/>
   <span itemprop="description">Винни-Пух и все-все-все.</span>
</div>
```

Правильно:

```html
<div itemscope itemtype="http://schema.org/ImageObject">
   <h2 itemprop="name">Винни-Пух</h2>
   <img src="http://example.com/image.png" itemprop="contentUrl"/>
   <span itemprop="description">Винни-Пух и все-все-все.</span>
</div>
```

## Предупреждения

| Предупреждение | Описание |
|---|---|
| Значение «...» в поле \<...\> не является корректным значением | Значение поля не соответствует стандарту. Например, дата в Schema.org должна быть указана в формате [ISO 8601](http://ru.wikipedia.org/wiki/ISO_8601), дата в другом формате не распознается корректно. |
| Тип \<...\> неизвестен по спецификации \<...\> | Указанный тип данных не входит в число стандартных типов формата или в число типов, введенных Яндексом. Убедитесь, что имя типа данных указано верно. |
| В данный момент разметка \<...\> не может использоваться отдельно от разметки \<...\> | Чтобы ваши данные использовались в сервисе, необходимо дополнительно указать поля. Валидатор предупреждает, что разметка корректна, но сервисы Яндекса не смогут использовать извлеченную информацию. Ознакомьтесь с информацией в разделе [Введение в schema.org](https://yandex.ru/support/webmaster/ru/schema-org/intro-schema-org), чтобы правильно дополнить разметку. |

**Пример: Некорректное значение даты**

Неправильно:

```html
<meta itemprop="datePublished" content="2012/07/15">
```

Правильно:

```html
<meta itemprop="datePublished" content="2012-07-15">
```

Если валидация разметки завершена успешно, и вы выполнили требования партнерской программы, структурированный сниппет может сформироваться после очередного переобхода страниц роботом Яндекса. Это может занять около двух недель.

## Вопросы и ответы

### Ошибки в разметке

С помощью валидатора микроразметки вы можете проверить HTML-фрагмент страницы. Попробуйте редактировать код непосредственно в валидаторе и повторно проверять его после каждого изменения, чтобы найти ошибку в разметке.

Подробное описание возможных ошибок см. в разделе [Валидатор микроразметки](https://yandex.ru/support/webmaster/ru/yandex-indexing/validator).
